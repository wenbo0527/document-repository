## 二、数据库设计

### 2.1 特征表 (feature_info)

```sql
CREATE TABLE feature_info (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
    feature_code VARCHAR(64) NOT NULL UNIQUE COMMENT '特征编码',
    feature_name VARCHAR(128) NOT NULL COMMENT '特征名称',
    feature_type VARCHAR(32) NOT NULL COMMENT '特征类型: RAW/DERIVED/COMPOSITE',
    data_type VARCHAR(32) NOT NULL COMMENT '数据类型: STRING/INT/DOUBLE/DATE',
    description TEXT COMMENT '特征描述',
    status VARCHAR(32) NOT NULL DEFAULT 'DRAFT' COMMENT '状态: DRAFT/PENDING/APPROVED/ARCHIVED',
    source_table VARCHAR(128) COMMENT '源数据表',
    source_field VARCHAR(128) COMMENT '源数据字段',
    owner_id BIGINT COMMENT '负责人ID',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_feature_code (feature_code),
    INDEX idx_status (status),
    INDEX idx_create_time (create_time)
) COMMENT='特征信息表';
```

### 2.2 回溯任务表 (backfill_task)

```sql
CREATE TABLE backfill_task (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
    task_code VARCHAR(64) NOT NULL UNIQUE COMMENT '任务编码',
    task_name VARCHAR(128) NOT NULL COMMENT '任务名称',
    partition_type VARCHAR(32) NOT NULL COMMENT '分区类型: DAY/WEEK/MONTH',
    cron_expression VARCHAR(64) COMMENT 'Cron表达式',
    start_date DATE COMMENT '开始日期',
    end_date DATE COMMENT '结束日期',
    status VARCHAR(32) NOT NULL DEFAULT 'STOPPED' COMMENT '状态: STOPPED/RUNNING/PAUSED',
    last_run_time DATETIME COMMENT '上次执行时间',
    next_run_time DATETIME COMMENT '下次执行时间',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_task_code (task_code),
    INDEX idx_status (status)
) COMMENT='回溯任务表';
```

### 2.3 回溯执行记录表 (backfill_execution)

```sql
CREATE TABLE backfill_execution (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
    task_id BIGINT NOT NULL COMMENT '任务ID',
    execution_time DATETIME NOT NULL COMMENT '执行时间',
    partition_date DATE NOT NULL COMMENT '分区日期',
    status VARCHAR(32) NOT NULL COMMENT '状态: RUNNING/SUCCESS/FAILED',
    start_time DATETIME COMMENT '开始时间',
    end_time DATETIME COMMENT '结束时间',
    total_count INT DEFAULT 0 COMMENT '总数量',
    success_count INT DEFAULT 0 COMMENT '成功数量',
    fail_count INT DEFAULT 0 COMMENT '失败数量',
    error_message TEXT COMMENT '错误信息',
    INDEX idx_task_id (task_id),
    INDEX idx_execution_time (execution_time),
    INDEX idx_partition_date (partition_date)
) COMMENT='回溯执行记录表';
```

   │<─────────────────────────┼                           │
   │   返回注册表单           │                           │
   │                           │                           │
   ├─> 提交注册 ─────────────>│                           │
   │                           ├─> 写入特征表 ─────────> MySQL
   │                           │<──────────────────────────┤
   │                           ├─> 发送审核通知 ────────> 消息队列
   │<─────────────────────────┤                           │

## 五、非功能性设计

### 5.1 性能设计

| 指标 | 目标 | 方案 |
|:---|:---|:---|
| 特征查询响应 | ≤ 2s | Redis 缓存热点特征数据 |
| 批量导入吞吐 | ≥ 1000条/min | 异步队列+批量写入 |
| 回溯任务启动 | ≤ 30s | 预加载+任务池 |

### 5.2 高可用设计

| 方案 | 说明 |
|:---|:---|
| 服务多实例 | 后端服务部署多实例，Nginx 负载均衡 |
| 任务调度高可用 | XXL-Job 执行器多实例部署 |
| 数据高可用 | MySQL 主从复制 |

### 5.3 安全设计

| 方案 | 说明 |
|:---|:---|
| 权限控制 | 基于 RBAC 的功能权限和数据权限 |
| 数据脱敏 | 敏感特征数据脱敏展示 |
| 操作审计 | 记录所有操作日志 |
