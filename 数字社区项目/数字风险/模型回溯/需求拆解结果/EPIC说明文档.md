## 2. EPIC 概述

### 2.1 是什么

模型回溯是数字风险产品域的核心模块，覆盖特征管理、模型注册、模型回溯、模型评估的全生命周期管理。

### 2.2 解决什么问题

1. **特征管理混乱**：特征缺乏统一管理，版本控制困难
2. **模型追溯困难**：模型上线后难以追溯其效果和影响
3. **评估体系缺失**：缺乏标准的模型评估流程

### 2.3 目标用户

- 数据科学家：特征管理、模型注册
- 风控人员：模型回溯、效果评估
- 运维人员：任务监控、问题排查

## 3. 功能范围

### 3.1 包含的功能

| 功能模块 | 功能描述 |
|:---|:---|
| 特征中心 | 特征列表、快速注册、表单注册、批量导入、详情查看、编辑、归档、删除 |
| 模型注册 | 模型列表、筛选搜索、新建模型、详情查看、编辑、历史版本对比、归档 |
| 模型回溯 | 回溯记录列表、单次回溯创建、周期回溯创建、详情查看、任务停止、模型信息查看 |
| 模型评估 | 评估概览卡片、评估记录列表、评估得分展示、新建评估、详情查看、删除、筛选搜索、关联模型查看 |
| 任务管理 | 任务统计卡片、任务列表、任务进度、筛选搜索、刷新、自动刷新、详情查看、暂停、继续、停止、删除 |

### 3.2 不包含的功能

- 实时数据接入
- 模型训练
- 在线预测
