## 2. Feature 概述

### 2.1 是什么

模型评估模块负责模型效果的评估分析，提供评估概览、记录查询、得分展示等功能。

### 2.2 解决什么问题

1. **评估不透明**：评估标准和结果不清晰
2. **评估记录分散**：缺乏统一的评估记录管理
3. **关联查看不便**：难以快速关联查看模型信息

### 2.3 用户场景

| 场景 | 用户 | 描述 |
|:---|:---|:---|
| 场景1 | 数据科学家 | 创建评估、分析结果 |
| 场景2 | 风控人员 | 查看评估记录、对比得分 |
| 场景3 | 管理人员 | 了解模型整体质量 |
