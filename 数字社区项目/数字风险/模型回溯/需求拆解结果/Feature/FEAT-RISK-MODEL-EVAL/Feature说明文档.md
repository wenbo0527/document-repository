# FEAT-RISK-MODEL-EVAL - 模型评估

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-RISK-MODEL-EVAL |
| Feature 名称 | 模型评估 |
| 所属 EPIC | EPIC-RISK-MODEL 模型回溯 |
| 所属产品域 | PD-RISK 数字风险 |

## 2. 概述

模型评估管理，对上线模型进行持续监控和评估。

## 3. 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 评估列表检索。**筛选器**：模型名称(模糊)、评估类型(线上评估/线下评估)、评估状态(待评估/评估中/已完成) |
| FP-002 | 页面 | 评估列表。**字段**：模型名称、评估类型(线上/线下)、评估指标、评估分数、环比变化、评估状态(待评估灰/评估中蓝/已完成绿)、评估时间 |
| FP-003 | 页面 | 新建评估。**交互**：点击"新建评估"按钮 |
| FP-004 | 页面 | 执行评估。**交互**：点击"评估"按钮 |
| FP-005 | 页面 | 查看报告。**交互**：点击"报告"按钮，**指标**：准确率、精确率、召回率、F1、AUC、KS值、PSI |
| FP-006 | 页面 | 告警设置。**交互**：点击"告警设置"按钮，设置评估指标告警阈值 |
| FP-007 | 页面 | 评估详情。**内容**：评估配置、评估指标详情、趋势图表 |
| FP-008 | 页面 | 指标趋势图表。**图表**：评估指标历史趋势可视化 |
| FP-009 | 页面 | 告警规则配置。**规则**：指标阈值、告警方式(邮件/短信/站内) |
| FP-010 | 页面 | 列表分页。**交互**：支持分页导航 |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 评估类型正确区分线上评估/线下评估 |
| 功能验收 | 评估状态正确区分待评估(灰)/评估中(蓝)/已完成(绿) |
| 功能验收 | 评估指标正确展示准确率/精确率/召回率/F1/AUC/KS值/PSI |
| 功能验收 | 环比变化正确显示上升/下降 |
| 功能验收 | 告警设置规则正确保存 |
| 功能验收 | 趋势图表正确可视化历史数据 |
| 功能验收 | 列表支持分页 |

## 5. 依赖关系

| 依赖项 | 类型 | 说明 |
|:---|:---|:---|
| FEAT-RISK-MODEL-REGISTER | 上游 | 评估对象为已注册模型 |
