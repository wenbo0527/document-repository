# FEAT-RISK-MODEL-BACKTRACK - 模型回溯

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-RISK-MODEL-BACKTRACK |
| Feature 名称 | 模型回溯 |
| 所属 EPIC | EPIC-RISK-MODEL 模型回溯 |
| 所属产品域 | PD-RISK 数字风险 |

## 2. 概述

模型回溯分析，对历史数据进行模型效果评估。

## 3. 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 回溯列表检索。**筛选器**：任务名称(模糊)、模型下拉、回溯状态(待执行灰/执行中蓝/已完成绿/失败红) |
| FP-002 | 页面 | 回溯列表。**字段**：任务名称、关联模型、回溯时间范围、样本数量、状态(待执行灰/执行中蓝/已完成绿/失败红)、开始时间、完成时间 |
| FP-003 | 页面 | 新建回溯。**表单**：任务名称(必填)、选择模型(必填，下拉)、开始时间(必填)、结束时间(必填)、样本策略(必填：全量/抽样)、抽样比例(抽样时必填) |
| FP-004 | 页面 | 执行回溯/保存草稿。**交互**：点击"执行回溯/保存草稿"按钮 |
| FP-005 | 页面 | 查看结果。**交互**：点击"结果"按钮，查看回溯分析结果 |
| FP-006 | 页面 | 取消任务。**交互**：点击"取消"按钮，仅对执行中任务生效 |
| FP-007 | 页面 | 回溯详情。**内容**：回溯配置、回溯结果、性能指标对比 |
| FP-008 | 页面 | 性能指标对比。**图表**：新旧模型效果对比可视化 |
| FP-009 | 页面 | 执行日志。**交互**：查看回溯执行日志 |
| FP-010 | 页面 | 列表分页。**交互**：支持分页导航 |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 回溯状态正确区分待执行(灰)/执行中(蓝)/已完成(绿)/失败(红) |
| 功能验收 | 新建表单必填校验 |
| 功能验收 | 抽样比例仅在抽样策略时必填 |
| 功能验收 | 执行回溯状态正确更新 |
| 功能验收 | 查看结果正确展示分析报告 |
| 功能验收 | 取消操作仅对执行中任务生效 |
| 功能验收 | 列表支持分页 |

## 5. 依赖关系

| 依赖项 | 类型 | 说明 |
|:---|:---|:---|
| FEAT-RISK-MODEL-REGISTER | 上游 | 回溯对象为已注册模型 |
