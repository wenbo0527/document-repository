# FEAT-RISK-MODEL-REGISTER - 模型注册

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-RISK-MODEL-REGISTER |
| Feature 名称 | 模型注册 |
| 所属 EPIC | EPIC-RISK-MODEL 模型回溯 |
| 所属产品域 | PD-RISK 数字风险 |

## 2. 概述

模型注册管理，支持机器学习模型的注册、训练、发布等全生命周期管理。

## 3. 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 模型列表检索。**筛选器**：模型名称(模糊)、模型类型(分类蓝/回归绿/聚类橙/深度学习紫)、状态(开发中灰/训练中蓝/已上线绿/已下线红) |
| FP-002 | 页面 | 模型列表。**字段**：模型名称(可点击查看详情)、模型类型(分类蓝/回归绿/聚类橙/深度学习紫)、算法框架、特征数量、训练状态、模型版本、状态(开发中灰/训练中蓝/已上线绿/已下线红)、创建时间 |
| FP-003 | 页面 | 新建模型。**表单**：模型名称(必填)、模型类型(必填)、算法框架(必填)、特征选择(多选，必填)、目标变量(必填)、训练集比例(必填，0-1)、描述 |
| FP-004 | 页面 | 训练参数配置。**参数**：学习率、迭代次数、正则化参数、早停策略(开关) |
| FP-005 | 页面 | 保存草稿/开始训练。**交互**：点击"保存草稿/开始训练"按钮 |
| FP-006 | 页面 | 训练模型。**交互**：点击"训练"按钮 |
| FP-007 | 页面 | 上线/下线模型。**交互**：点击"上线/下线"按钮 |
| FP-008 | 页面 | 版本管理。**交互**：点击"版本"按钮 |
| FP-009 | 页面 | 评估模型。**交互**：点击"评估"按钮，跳转评估页面 |
| FP-010 | 页面 | 模型详情。**Tab**：基本信息、特征配置、训练结果(准确率/精确率/召回率/F1/AUC)、性能图表(混淆矩阵/ROC曲线/特征重要性/训练曲线)、版本历史 |
| FP-011 | 页面 | 编辑模型。**交互**：点击"编辑"按钮 |
| FP-012 | 页面 | 重新训练。**交互**：点击"重新训练"按钮 |
| FP-013 | 页面 | 导出模型。**交互**：点击"导出"按钮 |
| FP-014 | 页面 | 复制模型。**交互**：点击"复制"按钮，创建新模型 |
| FP-015 | 页面 | 列表分页。**交互**：支持分页导航 |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 模型类型正确区分分类(蓝)/回归(绿)/聚类(橙)/深度学习(紫) |
| 功能验收 | 状态正确区分开发中(灰)/训练中(蓝)/已上线(绿)/已下线(红) |
| 功能验收 | 新建表单必填校验 |
| 功能验收 | 训练参数配置正确保存 |
| 功能验收 | Tab切换正常 |
| 功能验收 | 性能图表正确展示 |
| 功能验收 | 列表支持分页 |
