# FEAT-RISK-MODEL-FEATURE - 特征中心

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-RISK-MODEL-FEATURE |
| Feature 名称 | 特征中心 |
| 所属 EPIC | EPIC-RISK-MODEL 模型回溯 |
| 所属产品域 | PD-RISK 数字风险 |

## 2. 概述

特征中心管理，支持特征的创建、编辑、版本管理等功能。

## 3. 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 特征列表检索。**筛选器**：特征名称(模糊)、特征类型(数值型/分类型/文本型)、状态(开发中灰/已上线绿/已下线红) |
| FP-002 | 页面 | 特征列表。**字段**：特征编码、特征名称、特征类型(数值/分类/文本)、数据类型、来源表、更新频率、状态(开发中灰/已上线绿/已下线红)、创建时间 |
| FP-003 | 页面 | 新建特征。**表单**：特征编码(必填)、特征名称(必填)、特征类型(必填)、数据类型(必填)、来源表(必填)、来源字段、更新频率(必填)、计算规则SQL、描述 |
| FP-004 | 页面 | 保存草稿/提交上线。**交互**：点击"保存草稿/提交上线"按钮 |
| FP-005 | 页面 | 上线特征。**交互**：点击"上线"按钮 |
| FP-006 | 页面 | 下线特征。**交互**：点击"下线"按钮 |
| FP-007 | 页面 | 版本管理。**交互**：点击"版本"按钮，查看特征版本历史 |
| FP-008 | 页面 | 查看详情。**交互**：点击"详情"按钮，查看特征详细信息 |
| FP-009 | 页面 | 编辑特征。**交互**：点击"编辑"按钮 |
| FP-010 | 页面 | 列表分页。**交互**：支持分页导航 |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 特征类型正确区分数值型/分类型/文本型 |
| 功能验收 | 状态正确区分开发中(灰)/已上线(绿)/已下线(红) |
| 功能验收 | 新建表单必填校验 |
| 功能验收 | 保存草稿和提交上线区分 |
| 功能验收 | 上线/下线操作即时生效 |
| 功能验收 | 版本历史正确展示 |
| 功能验收 | 列表支持分页 |
