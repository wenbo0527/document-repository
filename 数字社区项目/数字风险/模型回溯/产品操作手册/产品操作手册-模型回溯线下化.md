## 一、产品概述

### 1.1 功能简介

模型回溯线下化模块提供三大核心功能：

| 功能 | 说明 |
|:---|:---|
| 特征中心 | 统一管理模型特征，支持快速注册、批量导入、归档管理 |
| 周期回溯 | 配置日/周/月级自动回溯任务，监控执行状态 |
| 一键注册 | 基于模型输出文件快速注册特征 |

## 三、特征中心操作指南

### 3.1 特征注册

#### 快速注册（推荐）

**适用场景**：特征定义简单，字段较少

**操作步骤**：

| 步骤 | 操作 | 说明 |
|:---:|:---|:---|
| 1 | 点击「快速注册」 | 打开快速注册弹窗 |
| 2 | 输入特征名称 | 支持中英文名称 |
| 3 | 选择特征类型 | 原始特征/衍生特征/组合特征 |
| 4 | 上传样本数据 | CSV/Excel 格式，支持拖拽上传 |
| 5 | 点击「注册」 | 完成快速注册 |

**注意事项**：
- 特征编码自动生成，全局唯一
- 样本数据用于特征验证，建议提供 100 条以上

#### 完整表单注册

**适用场景**：特征定义复杂，需要详细配置

**操作步骤**：

| 步骤 | 操作 | 说明 |
|:---:|:---|:---|
| 1 | 点击「完整注册」 | 打开完整表单页面 |
| 2 | 填写基本信息 | 特征编码、名称、类型、描述 |
| 3 | 配置字段映射 | 字段名、字段类型、是否必填 |
| 4 | 设置校验规则 | 非空、唯一、正则表达式 |
| 5 | 配置血缘关系 | 上游数据源、下游模型 |
| 6 | 点击「提交」 | 提交审核 |

### 3.2 批量导入

**适用场景**：批量注册特征

**操作步骤**：

| 步骤 | 操作 | 说明 |
|:---:|:---|:---|
| 1 | 点击「批量导入」 | 打开导入向导 |
| 2 | 下载模板 | 点击「下载模板」获取 Excel 模板 |
| 3 | 填写模板 | 按模板格式填写特征信息 |
| 4 | 上传文件 | 拖拽或点击上传 Excel 文件 |
| 5 | 字段映射 | 确认导入字段与模板字段对应关系 |
| 6 | 预览校验 | 查看导入预览，确认无误后提交 |
| 7 | 执行导入 | 点击「确认导入」，查看导入结果 |

**模板字段说明**：

| 字段名 | 是否必填 | 说明 |
|:---|:---:|:---|
| 特征编码 | 是 | 全局唯一编码 |
| 特征名称 | 是 | 中英文名称 |
| 特征类型 | 是 | 原始/衍生/组合 |
| 数据类型 | 是 | STRING/INT/DOUBLE/DATE |
| 描述 | 否 | 特征说明 |

### 3.3 特征归档

**操作步骤**：

| 步骤 | 操作 | 说明 |
|:---:|:---|:---|
| 1 | 在特征列表点击「归档」 | 针对单条特征操作 |
| 2 | 确认归档 | 弹窗提示归档影响 |
| 3 | 归档成功 | 特征状态变更为「已归档」 |

**归档规则**：
- 被模型引用的特征需先解除引用才能归档
- 归档后特征不可被新模型引用
- 支持归档恢复

## 六、常见问题

### Q1: 特征注册审核需要多长时间？
**A**：一般情况下，审核时间为 1-3 个工作日。如需加急，请联系数据管理员。

### Q2: 批量导入支持的最大数据量是多少？
**A**：单次批量导入最大支持 5000 条特征数据。超出时请分批导入。

### Q3: 回溯任务失败如何处理？
**A**：查看任务日志定位失败原因，修复后点击「重试」重新执行。

### Q4: 一键注册支持哪些文件格式？
**A**：支持 CSV、Parquet 格式的模型输出文件。
