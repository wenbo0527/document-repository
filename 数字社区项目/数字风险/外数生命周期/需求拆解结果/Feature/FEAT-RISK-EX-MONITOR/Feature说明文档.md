# FEAT-RISK-EX-MONITOR - 外数监控中心

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-RISK-EX-MONITOR |
| Feature 名称 | 外数监控中心 |
| 所属 EPIC | EPIC-RISK-EXTERNAL 外数生命周期 |
| 所属产品域 | PD-RISK 数字风险 |

## 2. 概述

外数监控中心页面，提供预算消耗可视化、预警信息展示等功能。

## 3. 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 监控筛选器。**筛选器**：业务类型(助贷/融担/直贷)、平台产品(字节/蚂蚁/京东/美团等)、目标贷余、年份、健康度状态(多选) |
| FP-002 | 页面 | 预算燃尽图。**图表**：预算消耗趋势，**粒度**：月度/季度/年度切换 |
| FP-003 | 页面 | 预警表格。**字段**：业务类型、平台产品、实际放款(超10%标红)、实际费用、年化成本、无风险收益 |
| FP-004 | 页面 | 偏离率高亮。**规则**：费用/成本超标10%+红色高亮+上升图标，收益低于10%+红色+下降图标 |
| FP-005 | 页面 | 导出数据。**交互**：点击"导出数据"按钮 |
| FP-006 | 页面 | 粒度切换。**交互**：月度/季度/年度切换 |
| FP-007 | 页面 | 平台详情。**交互**：点击平台名称打开弹窗 |
| FP-008 | 页面 | 查询/重置。**交互**：点击"查询/重置"按钮 |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|

| 功能验收 | 燃尽图正确可视化预算消耗 |
| 功能验收 | 偏离率高亮规则正确 |
| 功能验收 | 粒度切换即时生效 |
