# FEAT-RISK-EX-SERVICE - 外数数据服务

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-RISK-EX-SERVICE |
| Feature 名称 | 外数数据服务 |
| 所属 EPIC | EPIC-RISK-EXTERNAL 外数生命周期 |
| 所属产品域 | PD-RISK 数字风险 |

## 2. 概述

外数数据服务的管理页面，支持创建和管理各类数据服务。

## 3. 功能清单

### 3.1 服务管理

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 服务列表检索。**筛选器**：供应商下拉、服务类型(API/文件/数据库/平台工具/陪跑计划) |
| FP-002 | 页面 | 新增数据服务。**交互**：两步骤向导，**模板**：online-detail/offline-task/variable-backtrack/file-clean/risk-query/accompany-plan |
| FP-003 | 页面 | 服务列表。**字段**：服务名称、供应商、类型(API蓝/文件绿/数据库橙/平台工具紫/陪跑计划灰)、计费模式(按次/按月/阶梯)、单价、状态(待上线灰/在线绿/维护中橙) |
| FP-004 | 页面 | 模板选择卡片。**交互**：点击选择模板 |
| FP-005 | 页面 | 基础计费配置。**字段**：计费模式(按次/按月/阶梯)、单价、状态、描述 |
| FP-006 | 页面 | 查询/重置。**交互**：点击"查询/重置"按钮 |
| FP-007 | 页面 | 服务详情。**交互**：查看服务详细信息 |
| FP-008 | 页面 | 服务状态管理。**交互**：状态切换(待上线/在线/维护中) |

### 3.2 陪跑计划

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-009 | 页面 | 陪跑列表检索。**筛选器**：陪跑名称(模糊)、状态(进行中绿/已完成蓝/已取消灰) |
| FP-010 | 页面 | 新建陪跑。**交互**：点击"新建陪跑"按钮，**字段**：陪跑名称、关联项目、负责人 |
| FP-011 | 页面 | 编辑陪跑。**交互**：点击"编辑"按钮，修改陪跑配置 |
| FP-012 | 页面 | 取消陪跑。**交互**：点击"取消"按钮，仅能取消进行中的陪跑 |
| FP-013 | 页面 | 结果列表检索。**筛选器**：陪跑名称(模糊)、结果状态(成功/失败/部分成功) |
| FP-014 | 页面 | 查看报告。**交互**：点击"查看报告"按钮，展示执行报告 |
| FP-015 | 页面 | 重新执行。**交互**：点击"重新执行"按钮，重新执行陪跑任务 |

### 3.3 流程化工具配置

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-016 | 页面 | 流程化工具配置。**环节类型**：数据源/SQL处理/Python处理/审批/发布/运维，**操作**：新增、上移、下移、删除环节 |
| FP-017 | 页面 | 环节顺序调整。**交互**：上移/下移调整处理环节顺序 |
| FP-018 | 页面 | 环节配置。**数据源**：主机、数据库、表名；**SQL处理**：标签、SQL语句；**Python处理**：依赖包、脚本 |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 服务类型正确区分5种类型(API/文件/数据库/平台工具/陪跑计划) |
| 功能验收 | 状态正确区分待上线(灰)/在线(绿)/维护中(橙) |
| 功能验收 | 两步骤向导正确引导创建流程 |
| 功能验收 | 模板卡片选择即时生效 |
| 功能验收 | 陪跑列表状态正确区分进行中(绿)/已完成(蓝)/已取消(灰) |
| 功能验收 | 新建/编辑陪跑表单正常 |
| 功能验收 | 取消操作仅对进行中陪跑生效 |
| 功能验收 | 结果状态正确区分成功/失败/部分成功 |
| 功能验收 | 重新执行触发新任务 |
| 功能验收 | 流程化工具环节增删改正常 |
| 功能验收 | 环节顺序调整即时生效 |
