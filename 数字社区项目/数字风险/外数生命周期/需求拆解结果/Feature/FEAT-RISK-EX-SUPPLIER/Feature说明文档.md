# FEAT-RISK-EX-SUPPLIER - 供应商管理

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-RISK-EX-SUPPLIER |
| Feature 名称 | 供应商管理 |
| 所属 EPIC | EPIC-RISK-EXTERNAL 外数生命周期 |
| 所属产品域 | PD-RISK 数字风险 |

## 2. 概述

供应商信息的管理页面，统一管理外部数据供应商的基础信息、联系方式、业务信息等。

## 3. 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 统计卡片。**指标**：供应商总数、活跃供应商(绿)、数据提供商(蓝)、平均信用评级 |
| FP-002 | 页面 | 供应商列表检索。**筛选器**：关键词(模糊)、供应商类型(数据提供商蓝/服务提供商绿/平台提供商橙)、状态(活跃绿/停用灰/暂停橙)、信用评级(1-5星) |
| FP-003 | 页面 | 供应商列表。**字段**：供应商编码、供应商名称(可点击)、类型、状态(活跃绿/停用灰/暂停橙)、信用评级(五星)、联系人、电话、注册时间、标签 |
| FP-004 | 页面 | 新增供应商。**表单**：供应商编码、名称、类型(必填)、信用评级、公司名称、联系人(必填)、邮箱(必填)、电话(必填)、地址、描述、标签 |
| FP-005 | 页面 | 编辑供应商。**交互**：点击"编辑"按钮 |
| FP-006 | 页面 | 启用/停用。**交互**：点击"启用/停用"按钮(确认弹窗) |
| FP-007 | 页面 | 供应商详情抽屉。**内容**：基础信息、联系信息、业务信息(营业执照号、税号、银行信息)、关联产品、状态变更记录 |
| FP-008 | 页面 | 导出数据。**交互**：点击"导出数据"按钮，**格式**：CSV |
| FP-009 | 页面 | 定价档案跳转。**交互**：点击"定价档案"按钮，跳转定价档案管理 |
| FP-010 | 页面 | 查询/重置。**交互**：点击"查询/重置"按钮 |
| FP-011 | 页面 | 供应商类型标签。**颜色**：数据提供商(蓝)、服务提供商(绿)、平台提供商(橙) |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 统计卡片正确展示各项指标 |
| 功能验收 | 类型正确区分数据提供商(蓝)/服务提供商(绿)/平台提供商(橙) |
| 功能验收 | 状态正确区分活跃(绿)/停用(灰)/暂停(橙) |
| 功能验收 | 新增表单必填校验 |
| 功能验收 | 启用/停用需二次确认 |
| 功能验收 | 详情抽屉正确展示信息 |
| 功能验收 | 导出CSV包含正确字段 |
