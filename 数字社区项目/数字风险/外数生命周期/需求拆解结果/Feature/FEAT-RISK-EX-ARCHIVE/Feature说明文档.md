# FEAT-RISK-EX-ARCHIVE - 外数档案管理

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-RISK-EX-ARCHIVE |
| Feature 名称 | 外数档案管理 |
| 所属 EPIC | EPIC-RISK-EXTERNAL 外数生命周期 |
| 所属产品域 | PD-RISK 数字风险 |

## 2. 概述

外部数据产品的生命周期档案管理页面，统一管理数据产品的基础信息、接口配置、供应商关联等。

## 3. 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 档案列表检索。**筛选器**：快速状态(全部/引入中/待完善/已上线/待评估/已归档)、供应商(多选)、状态、使用场景(模糊)、关键词 |
| FP-002 | 页面 | 新建外数。**交互**：点击"新建外数"按钮，**表单**：外数名称、供应商、当前状态、使用场景(多行)、标签 |
| FP-003 | 页面 | 接口配置。**表单**：接口地址(必填)、请求方式(GET/POST) |
| FP-004 | 页面 | 数据要素模型。**表单**：入参定义(参数名、类型、必填、是否要素)、出参定义(参数名、类型、描述) |
| FP-005 | 页面 | 数据存储与血缘。**表单**：落库表名(必填)、查看表字段、查看血缘 |
| FP-006 | 页面 | 档案详情抽屉。**内容**：基础信息、定价信息、月度计价快照、关联采购项目 |
| FP-007 | 页面 | 档案详情页。**Tab**：产品信息、接口技术、落库信息、产品入参、产品出参、调用与费用、评估索引、合同关联、别名信息、档案维护 |
| FP-008 | 页面 | 编辑档案。**交互**：三步骤向导，**步骤**：基础信息 → 接口信息 → 数据存储与血缘 |
| FP-009 | 页面 | 导出列表。**交互**：点击"导出列表"按钮，**格式**：CSV |
| FP-010 | 页面 | 刷新/重置。**交互**：点击"刷新/重置"按钮 |
| FP-011 | 页面 | 查看表字段。**交互**：点击"查看表字段"按钮(打开抽屉) |
| FP-012 | 页面 | 查看血缘。**交互**：点击"查看血缘"按钮(跳转血缘图谱) |
| FP-013 | 页面 | 标签页切换。**Tab**：档案列表Tab/详情Tab |
| FP-014 | 页面 | 产品入参/出参表格。**表格**：参数名、类型、必填、是否要素、描述 |
| FP-015 | 页面 | 月度计价快照。**表格**：月度费用汇总 |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 筛选器正确区分快速状态和精确状态 |
| 功能验收 | 新建表单三步骤必填校验 |
| 功能验收 | 入参/出参表格编辑正常 |
| 功能验收 | 落库表至少保留一个 |
| 功能验收 | 导出CSV包含正确字段 |
| 功能验收 | 查看血缘跳转图谱页面 |
| 功能验收 | 列表支持分页 |
