# FEAT-RISK-EX-LIFECYCLE - 外数生命周期首页

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-RISK-EX-LIFECYCLE |
| Feature 名称 | 外数生命周期首页 |
| 所属 EPIC | EPIC-RISK-EXTERNAL 外数生命周期 |
| 所属产品域 | PD-RISK 数字风险 |

## 2. 概述

外数管理的中枢页面，提供四宫格导航入口、四状态统计卡片、预算燃尽图和待办事项模块。

## 3. 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 四宫格导航。**入口**：预算管理、档案管理、评估中心、服务管理 |
| FP-002 | 页面 | 四状态统计卡片。**指标**：引入中数量、已上线数量、待评估数量、已归档数量 |
| FP-003 | 页面 | 预算燃尽图。**图表**：预算消耗进度可视化，**粒度**：月度/季度切换 |
| FP-004 | 页面 | 待办事项列表。**状态**：待处理(灰)、进行中(橙)、已完成(绿)、失败(红) |
| FP-005 | 页面 | 状态卡片跳转。**交互**：点击状态卡片 → 带状态参数跳转档案页 |
| FP-006 | 页面 | 刷新数据。**交互**：页面加载时自动刷新 |
| FP-007 | 页面 | 快速跳转。**交互**：点击四宫格卡片跳转对应功能页面 |
| FP-008 | 页面 | 燃尽图粒度切换。**交互**：月度/季度切换按钮 |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 四宫格导航正确展示4个入口 |
| 功能验收 | 状态卡片正确展示各状态数量 |
| 功能验收 | 燃尽图正确可视化预算消耗 |
| 功能验收 | 待办列表正确展示任务及状态 |
| 功能验收 | 点击状态卡片跳转档案页并带状态参数 |
| 功能验收 | 粒度切换即时生效 |
