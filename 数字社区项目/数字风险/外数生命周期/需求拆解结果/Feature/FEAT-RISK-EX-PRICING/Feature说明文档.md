# FEAT-RISK-EX-PRICING - 供应商定价档案

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-RISK-EX-PRICING |
| Feature 名称 | 供应商定价档案 |
| 所属 EPIC | EPIC-RISK-EXTERNAL 外数生命周期 |
| 所属产品域 | PD-RISK 数字风险 |

## 2. 概述

供应商产品定价档案的管理页面，支持配置和管理多种计费模式。

## 3. 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 定价档案检索。**筛选器**：供应商下拉、产品编码(模糊)、计费类型(固定单价蓝/阶梯定价绿/量量折扣橙/订阅制紫)、状态(生效绿/失效灰/草稿橙) |
| FP-002 | 页面 | 定价档案列表。**字段**：供应商、产品编码、产品名称、计费类型(固定单价蓝/阶梯定价绿/量量折扣橙/订阅制紫)、计费模式(按次/按条/按GB/按月/按年)、基础单价(4位小数)、币种、生效日期、失效日期、状态(生效绿/失效灰/草稿橙)、税率、结算周期 |
| FP-003 | 页面 | 新增定价档案。**表单**：供应商(必填，下拉)、产品编码(必填)、产品名称(必填)、计费类型(必填)、计费模式(必填)、基础单价(必填，4位小数)、币种、税率、状态、生效日期(必填)、失效日期(必填) |
| FP-004 | 页面 | 编辑定价档案。**交互**：点击"编辑"按钮(产品编码禁用) |
| FP-005 | 页面 | 删除定价档案。**交互**：点击"删除"按钮(确认弹窗) |
| FP-006 | 页面 | 定价详情。**交互**：点击"详情"按钮(打开弹窗) |
| FP-007 | 页面 | 阶梯定价配置。**交互**：当计费类型为阶梯定价时显示阶梯配置表格 |
| FP-008 | 页面 | 结算周期配置。**字段**：结算周期(月度/季度/年度)、付款账期(天数0-365) |
| FP-009 | 页面 | 导出数据。**交互**：点击"导出数据"按钮，**格式**：CSV |
| FP-010 | 页面 | 查询/重置。**交互**：点击"查询/重置"按钮 |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 计费类型正确区分4种类型 |
| 功能验收 | 状态正确区分生效(绿)/失效(灰)/草稿(橙) |
| 功能验收 | 新增表单必填校验(供应商、产品编码、产品名称、计费类型、计费模式、基础单价、生效日期、失效日期) |
| 功能验收 | 编辑时产品编码禁用 |
| 功能验收 | 删除需二次确认 |
| 功能验收 | 阶梯定价配置表格正常 |
| 功能验收 | 导出CSV包含正确字段 |
