## 一、产品概述

### 1.1 产品定位
外部数据生命周期管理提供外部数据的采购、合同、结算、评估、监控等全生命周期管理能力。

### 1.2 核心价值

| 价值 | 说明 |
|:---|:---|
| 全流程管理 | 外部数据从采购到下线的全生命周期管理 |
| 合同管控 | 电子合同签署与管理 |
| 预算控制 | 外部数据预算配置与预警 |
| 质量评估 | 数据质量评估与监控 |
| 合规管理 | 数据合规性管理 |
