## 三、核心理念：档案是外数生命周期的基础

### 3.1 为什么档案是基础？

**外数档案**是外部数据产品的核心实体，承载了产品的所有信息和配置。所有外数相关的能力（服务、调用、评估、结算）都基于档案展开。

```
档案 ──────────────────────────────────────────────────────┐
  │                                                         │
  ├── 基础信息（名称、供应商、用途）                        │
  ├── 技术配置（接口、入参出参）                           │
  ├── 落库配置（表名、字段）                               │
  ├── 合同关联（合同ID）                                  │
  ├── 定价配置（挂在合同下）                               │
  │                                                         │
  └── 生命周期状态 ────────────────────────────────────────┼──→ 服务创建
                                                                ───→ 调用计费
                                                                ───→ 效果评估
                                                                ───→ 预算结算
```

### 3.2 外数生命周期状态

| 状态值 | 显示文本 | 说明 | 支持的核心能力 |
|:---|:---|:---|:---|
| `importing` | 引入中 | 新建档案，初始状态 | 基础信息录入 |
| `pending_tech_profile` | 待完善技术档案 | 技术配置未完成 | 技术信息完善 |
| `online` | 已上线 | 档案完整，可对外服务 | **服务调用、计费结算** |
| `pending_evaluation` | 待评估 | 需要进行质量评估 | 评估分析 |
| `archived` | 已归档 | 归档下线，不再使用 | 历史查询 |

### 4.2 状态变更条件详解

| 当前状态 | 目标状态 | 触发条件 | 触发方式 | 操作要求 |
|:---|:---|:---|:---:|:---|
| **引入中** | **待完善技术档案** | 基础信息补全 | 人工 | 名称✓ + 供应商✓ + 用途✓ |
| **待完善技术档案** | **已上线** | 技术配置 + 价格配置完成 | 系统自动 | 接口地址✓ + 入参✓ + 出参✓ + 落库表✓ + **关联合同✓ + 定价配置✓** |
| **已上线** | **待评估** | 效果异常 | 系统/人工 | 连续3周期未达标 / 业务反馈异常 / 数据一致性问题 |
| **已上线** | **已归档** | 主动归档 | 人工 | 无需条件，可直接归档 |
| **待评估** | **已上线** | 评估通过 | 人工 | 完成评估报告，选择「恢复上线」 |
| **待评估** | **已归档** | 评估不通过 | 人工 | 完成评估报告，选择「归档处理」 |

**说明**：
- 「待完善技术档案 → 已上线」需要**同时满足**：技术配置完成 **且** 价格配置完成
- 价格配置指：关联采购合同 + 合同下有生效的定价配置

#### 状态2：待完善技术档案（Pending Tech Profile）

**说明**：基础信息已完善，还需完成技术配置和价格配置才能上线

**必须完成的技术配置**（满足后触发系统检查价格配置）：

| 信息类别 | 字段 | 必填 | 说明 |
|:---|:---|:---:|:---|
| 接口配置 | 接口地址 | ✅ | API URL |
| | 请求方式 | ✅ | GET/POST |
| 入参定义 | 参数列表 | ✅ | 参数名、类型、必填 |
| 出参定义 | 参数列表 | ✅ | 参数名、类型、描述 |
| 落库配置 | 落库表名 | ✅ | 数据落库的表名 |

**必须完成的价格配置**（系统自动检查）：

| 信息类别 | 字段 | 必填 | 说明 |
|:---|:---|:---:|:---|
| 合同关联 | 关联合同 | ✅ | 选择已有的采购合同 |
| 定价配置 | 生效定价 | ✅ | 合同下有生效的计费配置 |

**可选维护的信息**：

| 信息类别 | 字段 | 说明 |
|:---|:---|:---|
| 技术配置 | Headers | 请求头配置 |
| | 超时时间 | 超时阈值 |
| | QPS限制 | 限流阈值 |
| 落库配置 | 数据格式 | JSON/Parquet/CSV |
| | 更新频率 | 实时/T+1/T+7 |

**此状态支持的操作**：
- ✅ 编辑所有信息
- ✅ 关联采购合同
- ✅ 在合同下配置定价
- ❌ 创建服务（需先上线）
- ❌ 调用接口（需先上线）

**流转条件**：
- 技术配置完成（接口✓ + 入参✓ + 出参✓ + 落库表✓）
- **且** 价格配置完成（关联合同✓ + 生效定价✓）
- → 系统自动流转至"已上线"
