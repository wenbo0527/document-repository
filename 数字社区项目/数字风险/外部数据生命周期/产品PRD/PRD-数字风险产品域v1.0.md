## 一、产品概述

### 1.1 产品定位
数字风险产品域（PD-RISK）为企业提供外部数据生命周期管理、模型回溯和风险控制能力。

### 1.2 核心价值

| 价值 | 说明 |
|:---|:---|
| 外部数据管理 | 外部数据生命周期全流程管理 |
| 模型回溯 | 离线模型分析、回溯版本管理 |
| 风险控制 | 合规检查、风险预警 |
| 调查分析 | 风险事件调查、取证 |

### 1.3 目标用户

- **风控策略师**：管理外部数据、配置风控规则
- **模型工程师**：注册特征、执行回溯、查看结果
- **合规人员**：合规检查、审计追溯
- **调查人员**：风险事件调查、取证分析

## 二、产品架构

PD-RISK 数字风险域包含：

| 模块 | 说明 |
|:---|:---|
| **外部数据生命周期（EPIC-RISK-EXT）** | 外数评估、注册、监控、下线 |
| **模型回溯（EPIC-RISK-MODEL）** | 特征中心、周期回溯、离线分析 |
| **实时决策（EPIC-RISK-DECISION）** | 决策引擎、规则配置、实时评分 |
| **合规管理（EPIC-RISK-COMPLIANCE）** | 合规检查、报告、审计 |
| **调查分析（EPIC-RISK-INVEST）** | 案件管理、取证分析、报告 |
