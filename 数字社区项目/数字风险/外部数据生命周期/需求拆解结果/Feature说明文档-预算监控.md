## 2. Feature 概述

### 2.1 是什么

预算监控模块用于监控和分析整体预算消耗情况，支持按业务类型、平台产品、目标贷余筛选，展示Burn-Down图和预警信息。

### 2.2 解决什么问题

- 预算超支、消耗过慢等异常情况无法及时预警
- 没有打通预警通知的信息闭环
- 缺乏可视化的预算执行分析工具

### 2.3 用户场景

| 场景 | 用户 | 描述 |
|:---|:---|:---|
| 预算执行监控 | 采购管理 | 实时查看预算消耗进度 |
| 异常预警 | 系统 | 低于阈值时触发告警 |
| 归因分析 | 采购管理 | 分析预算差异原因 |

## 3. 功能说明

### 3.1 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-EXT-MON-001 | 页面 | 预算大盘监控（实际使用量/总预算/使用进度） |
| FP-EXT-MON-002 | 页面 | Burn-Down图（预估剩余 vs 实际剩余） |
| FP-EXT-MON-003 | 页面 | 健康度预警模块（正常/超支/消耗过慢） |
| FP-EXT-MON-004 | 页面 | 详情分析（下钻实际消耗） |
| FP-EXT-MON-005 | 页面 | 业务过程比对 |

### 3.2 筛选器

| 筛选项 | 控件类型 | 默认值 |
|:---|:---|:---|
| 业务类型 | 多选框 | 全选 |
| 平台产品 | 多选框（支持搜索） | 全选 |
| 目标贷余 | 单选框 | - |
| 数据月份 | 下拉选择 | - |

### 3.3 时间维度

支持按年/季/月切换

### 3.4 Burn-Down计算规则

| 类型 | 计算逻辑 |
|:---|:---|
| 预估剩余预算 | 总预算 - 累计预算（按月） |
| 实际剩余预算 | 总预算 - 累计实际消耗（按月） |

### 3.5 健康度判定

| 健康度 | 公式 | 说明 |
|:---|:---|:---|
| 正常 | 实际剩余/预估剩余 ∈ [0.9, 1.1] | - |
| 超支 | 实际剩余/预估剩余 > 1.1 | 消耗过快 |
| 消耗过慢 | 实际剩余/预估剩余 < 0.9 | 消耗不足 |

### 3.6 预警规则

当"实际剩余预算"低于"预估剩余预算"的X%时，触发预算超支风险预警
