## 2. EPIC 概述

### 2.1 是什么

外部数据生命周期管理是数字风险产品域的核心模块，覆盖从供应商引入、合同管理、服务交付到结算的全流程数字化管理。

### 2.2 解决什么问题

1. **流程不透明**：外部数据采购和管理流程缺乏统一管理
2. **效率低下**：手动操作多，耗时长
3. **数据分散**：供应商、合同、服务数据分散在不同系统

### 2.3 目标用户

- 采购人员：供应商引入和采购流程
- 风控人员：服务评估和监控
- 财务人员：结算和对账

## 3. 功能范围

### 3.1 包含的功能

| 功能模块 | 功能描述 |
|:---|:---|
| 供应商管理 | 供应商入驻、资质审核、退出管理 |
| 合同管理 | 合同创建、审批、履行、终止 |
| 服务管理 | 服务发起、样本表管理、校验规则 |
| 评估管理 | 服务质量评估、效果分析 |
| 采购管理 | 采购流程、预算管理 |
| 结算管理 | 对账自动化、结算流程 |

### 3.2 不包含的功能

- 内部数据管理
- 实时数据接口
