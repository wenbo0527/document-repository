## 2. Feature 概述

### 2.1 是什么

外数数据服务模块提供3步服务申请流程、样本表管理和审批执行全流程管理。

### 2.2 解决什么问题

- 外数调用流程分散，缺乏统一入口
- 样本表管理不规范，版本混乱
- 审批流程缺乏有效跟踪

### 2.3 用户场景

| 场景 | 用户 | 描述 |
|:---|:---|:---|
| 服务申请 | 业务用户 | 通过3步流程申请外数服务 |
| 样本表管理 | 数据管理员 | 创建/编辑/版本管理样本表 |
| 审批跟踪 | 业务用户 | 查看审批进度和执行结果 |

## 3. 功能说明

### 3.1 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-EXT-SVC-001 | 页面 | 服务场景入口（新增申请卡片） |
| FP-EXT-SVC-002 | 页面 | 3步申请流程（基础信息→样本选择→参数绑定） |
| FP-EXT-SVC-003 | 页面 | 样本表列表与筛选 |
| FP-EXT-SVC-004 | 页面 | 样本表创建/编辑/版本管理 |
| FP-EXT-SVC-005 | 页面 | 审批处理（通过/驳回） |
| FP-EXT-SVC-006 | 页面 | 执行结果查看与重试 |

### 3.2 3步申请流程

| 步骤 | 内容 | 必填项 |
|:---:|:---|:---|
| 步骤1 | 基础信息配置 | 外数产品、团队经理、申请原因 |
| 步骤2 | 样本选择 | 选择已创建的样本表 |
| 步骤3 | 参数绑定配置 | 绑定产品要素与样本字段 |

### 3.3 审批流程

```
发起人团队审批 → 数据团队审批 → 发起人部门审批 → 数据部门审批
     ↓
外数文件放置到指定路径 → 数据确认通知
```

### 3.4 样本表生命周期

| 状态 | 说明 |
|:---|:---|
| 运行中 | 正在执行同步/更新 |
| 已完成 | 执行成功 |
| 运行失败 | 执行异常 |

---

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 3步流程配置完整，步骤间可切换 |
| 功能验收 | 样本表创建/编辑/版本回滚正常 |
| 功能验收 | 审批流程状态正确展示 |
| 功能验收 | 执行结果支持查看/下载/重试 |
| 交互验收 | 样本表选择后展示预览数据 |
