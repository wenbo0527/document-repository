## 2. Feature 概述

### 2.1 是什么

档案配置模块负责外数档案的创建、编辑和状态流转管理，是外数全生命周期管理的核心基础。

### 2.2 解决什么问题

- 档案信息不完整，支撑能力不足
- 缺少对账相关字段
- 未实现元数据规范化管理

### 2.3 用户场景

| 场景 | 用户 | 描述 |
|:---|:---|:---|
| 新建档案 | 数据管理员 | 采购新外数时录入基础信息 |
| 编辑档案 | 数据管理员 | 修改外数配置和关联信息 |
| 状态变更 | 系统 | 自动处理状态流转 |

---

## 3. 功能说明

### 3.1 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-EXT-ARCH-001 | 页面 | 档案列表展示 |
| FP-EXT-ARCH-002 | 页面 | 档案新建/编辑 |
| FP-EXT-ARCH-003 | 页面 | 档案状态流转 |
| FP-EXT-ARCH-004 | 接口 | 档案元数据管理 |

### 3.2 状态流转规则

| 当前状态 | 触发条件 | 状态变更结果 |
|:---|:---|:---|
| 引入中（初始） | 新建档案并提交 | 生成初始档案，状态固定 |
| 引入中→上线中 | 关联生效合同+补充借款+落库表信息 | 开放业务调用权限 |
| 上线中→待评估 | 效果追踪未达标/业务反馈异常/数据问题 | 生成评估待办任务 |
| 待评估→上线中 | 完成评估报告，选择"恢复上线" | 恢复业务权限 |
| 待评估→已归档 | 完成评估报告，选择"归档处理" | 冻结业务权限 |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 支持录入外数基础信息（名称、渠道、供应商） |
| 功能验收 | 状态默认"引入中"，生成初始档案 |
| 功能验收 | 满足条件后状态可流转至"上线中" |
| 功能验收 | 关联合同信息、借款信息完整 |
| 交互验收 | 档案编辑保存后数据实时更新 |
