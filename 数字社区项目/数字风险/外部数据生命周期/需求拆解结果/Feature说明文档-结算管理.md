## 2. Feature 概述

### 2.1 是什么

结算管理模块负责外数费用核算、外部对账、确认核销和完成报销的完整流程管理。

### 2.2 解决什么问题

- 人工对账效率低，易出错
- 名称匹配错误、免费量统计遗漏
- 对账差异追溯困难

### 2.3 用户场景

| 场景 | 用户 | 描述 |
|:---|:---|:---|
| 费用核算 | 采购管理 | 按固定→阶梯→特殊顺序核算费用 |
| 外部对账 | 采购管理 | 上传对账单并匹对内部产品 |
| 核销操作 | 采购管理 | 按合同分笔核销费用 |
| 发起报销 | 财务 | 记录报销单据 |

## 3. 功能说明

### 3.1 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-EXT-SETTLE-001 | 页面 | 结算任务列表（状态筛选） |
| FP-EXT-SETTLE-002 | 页面 | 费用核算（固定→阶梯→特殊） |
| FP-EXT-SETTLE-003 | 页面 | 外部对账（上传对账单/自动匹配） |
| FP-EXT-SETTLE-004 | 页面 | 核销操作（按合同分笔） |
| FP-EXT-SETTLE-005 | 页面 | 发起报销（记录单据） |
| FP-EXT-SETTLE-006 | 接口 | 数据下载（核算清单/对账结果/核销结果） |

### 3.2 结算流程

```
费用核算 → 外部对账 → 确认核销 → 完成报销
    ↓           ↓          ↓         ↓
  待核算     待对账    待核销    待报销/已完成
```

### 3.3 费用核算顺序

| 顺序 | 类型 | 处理方式 |
|:---:|:---|:---|
| 1 | 固定费用产品 | 系统自动计算费用，支持批量确认 |
| 2 | 阶梯定价产品 | 按产品逐个处理，计算公式展示 |
| 3 | 特殊计费产品 | 需人工填写费用金额 |

### 3.4 核销规则

- 按"外数产品"维度分产品核销
- 需关联对应合同分笔完成费用抵扣
- 每次核销金额≤合同剩余可核销费用
- 支持补充备注信息
