## 2. Feature 概述

### 2.1 是什么

外数生命周期总览模块提供外部数据生命周期的整体视图，包括导航卡片、状态统计、预算燃尽图、待办项列表等。

### 2.2 解决什么问题

1. **信息分散**：外部数据各模块信息分散，难以统一查看
2. **状态不透明**：整体状态难以快速掌握
3. **预算不清晰**：预算使用情况难以追踪

### 2.3 用户场景

| 场景 | 用户 | 描述 |
|:---|:---|:---|
| 场景1 | 管理人员 | 查看整体状态 |
| 场景2 | 风控人员 | 了解待办事项 |
| 场景3 | 财务人员 | 监控预算使用 |
