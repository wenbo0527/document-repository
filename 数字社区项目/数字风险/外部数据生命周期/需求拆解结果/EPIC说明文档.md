## 2. EPIC 概述

### 2.1 是什么

外部数据生命周期是数字风险产品域的核心模块，覆盖外部数据的采购合同、结算、评估、监控、归档等全生命周期管理。

### 2.2 解决什么问题

1. **合同管理混乱**：外部数据采购合同缺乏统一管理
2. **结算不透明**：结算流程不规范，难以追踪
3. **评估不透明**：外部数据质量评估缺乏标准
4. **监控缺失**：外部数据使用情况难以追踪
5. **预算失控**：外部数据采购预算难以控制

### 2.3 目标用户

- 数据采购人员：管理外部数据供应商和合同
- 财务人员：管理结算和预算
- 风控人员：评估和监控外部数据质量
- 运维人员：监控系统运行状态

## 3. 功能范围

### 3.1 包含的功能

| 功能模块 | 功能描述 |
|:---|:---|
| 合同管理 | 合同列表、筛选、新建合同、编辑、详情查看、归档 |
| 结算管理 | 结算列表、筛选、新建结算、编辑、详情查看、确认 |
| 外数数据服务 | 服务列表、筛选、发起新服务、服务编辑、服务标签、分页 |
| 外数生命周期总览 | 导航卡片、状态统计、预算燃尽图、待办项列表 |
| 外部数据监控 | 监控状态嵌入档案管理（监控状态字段） |
| 外部数据评估 | 评估报告列表、筛选、创建、详情查看、发布、归档 |
| 档案管理 | 档案列表、快速筛选、高级筛选、导出、刷新、详情、编辑 |
| 预算管理 | 预算列表、筛选、新建、编辑、删除、详情、燃尽图 |

### 3.2 不包含的功能

- 实时数据接入
- 外部数据采购流程（合同走 OA）
- 财务结算系统对接
