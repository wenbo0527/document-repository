## 1. 产品概述

### 1.1 产品简介

外部数据生命周期管理提供外部数据的采购、合同、结算、评估、监控等全生命周期管理能力。

### 1.2 目标用户

| 用户群体 | 角色 | 使用场景 |
|:---|:---|:---|
| 数据管理员 | 全流程统筹管控 | 基础配置、权限分配、数据维护 |
| 采购管理 | 核心业务落地 | 预算监控、合同管理、对账结算 |
| 业务用户 | 需求发起与反馈 | 外数申请、服务使用 |
| 访客用户 | 公开信息浏览 | 查看公开信息 |

### 1.3 功能概览

| 功能模块 | 说明 |
|:---|:---|
| 生命周期总览 | 统一入口，展示KPI、状态统计、待办 |
| 档案管理 | 外数档案的创建/编辑/状态流转 |
| 预算管理 | 预算录入/监控/Burn-Down图 |
| 合同管理 | 合同上传/计费配置/状态管理 |
| 结算管理 | 费用核算/外部对账/核销/报销 |
| 外数评估 | 质量评估/报告生成 |

## 3. 操作指南

### 3.1 生命周期总览

#### 3.1.1 功能入口

**菜单位置**：数字风险 → 外数生命周期管理

#### 3.1.2 操作步骤

| 步骤 | 操作 | 说明 |
|:---:|:---|:---|
| 1 | 登录系统 | 进入数字风险模块 |
| 2 | 点击"外数生命周期管理" | 进入默认首页 |
| 3 | 查看KPI卡片 | 了解外数整体运行状态 |
| 4 | 查看待办列表 | 处理待办任务 |
| 5 | 点击快捷入口 | 跳转至各功能模块 |

---

### 3.2 档案管理

#### 3.2.1 功能入口

**菜单位置**：数字风险 → 外数生命周期管理 → 档案管理

#### 3.2.2 操作步骤

| 步骤 | 操作 | 说明 |
|:---:|:---|:---|
| 1 | 点击"新建档案" | 进入档案创建页面 |
| 2 | 填写基本信息 | 输入外数名称、渠道、供应商 |
| 3 | 关联合同 | 选择已生效的采购合同 |
| 4 | 补充借款信息 | 输入目标贷余、预估放款 |
| 5 | 补充落库表信息 | 配置存储位置、字段映射 |
| 6 | 提交保存 | 系统自动流转状态 |

#### 3.2.3 状态流转规则

| 当前状态 | 触发条件 | 结果 |
|:---|:---|:---|
| 引入中 | 新建档案提交 | 状态固定为此 |
| 引入中→上线中 | 关联生效合同+借款+落库表 | 开放业务调用权限 |
| 上线中→待评估 | 效果追踪未达标 | 生成评估待办 |
| 待评估→上线中/已归档 | 完成评估报告 | 恢复/冻结权限 |

---

### 3.3 预算管理

#### 3.3.1 功能入口

**菜单位置**：数字风险 → 外数生命周期管理 → 预算管理

#### 3.3.2 操作步骤（预算录入）

| 步骤 | 操作 | 说明 |
|:---:|:---|:---|
| 1 | 点击"预算配置" | 进入预算配置页 |
| 2 | 点击"上传预算" | 下载模板填写 |
| 3 | 填写预算数据 | 按字段要求填写 |
| 4 | 上传文件 | 系统解析并校验 |
| 5 | 确认提交 | 记录操作日志 |

**必填字段**：业务类型、平台产品、目标贷余、预估放款、预估费用、年化数据成本、无风险收益、预算粒度、对应时间

#### 3.3.3 操作步骤（预算监控）

| 步骤 | 操作 | 说明 |
|:---:|:---|:---|
| 1 | 点击"预算监控" | 查看监控看板 |
| 2 | 切换时间维度 | 年/季/月 |
| 3 | 筛选条件 | 业务类型/平台产品/目标贷余 |
| 4 | 查看Burn-Down图 | 对比预估vs实际剩余 |
| 5 | 查看健康度 | 正常/超支/消耗过慢 |

---

### 3.4 合同管理

#### 3.4.1 功能入口

**菜单位置**：数字风险 → 外数生命周期管理 → 合同管理

#### 3.4.2 操作步骤

| 步骤 | 操作 | 说明 |
|:---:|:---|:---|
| 1 | 点击"新建合同" | 选择合同类型 |
| 2 | 上传合同文件 | word/pdf格式 |
| 3 | 填写合同信息 | 名称/编号/金额/日期 |
| 4 | 配置计费方式 | 固定/阶梯/特殊 |
| 5 | 关联外数产品 | 配置每个产品的计费 |
| 6 | 提交生效 | 合同状态变为"生效" |

#### 3.4.3 计费配置说明

| 类型 | 配置说明 |
|:---|:---|
| 固定单价 | 输入固定金额，保留4位小数 |
| 阶梯计费 | 设置用量区间和对应单价 |
| 特殊计费 | 人工填写金额，需核销 |

---

### 3.5 结算管理

#### 3.5.1 功能入口

**菜单位置**：数字风险 → 外数生命周期管理 → 结算管理

#### 3.5.2 结算流程

```
费用核算 → 外部对账 → 确认核销 → 完成报销
    ↓           ↓          ↓         ↓
  待核算      待对账     待核销    待报销/已完成
```

#### 3.5.3 操作步骤

| 阶段 | 操作 | 说明 |
|:---|:---|:---|
| 1 | 发起结算任务 | 选择供应商和结算周期 |
| 2 | 费用核算 | 按固定→阶梯→特殊顺序处理 |
| 3 | 外部对账 | 上传对账单，系统自动匹配 |
| 4 | 确认核销 | 按合同分笔核销费用 |
| 5 | 发起报销 | 记录报销单号和付款日期 |

## 4. 注意事项

| 注意事项 | 说明 |
|:---|:---|
| 预算上传需权限 | 独立权限控制，需申请 |
| 合同状态不可逆 | 完结/中止后无法修改 |
| 核销金额限制 | ≤合同剩余可核销费用 |
| 操作日志追溯 | 所有操作自动记录 |

## 5. 常见问题FAQ

| 问题 | 解决方案 |
|:---|:---|
| 样本验证失败 | 检查接口配置，确认网络连通性 |
| 告警未触发 | 检查告警规则配置，确认通知渠道可用 |
| 对账不平 | 核对调用记录和账单，联系供应商 |
| 预算无法上传 | 检查必填字段，确认权限 |
| 合同无法关联 | 确认合同状态为"生效" |
