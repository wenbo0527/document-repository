## 一、产品概述

外部数据生命周期管理模块用于管理企业外部数据的全生命周期，包括评估、注册、监控、合同管理和服务管理。

---

## 二、功能说明

### 2.1 外数评估

#### 操作步骤

1. **进入评估页面**
   - 路径：数字风险 → 外部数据 → 评估管理
   - 点击「新建评估」按钮

2. **填写评估表单**
   - 选择供应商
   - 选择数据项
   - 上传样本数据
   - 填写评估说明

3. **提交审批**
   - 点击「提交审批」按钮
   - 选择审批人
   - 等待审批通过

4. **查看评估报告**
   - 审批通过后自动生成报告
   - 可下载 PDF 版本

#### 注意事项

- 样本数据大小不超过 10MB
- 评估流程可配置
- 评估报告可自定义模板

---

### 2.2 外数注册

#### 操作步骤

1. **进入注册页面**
   - 路径：数字风险 → 外部数据 → 注册管理
   - 点击「新建注册」按钮

2. **填写注册信息**
   - 基本信息（名称、类型、描述）
   - 接口配置（URL、认证方式、参数）
   - 更新频率配置

3. **样本验证**
   - 点击「验证」按钮
   - 系统自动获取样本数据
   - 验证数据格式和内容

4. **提交注册**
   - 点击「提交」按钮
   - 等待审批通过
   - 注册完成后即可使用

---

### 2.3 外数监控

#### 操作步骤

1. **进入监控看板**
   - 路径：数字风险 → 外部数据 → 监控看板
   - 默认展示所有外数的关键指标

2. **查看详情**
   - 点击外数卡片
   - 进入详情页面
   - 查看详细监控数据

3. **配置告警**
   - 点击「配置告警」按钮
   - 设置阈值（调用量、延迟、错误率）
   - 选择通知渠道

4. **查看历史趋势**
   - 选择时间范围
   - 查看指标趋势图
   - 导出数据报表

---

### 2.4 合同管理

#### 操作步骤

1. **进入合同管理**
   - 路径：数字风险 → 外部数据 → 合同管理
   - 点击「新建合同」按钮

2. **填写合同信息**
   - 供应商信息
   - 合同金额
   - 合同期限
   - 结算方式

3. **对账操作**
   - 点击「对账」按钮
   - 选择对账周期
   - 确认对账结果

4. **结算操作**
   - 点击「结算」按钮
   - 发起结算审批
   - 审批通过后完成结算

## 三、常见问题

| 问题 | 解决方案 |
|:---|:---|
| 样本验证失败 | 检查接口配置是否正确，确认网络连通性 |
| 告警未触发 | 检查告警规则配置，确认通知渠道可用 |
| 对账不平 | 核对调用记录和账单，如有疑问联系供应商 |
