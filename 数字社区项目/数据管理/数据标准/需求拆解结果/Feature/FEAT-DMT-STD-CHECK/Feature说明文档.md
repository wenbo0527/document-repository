# FEAT-DMT-STD-CHECK - 标准稽核管理

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-DMT-STD-CHECK |
| Feature 名称 | 标准稽核管理 |
| 所属 EPIC | EPIC-DMT-STD 数据标准治理 |
| 所属产品域 | PD-DMT 数据管理 |

## 2. 概述

### 2.1 是什么
数据标准执行情况的稽核检查，发现不符合标准的数据。

### 2.2 解决什么问题
- 不知道数据是否符合标准
- 缺乏自动化的标准检查

## 3. 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 稽核任务检索，按名称模糊匹配。**筛选器**：稽核任务名称文本(模糊匹配)、稽核类型下拉(命名规范/代码规范/完整性)、状态下拉(运行中/已完成/失败) |
| FP-002 | 页面 | 新建任务，创建新的稽核任务。**交互**：点击"新建"按钮弹出表单 |
| FP-003 | 页面 | 立即执行，立即执行稽核。**交互**：点击"立即执行"按钮 |
| FP-004 | 页面 | 查看报告，查看稽核报告。**交互**：点击"查看报告"按钮，**数据**：问题数量、严重程度(高/中/低) |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 稽核任务检索支持名称模糊匹配 |
| 功能验收 | 类型筛选正确区分命名规范/代码规范/完整性 |
| 功能验收 | 立即执行触发稽核任务 |
| 功能验收 | 报告展示问题数量和严重程度 |
| 功能验收 | 列表支持分页 |

## 5. 依赖关系

|:---|:---|:---|
