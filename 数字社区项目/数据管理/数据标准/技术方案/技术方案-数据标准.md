## 三、数据库设计

### 3.1 数据标准表 (data_standard)

```sql
CREATE TABLE data_standard (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    std_code VARCHAR(64) NOT NULL UNIQUE,
    std_name VARCHAR(128) NOT NULL,
    std_type VARCHAR(32) NOT NULL COMMENT 'CODE/NAME/FORMAT/DOMAIN',
    std_category VARCHAR(64) COMMENT '标准分类',
    std_rule TEXT NOT NULL COMMENT '标准规则',
    std_version INT DEFAULT 1,
    status VARCHAR(32) DEFAULT 'DRAFT',
    creator_id BIGINT,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_std_code (std_code),
    INDEX idx_std_type (std_type)
) COMMENT='数据标准表';
```

### 3.2 标准映射表 (standard_mapping)

```sql
CREATE TABLE standard_mapping (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    mapping_code VARCHAR(64) NOT NULL UNIQUE,
    std_code VARCHAR(64) NOT NULL,
    data_code VARCHAR(64) NOT NULL COMMENT '数据编码',
    data_type VARCHAR(32) COMMENT '数据类型',
    mapping_rule TEXT COMMENT '映射规则',
    status VARCHAR(32) DEFAULT 'ACTIVE',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_mapping_code (mapping_code),
    INDEX idx_std_code (std_code)
) COMMENT='标准映射表';
```

### 3.3 标准检查表 (standard_check)

```sql
CREATE TABLE standard_check (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    check_code VARCHAR(64) NOT NULL UNIQUE,
    std_code VARCHAR(64) NOT NULL,
    check_type VARCHAR(32) NOT NULL COMMENT 'AUTO/MANUAL',
    check_result VARCHAR(32) COMMENT 'PASS/FAIL',
    check_detail TEXT,
    check_time DATETIME,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_check_code (check_code),
    INDEX idx_std_code (std_code)
) COMMENT='标准检查表';
```
