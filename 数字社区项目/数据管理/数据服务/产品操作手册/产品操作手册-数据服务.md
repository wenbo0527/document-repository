## 四、常见问题

### Q1: 如何调用数据服务？
**A**：订阅服务后获取 API Key，使用 HTTP 请求调用服务接口，传入必要的认证参数。

### Q2: 服务调用失败怎么办？
**A**：检查 API Key 是否有效、参数是否正确、网络是否通畅，查看调用日志排查具体原因。
