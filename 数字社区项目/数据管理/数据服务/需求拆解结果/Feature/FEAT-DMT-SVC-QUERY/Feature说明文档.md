# FEAT-DMT-SVC-QUERY - 明细查询服务管理

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-DMT-SVC-QUERY |
| Feature 名称 | 明细查询服务管理 |
| 所属 EPIC | EPIC-DMT-SVC 数据服务管理 |
| 所属产品域 | PD-DMT 数据管理 |

## 2. 概述

### 2.1 是什么
明细数据查询服务的管理，支持创建和管理数据查询接口。

### 2.2 解决什么问题
- 查询服务缺乏统一管理
- 难以追踪服务调用情况

## 3. 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 服务检索，按名称模糊匹配。**筛选器**：服务名称文本(模糊匹配)、服务类型下拉(实时查询/批量查询)、状态下拉(运行中/已停止) |
| FP-002 | 页面 | 新建服务，创建新的查询服务。**交互**：点击"新建"按钮弹出表单，**必填**：服务名称、服务类型、数据源、SQL模板 |
| FP-003 | 页面 | 启动/停止服务，控制服务状态。**交互**：点击"启动/停止"按钮，**状态**：运行中/已停止 |
| FP-004 | 页面 | 测试服务，测试服务可用性。**交互**：点击"测试"按钮，**结果**：成功/失败+错误信息 |
| FP-005 | 页面 | 删除服务，删除查询服务。**交互**：点击"删除"按钮，**确认**：需二次确认 |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 服务检索支持名称模糊匹配 |
| 功能验收 | 类型筛选正确区分实时查询/批量查询 |
| 功能验收 | 新建服务必填：服务名称、服务类型、数据源、SQL模板 |
| 功能验收 | 启动/停止即时生效 |
| 功能验收 | 测试服务返回成功/失败结果 |
| 功能验收 | 删除需二次确认 |
| 功能验收 | 列表支持分页 |
