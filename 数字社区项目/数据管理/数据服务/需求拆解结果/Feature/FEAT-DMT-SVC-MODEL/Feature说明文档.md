# FEAT-DMT-SVC-MODEL - 数据服务模型管理

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-DMT-SVC-MODEL |
| Feature 名称 | 数据服务模型管理 |
| 所属 EPIC | EPIC-DMT-SVC 数据服务管理 |
| 所属产品域 | PD-DMT 数据管理 |

## 2. 概述

### 2.1 是什么
数据服务模型的管理，支持创建和管理数据服务模型。

### 2.2 解决什么问题
- 数据模型缺乏统一管理
- 模型执行状态不透明

## 3. 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 模型检索，按名称模糊匹配。**筛选器**：模型名称文本(模糊匹配)、模型类型下拉(SQL模型/Python模型)、状态下拉(开发中/已上线/已下线) |
| FP-002 | 页面 | 新建模型，创建新的数据模型。**交互**：点击"新建"按钮弹出表单，**必填**：模型名称、模型类型、数据源 |
| FP-003 | 页面 | 上线模型，上线数据模型。**交互**：点击"上线"按钮 |
| FP-004 | 页面 | 下线模型，下线数据模型。**交互**：点击"下线"按钮，**确认**：需二次确认 |
| FP-005 | 页面 | 执行模型，立即执行模型。**交互**：点击"执行"按钮，**结果**：执行成功/失败 |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 模型检索支持名称模糊匹配 |
| 功能验收 | 类型筛选正确区分SQL模型/Python模型 |
| 功能验收 | 状态筛选正确区分开发中/已上线/已下线 |
| 功能验收 | 新建模型必填：模型名称、模型类型、数据源 |
| 功能验收 | 上线/下线即时生效 |
| 功能验收 | 执行模型返回执行结果 |
| 功能验收 | 列表支持分页 |
