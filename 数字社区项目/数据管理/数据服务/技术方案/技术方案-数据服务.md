## 三、数据库设计

### 3.1 服务表 (data_service)

```sql
CREATE TABLE data_service (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    service_code VARCHAR(64) NOT NULL UNIQUE,
    service_name VARCHAR(128) NOT NULL,
    service_type VARCHAR(32) NOT NULL COMMENT 'API/QUERY/FILE',
    service_desc TEXT,
    endpoint VARCHAR(256) COMMENT '服务地址',
    status VARCHAR(32) DEFAULT 'DRAFT',
    owner_id BIGINT,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_service_code (service_code),
    INDEX idx_status (status)
) COMMENT='数据服务表';
```

### 3.2 服务订阅表 (service_subscription)

```sql
CREATE TABLE service_subscription (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    sub_code VARCHAR(64) NOT NULL UNIQUE,
    service_code VARCHAR(64) NOT NULL,
    subscriber_id BIGINT NOT NULL,
    api_key VARCHAR(128) COMMENT '调用凭证',
    status VARCHAR(32) DEFAULT 'PENDING',
    expire_time DATETIME,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_sub_code (sub_code),
    INDEX idx_service_code (service_code)
) COMMENT='服务订阅表';
```

### 3.3 调用记录表 (invoke_record)

```sql
CREATE TABLE invoke_record (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    invoke_code VARCHAR(64) NOT NULL UNIQUE,
    service_code VARCHAR(64) NOT NULL,
    subscriber_id BIGINT NOT NULL,
    request_params JSON,
    response_data JSON,
    status VARCHAR(32) COMMENT 'SUCCESS/FAIL',
    error_code VARCHAR(64),
    duration_ms INT COMMENT '耗时毫秒',
    invoke_time DATETIME,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_invoke_code (invoke_code),
    INDEX idx_service_code (service_code),
    INDEX idx_invoke_time (invoke_time)
) COMMENT='调用记录表';
```
