## 一、产品概述

### 1.1 产品定位
数据管理产品域（PD-DMT）提供企业级元数据管理和数据服务能力。

### 1.2 核心价值

| 价值 | 说明 |
|:---|:---|
| 管理 | 元数据统一管理（采集、存储、检索） |
| 血缘 | 数据血缘追踪（关系构建、图谱展示） |
| 服务 | 统一数据服务（查询、导出、订阅、同步） |
| 质量 | 数据质量保障（规则、检测、报告） |

### 1.3 目标用户

- **数据架构师**：元数据规划、血缘设计
- **数据开发**：数据服务调用、数据同步
- **数据分析师**：数据获取、数据订阅
- **数据管理者**：元数据质量、数据标准

## 二、产品架构

PD-DMT 数据管理域包含：

| 模块 | 说明 |
|:---|:---|
| **元数据管理（EPIC-DMT-META）** | 元数据采集、元数据存储、元数据血缘、元数据检索 |
| **数据服务（EPIC-DMT-SVC）** | 数据查询、数据导出、数据订阅、数据同步 |
