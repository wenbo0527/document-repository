## 三、数据库设计

### 3.1 元数据表 (metadata)

```sql
CREATE TABLE metadata (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    meta_code VARCHAR(64) NOT NULL UNIQUE,
    meta_name VARCHAR(128) NOT NULL,
    meta_type VARCHAR(32) NOT NULL COMMENT 'TABLE/COLUMN/PROCESS/API',
    data_source VARCHAR(64) COMMENT '数据源',
    description TEXT,
    status VARCHAR(32) DEFAULT 'ACTIVE',
    version INT DEFAULT 1,
    creator_id BIGINT,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_meta_code (meta_code),
    INDEX idx_meta_type (meta_type)
) COMMENT='元数据表';
```

### 3.2 血缘关系表 (metadata_lineage)

```sql
CREATE TABLE metadata_lineage (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    source_meta VARCHAR(64) NOT NULL,
    target_meta VARCHAR(64) NOT NULL,
    lineage_type VARCHAR(32) NOT NULL COMMENT 'TABLE_COL/ETL/FLOW',
    transform_rule TEXT,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_source (source_meta),
    INDEX idx_target (target_meta)
) COMMENT='血缘关系表';
```

### 3.3 质量检查表 (quality_check)

```sql
CREATE TABLE quality_check (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    check_code VARCHAR(64) NOT NULL UNIQUE,
    meta_code VARCHAR(64) NOT NULL,
    check_rule TEXT NOT NULL COMMENT '检查规则',
    check_result VARCHAR(32) COMMENT 'PASS/FAIL',
    check_detail TEXT,
    check_time DATETIME,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_check_code (check_code),
    INDEX idx_meta_code (meta_code)
) COMMENT='质量检查表';
```
