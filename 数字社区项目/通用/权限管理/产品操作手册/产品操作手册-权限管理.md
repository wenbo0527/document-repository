## 一、产品概述

权限管理提供社区用户的权限配置和管理能力，支持角色、权限组、访问控制等功能。

### 1.1 核心功能

| 功能 | 说明 |
|:---|:---|
| 角色管理 | 创建和管理角色 |
| 权限配置 | 配置角色权限 |
| 用户分配 | 分配用户角色 |
| 访问控制 | 设置访问权限 |

## 三、常见操作

### 3.1 创建角色

| 步骤 | 操作 | 说明 |
|:---:|:---|:---|
| 1 | 点击「创建角色」 | 打创建页面 |
| 2 | 填写角色信息 | 名称、描述 |
| 3 | 配置角色权限 | 选择权限项 |
| 4 | 保存角色 | 完成创建 |

### 3.2 分配用户角色

| 步骤 | 操作 | 说明 |
|:---:|:---|:---|
| 1 | 选择目标用户 | 从用户列表选择 |
| 2 | 分配角色 | 选择对应角色 |
| 3 | 设置有效期 | 可选设置有效期 |
| 4 | 确认分配 | 保存配置 |
