## 三、数据库设计

### 3.1 通知表 (notification)

```sql
CREATE TABLE notification (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    notif_code VARCHAR(64) NOT NULL UNIQUE,
    notif_type VARCHAR(32) NOT NULL COMMENT 'SYSTEM/USER/TASK',
    title VARCHAR(256) NOT NULL,
    content TEXT NOT NULL,
    sender_id BIGINT,
    receiver_id BIGINT NOT NULL,
    channel VARCHAR(32) NOT NULL COMMENT 'SMS/EMAIL/INAPP',
    status VARCHAR(32) DEFAULT 'PENDING',
    send_time DATETIME,
    read_time DATETIME,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_notif_code (notif_code),
    INDEX idx_receiver_id (receiver_id)
) COMMENT='通知表';
```

### 3.2 通知模板表 (notification_template)

```sql
CREATE TABLE notification_template (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    template_code VARCHAR(64) NOT NULL UNIQUE,
    template_name VARCHAR(128) NOT NULL,
    channel VARCHAR(32) NOT NULL,
    template_content TEXT NOT NULL,
    variables JSON COMMENT '模板变量',
    status VARCHAR(32) DEFAULT 'ACTIVE',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_template_code (template_code)
) COMMENT='通知模板表';
```
