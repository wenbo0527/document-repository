## 一、产品概述

### 1.1 产品定位
内容管理是数字社区产品域的核心组成部分，提供社区内容的创建、编辑、审核和发布能力。

### 1.2 核心价值

| 价值 | 说明 |
|:---|:---|
| 高效创作 | 丰富的创作工具 |
| 规范审核 | 合规的内容审核 |
| 便捷管理 | 统一的内容管理 |
