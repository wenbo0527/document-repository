## 1. 产品域概述

### 1.1 基本信息

| 字段 | 内容 |
|:---|:---|
| 产品域 ID | PD-COM |
| 产品域名称 | 通用 |
| 英文名 | Common / Portal |
| 所属业务线 | 企业数字化 |
| 产品负责人 | Tony Stark |
| 创建日期 | 2026-04-24 |

### 1.2 产品域定位

**基础层** - 企业数字社区的统一门户和基础能力支撑

PD-COM 是面向企业内部数字化的通用能力平台，提供统一门户入口、权限管理、通知消息和内容运营等基础能力，支撑各业务域的公共需求。

### 1.3 核心价值

| 价值维度 | 说明 |
|:---|:---|
| 用户价值 | 统一入口体验，一站式访问所有业务应用 |
| 业务价值 | 统一权限和认证体系，保障系统安全 |
| 技术价值 | 公共服务复用，避免重复建设 |

### 1.4 覆盖业务场景

1. 场景1：统一门户登录和工作台配置
2. 场景2：应用权限和角色管理
3. 场景3：系统通知和消息推送
4. 场景4：社区内容发布和运营

## 2. 产品架构

### 2.1 产品层级结构

```
PD-COM 通用
├── EPIC-COM-PORTAL 门户管理
├── EPIC-COM-PERM 权限管理
├── EPIC-COM-NOTICE 通知管理
└── EPIC-COM-CONTENT 内容管理
```

### 2.2 技术架构

| 层级 | 技术选型 | 说明 |
|:---|:---|:---|
| 前端 | Vue3 + Vite | 统一技术栈 |
| 后端 | Java/Node.js | 微服务架构 |
| 数据库 | MySQL | 关系数据存储 |
| 缓存 | Redis | 热点数据缓存 |
| 消息队列 | Kafka | 消息通知驱动 |

### 2.3 菜单结构

| 菜单名称 | 路由地址 | 说明 |
|:---|:---|:---|
| 门户管理 | /portal | 统一门户配置 |
| 权限管理 | /permission | 角色和权限配置 |
| 通知管理 | /notice | 消息通知配置 |
| 内容管理 | /content | 内容发布运营 |
