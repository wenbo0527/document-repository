## 2. FP 清单

### FP-MKT-REACH-ANAL-001 触达分析

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-ANAL-001 |
| 功能点名称 | 触达分析 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：展示今日触达数据概览和策略执行任务明细，实时监控触达系统运行状态。

**操作步骤**：

1. 进入触达首页，自动加载今日触达数据概览
2. 查看关键指标卡片：今日触达数、已工作触达数、下发占比等
3. 进入任务明细列表，支持多条件筛选：
   - MA任务ID（精确匹配）
   - 任务执行批次号（精确匹配）
   - 执行日期（日期范围选择）
   - 触达类型（实时/批量下拉）
   - 状态（策略执行完成/失败/执行中/数据准备中/批量任务执行取消）
4. 点击"查询"执行筛选，点击"重置"清空条件
5. 查看任务列表字段：策略ID、MA任务名称、MA任务ID、任务执行批次、触达类型、成功率、状态、预警标识
6. 点击"失败详情"按钮查看策略执行失败的详细原因（弹窗）
7. 状态颜色标识：策略执行完成（绿色）、策略执行失败（红色）、策略执行中（蓝色）、数据准备中（浅蓝色）、批量任务执行取消（灰色）

**输入字段**：MA任务ID、任务执行批次、执行日期、触达类型、状态

**输出字段**：策略ID、MA任务名称、MA任务ID、任务执行批次、触达类型、成功率（不统计显示"-"）、状态、预警标识（成功率低于阈值时显示黄色感叹号）、失败原因

**业务规则**：

- 成功率计算：成功下发数/总下发数×100%，小于100条数据时不统计，显示"-"或"不统计"
- 成功率预警阈值可配置，默认阈值为20%（低于此值显示预警标识）
- 列表按执行时间倒序排列（最新的任务显示在最前面）
- 失败详情仅在状态为"失败"时可用

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 今日触达数=所有渠道今日触达量之和；下发占比=今日下发成功数/今日下发总数×100% |
| 操作验收 | 首页加载时间<3秒；失败详情弹窗可关闭；翻页/筛选后保持排序一致性 |
| 数据验收 | MA任务ID精确查询返回唯一结果；批次号精确查询无遗漏；成功率低于20%时预警标识正确显示 |
| 交互验收 | 关键指标卡片数字变化时有数字滚动动画；状态筛选下拉包含全部5种状态；触达类型包含"全部/实时/批量" |

### FP-MKT-REACH-ANAL-002 转化分析

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-ANAL-002 |
| 功能点名称 | 转化分析 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：查询触达记录明细，支持多条件筛选查看触达转化数据。

**操作步骤**：

1. 进入触达查询明细页面
2. 查询条件：姓名（模糊匹配）、手机号码（模糊匹配）、模板ID（模糊匹配）、通话时长（秒，精确/模糊）、触达通道（短信/AI外呼/人工外呼下拉）、厂商（自营/阿里云/腾讯云/百应/九四下拉）、触达类型、触达状态（成功/失败/待处理下拉）
3. 点击"查询"执行筛选，点击"重置"清空条件
4. 查看触达明细列表字段：触达对象、手机号码（脱敏）、触达类型、模板ID、外部模板ID、通话时长（秒，短信显示"-"）、对话录音（AI/人工外呼显示播放按钮）、触达通道、厂商、触达状态、详细信息（查看详情入口）、触达时间
5. 点击"播放"按钮播放外呼通话录音（弹窗播放器）
6. 点击"查看详情"跳转到单条触达记录详情页（新窗口）
7. 触达状态颜色：成功（绿色）、失败（红色）、待处理（橙色）

**输入字段**：姓名、手机号码、模板ID、通话时长、触达通道、厂商、触达类型、触达状态

**输出字段**：触达对象、手机号码（脱敏138****8000）、触达类型、模板ID、外部模板ID、通话时长（秒，null显示"-"）、对话录音URL、触达通道、厂商、触达状态、触达时间

**业务规则**：

- 手机号码脱敏规则：中间4位脱敏，例：13812348000→138****8000
- 录音仅AI外呼和人工外呼有，短信触达记录无录音字段
- 列表默认按触达时间倒序排列
- 通话时长单位为秒，短信触达记录该字段显示"-"而非空值

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 姓名"张"查询返回所有姓张的触达记录；手机号138开头查询返回所有138开头号码的记录 |
| 操作验收 | 播放录音按钮点击后弹窗<300ms打开；重置后立即清空所有筛选条件；分页不丢失筛选状态 |
| 数据验收 | 手机号13812348000显示为138****8000（非138****2367）；失败状态记录数+成功状态记录数+待处理记录数=列表总记录数 |
| 交互验收 | 录音播放弹窗有关闭按钮（X）和遮罩点击关闭；触达时间格式为YYYY-MM-DD HH:mm:ss；列表支持列宽拖拽调整 |

### FP-MKT-REACH-ANAL-003 ROI分析

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-ANAL-003 |
| 功能点名称 | ROI分析 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：查看策略数据概览的ROI统计，支持按触达类型、供应商、任务多级聚合分析投入产出比。

**操作步骤**：

1. 进入策略数据概览页面（树形结构）
2. 第一级按触达类型聚合：短信（阿里云/腾讯云）、AI外呼（百应/九四）、人工外呼（人工电销）
3. 第二级按供应商聚合，展示各供应商的投入产出数据
4. 第三级按具体任务和批次展示
5. 各层级统计字段：下发成功率、触达成功数、触达成功率、触达失败数
6. 支持条件筛选：触达类型、供应商、任务ID、批次ID、任务下发时间范围
7. 点击"展开/收起"控制树形层级显示
8. 点击"详情"跳转到触达明细查询页面

**输入字段**：触达类型、供应商、任务ID、批次ID、任务下发时间范围

**输出字段**：触达类型、供应商名称、任务ID、批次ID、下发成功率、触达成功数、触达成功率、触达失败数

**业务规则**：

- ROI相关字段（投入成本、产出收入）由系统集成外部数据源，此处展示下发和触达数据作为ROI计算的基础
- 各层级触达成功率=该层级触达成功数/下发总数×100%（保留2位小数）
- 树形结构默认收起，用户展开状态在会话内保持
- 时间范围默认显示最近7天数据

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 各供应商ROI数据由外部系统同步；触达成功率计算误差<0.01% |
| 操作验收 | 展开/收起操作响应时间<500ms；切换时间范围后立即刷新列表；翻页保持展开层级 |
| 数据验收 | 短信供应商仅显示阿里云/腾讯云；AI外呼仅显示百应/九四；人工外呼仅显示人工电销 |
| 交互验收 | 详情链接跳转时URL携带当前筛选参数；无数据时显示空状态插图；树形展开图标与收起图标状态一致 |

### FP-MKT-REACH-ANAL-004 数据导出

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-ANAL-004 |
| 功能点名称 | 数据导出 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：支持触达查询明细、短信发送记录、AI外呼记录等数据的导出功能，可按条件筛选后导出指定字段。

**操作步骤**：

1. 进入触达查询明细页面或其他可导出页面
2. 设置查询条件筛选要导出的数据范围
3. 点击"查询"确认筛选结果
4. 点击"导出"按钮（页面顶部或列表工具栏）
5. 系统弹出导出配置弹窗（可选）：选择导出字段、导出格式（Excel/CSV）
6. 确认后系统开始生成导出文件，页面显示"导出中"状态
7. 导出完成后浏览器自动下载文件，或在"导出记录"中下载

**输入字段**：查询条件（姓名/手机号/模板ID/触达类型/触达状态等）、导出字段选择、导出格式

**输出字段**：导出文件名、导出记录条数、导出时间、导出状态、下载链接

**业务规则**：

- 单次导出最大条数限制为10万条，超出时提示"导出数据量过大，请缩小筛选范围"
- 导出字段默认包含列表展示的所有字段，支持自定义勾选
- 导出格式支持Excel（.xlsx）和CSV（.csv）两种
- 导出文件名格式：触达明细_YYYYMMDD_HHmmss.xlsx
- 导出记录永久保存，支持在"导出记录"页面查看和重新下载

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 筛选后导出100条记录，文件包含且仅包含筛选结果数据；导出Excel文件可用Excel/WPS正常打开 |
| 操作验收 | 导出中按钮显示加载状态；导出完成后浏览器自动弹出下载；取消导出操作不生成文件 |
| 数据验收 | 导出手机号字段与列表展示一致（已脱敏）；字段顺序与列表表头顺序一致 |
| 交互验收 | 导出按钮有导出图标标识；导出文件命名包含精确时间戳避免覆盖；超出导出上限时前端拦截提示 |

### 2.3 用户场景

| 场景 | 用户 | 描述 |
|:---|:---|:---|
| 场景1 | 运营人员 | 运营人员进入触达首页，自动加载今日触达数据概览，查看关键指标卡片（今日触达数、下发占比等） |
| 场景2 | 运营人员 | 运营人员在触达首页的任务明细列表，输入MA任务ID进行精确查询，找到对应策略的执行任务 |

| 场景4 | 运营人员 | 运营人员在触达查询明细页面查看触达记录，手机号脱敏显示（如138****8000），点击"查看详情"跳转到详情页 |

| 场景6 | 管理员 | 管理员在系统管理页面查看渠道配额与限流、短信签名与模板库、任务审核流配置等全局系统信息 |
| 场景7 | 管理员 | 管理员在字典管理页面查询系统数据字典，按关键字搜索键或值，查看字典分类、键、值和描述 |
