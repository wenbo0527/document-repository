## 2. FP 清单

### FP-MKT-REACH-FREQ-001 频次配置

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-FREQ-001 |
| 功能点名称 | 频次配置 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：配置和管理全局触达频率控制规则，防止过度触达用户。

**操作步骤**：

1. 进入全局频控页面，查看频控规则列表
2. 查询条件筛选：控制渠道（AI外呼/短信/人工外呼多选）、控制场景（营销类等多选）、一级场景（经审冷-停催/经审冷-黑催/经催热-意向/经催热-激活/历史客户单选）、状态（使用中/停用单选）
3. 点击"新建"按钮弹出频控规则配置表单
4. 填写表单：控制渠道（多选）、控制场景（多选）、一级场景（单选必填）、控制规则（N天M次数值）、状态（使用中/停用）、备注（可选）
5. 点击"确定"保存规则并刷新列表；点击"取消"放弃创建
6. 点击列表中"查看"链接查看规则详情（只读弹窗）
7. 点击"编辑"链接修改规则内容（表单弹窗）
8. 点击"删除"链接删除规则（确认弹窗，二次确认后删除）

**输入字段**：控制渠道（多选）、控制场景（多选）、一级场景（单选）、控制规则（N天M次，N范围1-30，M范围1-10）、状态、备注

**输出字段**：控制渠道、控制场景、一级场景、控制规则、状态、最近更新时间、备注

**业务规则**：

- 控制规则格式固定为"N天M次"，N为天数（1-30），M为次数（1-10）
- 同一控制渠道+控制场景+一级场景的组合只允许一条规则，重复创建时提示"规则已存在"
- 状态为"停用"的规则不参与频控校验
- 删除操作需要二次确认，已删除规则不可恢复

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 同一组合（渠道+场景+一级场景）重复创建时前端拦截并提示错误；停用规则在触达时不参与频控判断 |
| 操作验收 | 控制渠道最多可选3个（AI外呼/短信/人工外呼）；控制场景最多可选5个；一级场景为单选且必填 |
| 数据验收 | 新建规则后"最近更新时间"自动填充当前时间戳；删除后列表实时刷新 |
| 交互验收 | 表单必填字段未填写时"确定"按钮置灰；编辑时表单预填充当前规则数据；删除确认弹窗显示规则摘要信息 |

### FP-MKT-REACH-FREQ-002 频次统计

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-FREQ-002 |
| 功能点名称 | 频次统计 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：以树形结构统计各触达渠道和供应商的触达数据，支持多级展开和条件筛选。

**操作步骤**：

1. 进入策略数据概览页面（树形结构），默认展示全量数据
2. 第一级按触达类型聚合（短信/AI外呼/人工外呼）
3. 第二级按供应商聚合：
   - 短信：阿里云短信、腾讯云短信
   - AI外呼：百应、九四
   - 人工外呼：人工电销
4. 第三级按具体任务名称和批次展示
5. 查询条件筛选：触达类型、供应商、任务ID、批次ID、任务下发时间（日期范围）
6. 点击"展开"查看子级数据，点击"收起"折叠父级
7. 查看各层级统计字段：下发成功率、触达成功数、触达成功率、触达失败数
8. 点击"详情"链接跳转到触达明细查询页面

**输入字段**：触达类型、供应商、任务ID、批次ID、任务下发时间范围

**输出字段**：触达类型、供应商、任务ID、批次ID、下发成功率、触达成功数、触达成功率、触达失败数

**业务规则**：

- 各层级下发成功率=该层级触达成功数之和/下发总数之和×100%（保留2位小数）
- 触达成功率=触达成功数/下发总数×100%（保留2位小数）
- 默认收起所有层级，支持记住用户展开偏好
- 时间范围默认显示最近7天

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 短信类型仅聚合阿里云/腾讯云供应商数据；AI外呼仅聚合百应/九四数据；人工外呼仅聚合人工电销数据 |
| 操作验收 | 展开/收起响应时间<500ms；翻页/筛选后保持当前展开层级状态；无数据时显示空状态插图和文字 |
| 数据验收 | 各层级触达成功数=所有子任务触达成功数之和；下发成功率计算误差<0.01% |
| 交互验收 | 详情链接跳转时携带当前任务的筛选条件作为URL参数；时间范围选择器支持快捷选项（今天/近7天/近30天） |

### FP-MKT-REACH-FREQ-003 频次预警

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-FREQ-003 |
| 功能点名称 | 频次预警 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：查看和管理触达预警规则及告警信息，支持按预警级别和状态筛选。

**操作步骤**：

1. 进入预警管理页面，查看预警规则列表
2. 支持预警信息展示：ID（预警规则唯一标识）、名称（预警名称）、级别（高/中/低）、状态（进行中/已处理）
3. 点击预警记录查看详细信息（弹窗）
4. 对"进行中"的预警进行处理操作：
   - 点击"处理"按钮（弹窗）填写处理备注
   - 点击确认后将状态变更为"已处理"
5. 处理后的预警记录保留在列表中，状态显示为"已处理"

**输入字段**：处理备注（必填，不超过200字符）

**输出字段**：预警ID、预警名称、预警级别、预警状态、预警时间、触发条件、处理时间、处理备注

**业务规则**：

- 预警级别颜色：高（红色）、中（橙色）、低（黄色）
- 进行中的预警数量在页面Tab或列表顶部显示角标
- 预警处理不可逆，处理后状态变更为"已处理"
- 预警触发条件由系统配置，包括成功率阈值、下发量阈值等

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 预警级别正确显示对应颜色标签；处理后状态秒级更新为"已处理" |
| 操作验收 | 处理备注未填写时确认按钮置灰；处理弹窗关闭后不丢失已填写内容 |
| 数据验收 | 预警记录永久保留，不可删除；处理时间精确到秒 |
| 交互验收 | 进行中的预警在列表中置顶显示；已处理预警的处理时间显示在状态之后 |

### FP-MKT-REACH-FREQ-004 频次报表

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-FREQ-004 |
| 功能点名称 | 频次报表 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：查询触达记录的明细数据，支持多条件筛选和导出。

**操作步骤**：

1. 进入触达查询明细页面
2. 查询条件：姓名（模糊）、手机号码（模糊）、模板ID（模糊）、通话时长（秒精确/模糊）、触达通道（短信/AI外呼/人工外呼）、厂商（自营/阿里云/腾讯云/百应/九四）、触达类型、触达状态（成功/失败/待处理）
3. 点击"查询"执行筛选，点击"重置"清空所有条件
4. 查看触达明细列表：触达对象、手机号码（脱敏显示）、触达类型、模板ID、外部模板ID、通话时长（秒，短信显示"-"）、对话录音（AI/人工外呼显示播放按钮）、触达通道、厂商、触达状态、详细信息（查看详情入口）、触达时间
5. 点击录音"播放"按钮弹出播放器播放通话录音
6. 点击"查看详情"跳转到单条触达记录详情页
7. 支持导出功能（如果系统配置了导出权限）

**输入字段**：姓名、手机号码、模板ID、通话时长、触达通道、厂商、触达类型、触达状态

**输出字段**：触达对象、手机号码、脱敏规则：138****8000、触达类型、模板ID、外部模板ID、通话时长、对话录音URL、触达通道、厂商、触达状态、触达时间

**业务规则**：

- 手机号码显示时脱敏：中间4位脱敏（如138****8000）
- 短信触达时通话时长显示"-"，不显示null
- 录音仅AI外呼/人工外呼有录音，短信无录音
- 触达状态颜色：成功（绿色）、失败（红色）、待处理（橙色）
- 列表默认按触达时间倒序排列

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 姓名/手机号支持模糊查询（输入"张"返回所有姓张的记录）；触达状态筛选正确过滤列表 |
| 操作验收 | 查询响应时间<2秒（数据量<10万条）；重置后所有筛选条件清空，列表恢复默认排序 |
| 数据验收 | 手机号脱敏规则正确：13812348000显示为138****8000；通话时长字段数字精确 |
| 交互验收 | 录音播放按钮点击后弹窗<300ms打开；失败记录红色高亮显示；查看详情跳转新页面不丢失当前筛选条件 |

### 2.3 用户场景

| 场景 | 用户 | 描述 |
|:---|:---|:---|
| 场景1 | 运营人员 | 运营人员在全局频控页面查看频控规则列表，按控制渠道（AI外呼/短信/人工外呼）、控制场景、状态等条件筛选 |
| 场景2 | 运营人员 | 运营人员在全局频控页面点击"新建"，配置"短信+营销类+历史客户"组合的频控规则为"7天1次"，保存后规则生效 |
| 场景3 | 运营人员 | 运营人员在预警管理页面查看进行中的预警记录，点击"处理"按钮填写处理备注后将预警状态变更为"已处理" |
| 场景4 | 运营人员 | 运营人员在触达查询明细页面输入姓名"张"进行模糊查询，返回所有姓张的触达记录 |
| 场景5 | 运营人员 | 运营人员在触达查询明细页面筛选触达类型为"AI外呼"、状态为"失败"，查看所有AI外呼失败的触达记录 |
| 场景6 | 运营人员 | 运营人员在外呼记录中点击录音"播放"按钮，在弹窗中播放AI外呼或人工外呼的通话录音 |
