## 2. FP 清单

### FP-MKT-REACH-TMPL-001 模板创建

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-TMPL-001 |
| 功能点名称 | 模板创建 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：支持运营人员创建多渠道（短信、推送、邮件、微信）消息模板，提供可视化编辑器，支持添加文字、图片、按钮等元素，支持插入变量占位符（如\{\{user_name\}\}、\{\{coupon_code\}\}），支持模板保存为草稿或直接提交审核。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 支持多渠道模板创建；支持变量占位符插入；支持预览模板效果 |
| 操作验收 | 表单必填项校验；保存草稿成功提示；提交审核时完整性校验 |
| 数据验收 | 模板数据完整写入；变量占位符格式正确解析；草稿与正式版本区分存储 |
| 交互验收 | 编辑器加载流畅；变量插入操作便捷；预览效果与实际发送一致 |

### FP-MKT-REACH-TMPL-002 模板编辑

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-TMPL-002 |
| 功能点名称 | 模板编辑 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：支持对已有模板进行编辑修改，包括内容调整、变量修改、渠道变更等操作，每次编辑自动生成版本记录，支持查看历史版本并可回滚到指定历史版本，编辑后需重新提交审核。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 支持模板内容编辑；自动生成版本号；支持历史版本查看和回滚 |
| 操作验收 | 编辑后需重新提交审核；回滚操作有二次确认；版本对比展示变更内容 |
| 数据验收 | 每次编辑生成新版本记录；历史版本不可篡改；回滚后原版本保留 |
| 交互验收 | 版本历史列表清晰；变更内容高亮展示；回滚后状态更新及时 |

### FP-MKT-REACH-TMPL-003 模板审核

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-TMPL-003 |
| 功能点名称 | 模板审核 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：建立模板审核流程，审核人员可查看待审核模板内容，对模板进行通过、驳回或返回修改操作，驳回时需填写审核意见，模板状态随审核结果实时更新，支持审核消息通知。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 支持审核通过/驳回/返回修改三种操作；驳回必须填写意见；状态自动更新 |
| 操作验收 | 审核操作后发送通知；驳回意见必填校验；通过后模板立即生效 |
| 数据验收 | 审核记录完整保存；包含审核人、审核时间、审核意见；审核状态流转正确 |
| 交互验收 | 审核意见输入框清晰；审核结果即时反馈；待审核列表实时更新 |

### FP-MKT-REACH-TMPL-004 模板管理

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-TMPL-004 |
| 功能点名称 | 模板管理 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：建立公共模板市场，提供已通过审核的模板集中展示和检索功能，用户可按渠道类型、行业场景、标签等维度筛选模板，支持模板预览和一键引用，支持收藏常用模板，支持将市场模板复制到个人空间后修改使用。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 模板市场展示所有已通过模板；支持按渠道/行业/标签筛选；支持模板预览 |
| 操作验收 | 筛选条件即时生效；预览弹窗展示模板详情；一键引用后跳转编辑页 |
| 数据验收 | 模板数据实时同步；引用操作生成模板副本；收藏状态持久化存储 |
| 交互验收 | 模板卡片展示清晰；筛选器布局合理；预览和引用操作直观便捷 |
