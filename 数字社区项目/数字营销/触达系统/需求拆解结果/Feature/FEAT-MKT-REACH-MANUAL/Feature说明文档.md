## 2. FP 清单

### FP-MKT-REACH-MANUAL-001 创建手工触达

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-MANUAL-001 |
| 功能点名称 | 创建手工触达 |
| 类型 | 功能点 |
| 优先级 | P2 |
| 状态 | 已上线 |

**功能描述**：支持运营人员手动创建单次或批量触达任务，选择触达渠道（短信、推送等）、输入触达内容、添加接收人列表，支持从通讯录导入或手动输入手机号码，支持设置发送时间（即时或定时）。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 支持创建手工触达任务；支持即时发送和定时发送；支持批量导入接收人 |
| 操作验收 | 创建流程步骤清晰；必填项校验完善；定时任务支持时间选择器 |
| 数据验收 | 触达任务数据完整写入；定时任务按时触发；导入数据格式校验 |
| 交互验收 | 表单布局合理；接收人列表支持增删改；预览效果与实际发送一致 |

### FP-MKT-REACH-MANUAL-002 选择触达渠道

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-MANUAL-002 |
| 功能点名称 | 选择触达渠道 |
| 类型 | 功能点 |
| 优先级 | P2 |
| 状态 | 已上线 |

**功能描述**：在创建手工触达时，支持从已配置的渠道列表中选择发送渠道，支持单渠道或多渠道组合发送，支持查看各渠道的发送能力和单价信息，便于运营人员选择最优渠道组合。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 渠道列表展示所有可用渠道；支持单选或多选；支持渠道优先级排序 |
| 操作验收 | 渠道选择后展示发送预览；渠道成本实时计算；不支持的渠道置灰 |
| 数据验收 | 渠道选择数据正确存储；多渠道组合时按优先级依次发送 |
| 交互验收 | 渠道卡片展示清晰；选中状态视觉区分；渠道详情可点击展开 |

### FP-MKT-REACH-MANUAL-003 发送与草稿管理

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-MANUAL-003 |
| 功能点名称 | 发送与草稿管理 |
| 类型 | 功能点 |
| 优先级 | P2 |
| 状态 | 已上线 |

**功能描述**：支持将编辑好的触达内容发送或保存为草稿，支持查看草稿列表并继续编辑，支持取消尚未发送的定时任务，发送后实时展示发送结果，包括成功数、失败数和失败原因。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 支持发送和保存草稿；草稿列表支持继续编辑；定时任务可取消 |
| 操作验收 | 发送前有确认预览；草稿自动保存；取消操作需二次确认 |
| 数据验收 | 发送结果实时更新；失败原因准确记录；草稿数据持久化存储 |
| 交互验收 | 发送状态即时反馈；结果展示清晰明了；重试操作便捷 |

### FP-MKT-REACH-MANUAL-004 历史发送记录

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-MANUAL-004 |
| 功能点名称 | 历史发送记录 |
| 类型 | 功能点 |
| 优先级 | P2 |
| 状态 | 已上线 |

**功能描述**：管理员可查看所有手工触达的历史发送记录，支持按发送时间、渠道、发送人等维度筛选，支持查看单条发送的详细信息（内容、接收人、发送结果），支持导出记录用于存档或分析。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 历史记录完整展示；支持多维度筛选；支持详情查看和数据导出 |
| 操作验收 | 筛选条件即时生效；导出支持 Excel 格式；分页加载流畅 |
| 数据验收 | 记录数据不可篡改；导出数据与页面展示一致；分页数据准确 |
| 交互验收 | 记录列表展示清晰；详情弹窗信息完整；导出按钮位置显眼 |
