## 2. FP 清单

### FP-MKT-REACH-CH-001 渠道配置

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-CH-001 |
| 功能点名称 | 渠道配置 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：支持配置短信、推送、邮件、微信、外呼等触达渠道的基础参数，包括渠道名称、渠道类型、接入密钥、发送地址等核心配置项。用户可新增、编辑、启用/禁用渠道，并查看渠道当前状态。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 支持新增渠道、编辑渠道参数、启用/禁用渠道；渠道状态（启用/禁用/异常）正确展示 |
| 操作验收 | 表单必填项校验提示准确；保存后自动刷新列表；禁用渠道时二次确认 |
| 数据验收 | 渠道配置参数完整写入数据库；渠道状态变更有操作日志 |
| 交互验收 | 配置表单布局规范；字段标签清晰；错误提示位于对应字段下方 |

### FP-MKT-REACH-CH-002 渠道接入

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-CH-002 |
| 功能点名称 | 渠道管理 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：支持将新的第三方触达渠道（如阿里云短信、腾讯云推送、华为推送等）接入系统，提供渠道接入向导，引导用户完成渠道资质验证、API配置、签名/证书上传等步骤，并记录接入时间和接入状态。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 接入向导包含资质验证、API配置、签名上传三步；支持主流渠道模板快速接入 |
| 操作验收 | 向导步骤可前进/后退；未完成步骤不可提交；接入进度实时显示 |
| 数据验收 | 渠道接入信息完整写入；接入状态（接入中/成功/失败）准确记录 |
| 交互验收 | 向导界面清晰；各步骤有进度指示；失败时展示具体错误原因 |

### FP-MKT-REACH-CH-003 渠道监控

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-CH-003 |
| 功能点名称 | 渠道统计 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：实时监控各触达渠道的发送状态，包括发送量、成功率、失败量、平均延迟等核心指标，提供渠道健康度看板，支持按渠道维度筛选和导出监控数据，便于运营人员及时发现渠道异常。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 监控面板实时展示各渠道发送量/成功率/失败率/延迟；支持按渠道/时间范围筛选 |
| 操作验收 | 数据每分钟自动刷新；支持手动刷新；支持监控数据导出 |
| 数据验收 | 监控指标数据来源可靠；延迟不超过1分钟；渠道异常时高亮提示 |
| 交互验收 | 监控面板图表清晰；关键指标可视化展示；异常渠道红色标识 |

### FP-MKT-REACH-CH-004 渠道测试

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-CH-004 |
| 功能点名称 | 渠道监控 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：提供渠道连通性测试功能，用户可在渠道配置完成后发送测试消息验证渠道是否正常工作，支持指定测试手机号/设备ID，支持查看测试报告，包括发送状态、耗时、错误码等详情。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 支持发送测试消息到指定接收人；测试完成后展示发送结果和耗时 |
| 操作验收 | 测试入口在渠道列表页和详情页均可触达；测试过程有加载状态 |
| 数据验收 | 测试记录完整保存；包含发送时间、接收人、发送状态、耗时、错误码 |
| 交互验收 | 测试结果弹窗展示；成功/失败状态清晰区分；支持重试操作 |
