## 2. FP 清单

### FP-MKT-REACH-TASK-001 任务创建

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-TASK-001 |
| 功能点名称 | 任务创建 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：创建触达策略模板，支持短信、AI外呼、人工外呼三种渠道配置。

**操作步骤**：

1. 填写消息策略模板基本信息：标题（必填）、消息类型（短信/推送/邮件）、一级场景（营销类/风控类/通知类/历史存量）、策略tag（高优先级/测试/生产）、产品（可选）、目标渠道（必填）、策略级频控（2-5次）、发送次数（必填）
2. 根据目标渠道动态配置渠道参数：
   - 短信渠道：选择厂商（阿里云/腾讯云），新建或选择已有模板，填写模板标题和短信内容（支持变量占位符）
   - AI外呼渠道：选择厂商（百应/九四）和AI话术模板，填写外呼任务ID，配置是否需要短信兜底（挂短）
   - 人工外呼渠道：选择人工外呼脚本，填写外呼任务ID、渠道编号、名单失效时间，配置是否挂短
3. 配置发送时间：设置每日允许发送时间段（时间范围选择）
4. 点击"确定"保存策略模板并跳转列表；点击"取消"放弃创建返回列表

**输入字段**：标题、消息类型、一级场景、策略tag、产品、目标渠道、策略级频控、发送次数、厂商、模板标题、短信内容、外呼任务ID、名单失效时间、每日发送时间段

**输出字段**：模板ID（系统生成）、消息类型、厂商、一级场景、策略tag、消息标题、策略描述

**业务规则**：

- 标题为必填项，不超过50字符
- 目标渠道选择后动态显示对应配置表单
- 短信内容支持变量占位符：{用户名}、{手机号}、{优惠券金额}、{活动名称}、{到期时间}
- 人工外呼渠道需配置名单失效时间，过期名单自动失效

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 新建策略模板保存成功，模板ID自动生成并显示在列表中 |
| 操作验收 | 切换目标渠道时表单动态刷新，填写字段数与渠道匹配（短信3字段/AI外呼4字段/人工外呼5字段） |
| 数据验收 | 保存后模板数据与填写内容完全一致，策略tag支持多选 |
| 交互验收 | 必填字段未填写时"确定"按钮置灰不可点击，表单有前端校验提示 |

### FP-MKT-REACH-TASK-002 任务审批

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-TASK-002 |
| 功能点名称 | 任务审批 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：对触达策略模板进行审批操作，支持审批通过或审批拒绝。

**操作步骤**：

1. 在策略模板列表页，点击模板"审批"按钮（仅待审批状态显示）
2. 弹出审批弹窗，查看模板详细信息：消息类型、厂商、一级场景、策略tag、消息标题、策略内容
3. 选择审批结果：通过或拒绝
4. 如拒绝，需填写拒绝原因（必填，不超过200字符）
5. 点击确认完成审批操作，模板状态更新为"审批通过"或"审批拒绝"
6. 审批拒绝的模板支持重新编辑后再次提交审批

**输入字段**：审批结果（通过/拒绝）、拒绝原因（拒绝时必填）

**输出字段**：审批状态（审批通过/审批拒绝）、审批时间、审批人

**业务规则**：

- 仅待审批状态的模板可进行审批操作
- 拒绝时必须填写拒绝原因，通过时原因可选填
- 审批操作不可逆，审批通过后模板状态变更为"使用中"
- 一个模板同一时间仅能被一人审批，审批中锁定

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 审批通过后模板状态变更为"使用中"，审批拒绝后状态变更为"审批拒绝"并可编辑 |
| 操作验收 | 拒绝时未填写原因则确认按钮置灰；审批中模板显示锁定标识，其他用户不可操作 |
| 数据验收 | 审批记录（审批人、时间、结果、原因）完整存储并可追溯 |
| 交互验收 | 审批弹窗中模板内容超出可视区域时可滚动查看，拒绝原因输入框字数实时统计 |

### FP-MKT-REACH-TASK-003 任务执行

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-TASK-003 |
| 功能点名称 | 任务执行 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：执行触达策略任务，追踪任务执行状态和批次明细。

**操作步骤**：

1. 从触达首页进入任务明细列表
2. 支持多条件筛选：MA任务ID（精确查询）、任务执行批次号（精确查询）、执行日期（日期范围选择）、触达类型（实时/批量下拉选择）、状态（执行完成/失败/执行中/数据准备中/批量任务执行取消）
3. 查看任务列表数据：策略ID、MA任务名称、MA任务ID、任务执行批次、触达类型、成功率、状态、预警标识
4. 点击"失败详情"按钮查看策略执行失败的具体原因（弹窗展示）
5. 任务状态实时更新：策略执行完成（绿色）、策略执行失败（红色）、策略执行中（蓝色）、数据准备中（浅蓝色）

**输入字段**：MA任务ID、任务执行批次、执行日期、触达类型、状态

**输出字段**：策略ID、MA任务名称、MA任务ID、任务执行批次、触达类型、成功率、下发成功率、状态、预警标识、失败原因

**业务规则**：

- 成功率小于100条数据时不进行统计，显示"-"或"不统计"
- 成功率低于阈值时显示预警标识（黄色感叹号）
- 任务执行批次号精确匹配，不支持模糊查询
- 失败详情仅在状态为"失败"时可用

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 按MA任务ID精确查询返回唯一结果；按批次号精确查询返回对应任务；执行日期范围筛选返回区间内所有任务 |
| 操作验收 | 列表按执行时间倒序排列；翻页后筛选条件保持不变；失败详情弹窗可关闭 |
| 数据验收 | 成功率计算公式正确（成功数/下发总数×100%）；成功率低于20%时预警标识显示正确 |
| 交互验收 | 状态筛选下拉包含全部5种状态选项；触达类型筛选包含"全部/实时/批量"三个选项 |

### FP-MKT-REACH-TASK-004 任务监控

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-REACH-TASK-004 |
| 功能点名称 | 任务监控 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：以树形结构监控策略数据概览，支持按触达类型、供应商、任务多级展开查看详情。

**操作步骤**：

1. 进入策略数据概览页面，默认展示全量数据树形结构
2. 第一级：按触达类型聚合（短信/AI外呼/人工外呼）
3. 第二级：按供应商聚合（阿里云短信/腾讯云短信/百应/九四/人工电销）
4. 第三级：按具体任务和批次展示
5. 支持查询条件筛选：触达类型、供应商、任务ID、批次ID、任务下发时间范围
6. 点击"展开"图标逐级展开查看子级数据，点击"收起"折叠
7. 点击"详情"链接跳转到触达明细查询页面
8. 点击"查询"执行筛选，点击"重置"清空条件

**输入字段**：触达类型（全部/短信/AI外呼/人工外呼）、供应商（阿里云短信/腾讯云短信/百应/九四/人工电销）、任务ID、批次ID、任务下发时间（日期范围）

**输出字段**：触达类型、供应商、任务ID、批次ID、下发成功率、触达成功数、触达成功率、触达失败数

**业务规则**：

- 树形结构默认全部收起，支持记住用户展开偏好
- 触达成功率=触达成功数/下发总数×100%（保留2位小数）
- 时间范围筛选默认显示最近7天数据
- 列表数据按触达时间倒序排列

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 三级树形结构数据正确聚合：短信仅显示阿里云/腾讯云，AI外呼仅显示百应/九四，人工外呼仅显示人工电销 |
| 操作验收 | 展开/收起操作响应时间<500ms；翻页不破坏树形展开状态；重置后恢复默认收起状态 |
| 数据验收 | 各层级下发成功率=下级触达成功数之和/下发总数之和；批次ID为空时显示"-" |
| 交互验收 | 详情链接跳转后回显当前任务的查询条件；无数据时显示空状态占位图 |

## 3. 依赖关系

| 依赖项 | 类型 | 说明 |
|:---|:---|:---|
| 客群中心 | 接口依赖 | 策略任务创建时目标人群从客群中心（EPIC-MKT-CROWD）选择 |
| 权益中心 | 接口依赖 | 策略中含权益发放时，调用权益中心（EPIC-MKT-BENEFIT）发放接口 |
