## 一、产品概述

### 1.1 产品定位
人工电销工作台（EPIC-MKT-MANUAL-SALES）是数字营销产品域的核心组成部分，为电销人员提供统一的客户管理、外呼、通话记录、工单管理和数据分析能力。

### 1.2 核心价值

| 价值 | 说明 |
|:---|:---|
| 工作台统一 | 统一的电销工作台，提升工作效率 |
| 流程自动化 | 自动拨号、弹屏、记录，减少人工操作 |
| 数据同步 | CRM 与电销系统数据实时同步 |
| 质检高效 | 在线质检和离线质检结合，提升服务质量 |
| 数据融合 | 电销数据与营销数据融合分析 |

### 1.3 目标用户

- **电销人员**：使用工作台进行外呼、客户管理和通话记录
- **运营主管**：查看电销报表、统计业绩、管理团队
- **质检人员**：对通话进行质检评分
- **管理人员**：查看整体电销数据和分析

## 二、产品架构

EPIC-MKT-MANUAL-SALES 包含四个主要功能模块：

| 模块 | 说明 | 优先级 |
|:---|:---|:---:|
| **电销工作台（FEAT-MKT-SALES-DESK）** | 客户列表、详情、外呼 | P0 |
| **通话管理（FEAT-MKT-SALES-CALL）** | 通话记录、质检、统计 | P0 |
| **工单管理（FEAT-MKT-SALES-WORKORDER）** | 工单创建、处理、跟进 | P0 |
| **数据分析（FEAT-MKT-SALES-ANALYSIS）** | 报表、业绩、转化分析 | P1 |
