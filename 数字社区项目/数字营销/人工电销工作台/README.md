## 概述

人工电销工作台是数字营销产品域的**渠道层**重要模块，提供电销场景下的工作台主页、任务管理、数据看板等能力，支持客服高效开展人工电销工作。

> ⚠️ **整改说明**：当前人工电销是独立应用（telemarketing-workbench），目标整合到数字营销作为子模块
