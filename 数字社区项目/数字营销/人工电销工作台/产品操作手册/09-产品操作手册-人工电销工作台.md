## 1. 产品概述

### 1.1 产品简介

人工电销工作台是一款面向电销团队的管理系统，提供完整的客户管理、外呼任务管理、数据监控、质检管理等核心功能。系统支持多种外呼模式，包括手拨任务和预测式外呼。

### 1.2 目标用户

| 用户群体 | 角色 | 使用场景 |
|:---|:---|:---|
| 电销坐席 | 一线员工 | 使用名单搜索、外呼、客户记录等功能 |
| 电销主管 | 团队管理者 | 管理团队、监控坐席、查看业绩 |
| 质检员 | 质量管控 | 进行通话质检、评分 |
| 系统管理员 | 运维人员 | 配置系统规则、管理权限 |

### 1.3 功能概览

| 功能模块 | 说明 |
|:---|:---|
| 📞 外呼管理 | 名单搜索、外呼任务、预约回电、通话记录 |
| 👥 架构管理 | 团队管理、小组管理、坐席管理、角色权限 |
| 📊 数据监控 | 数据概览、坐席监控、业绩统计 |
| 👁 质检管理 | 质检任务、评分模板、质检结果 |
| ⚙ 系统设置 | 出池规则、日志查询、通知管理 |

## 4. 操作指南

### 4.1 外呼管理模块

#### 4.1.1 名单列表

**菜单位置**：📞 外呼管理 → 名单列表

**功能入口**：`/target-prospect-workbench`

**操作步骤**：

| 步骤 | 操作 | 说明 |
|:---:|:---|:---|
| 1 | 进入名单列表页面 | 默认展示全部名单 |
| 2 | 使用综合搜索 | 输入客户编号/手机尾号/姓名进行搜索 |
| 3 | 使用高级搜索 | 点击"高级搜索"展开更多筛选条件 |
| 4 | 查看名单详情 | 双击客户编号跳转详情页 |
| 5 | 拨打电话 | 点击"拨打电话"按钮发起外呼 |
| 6 | 批量选择名单 | 勾选名单后进行批量操作 |
| 7 | 一键回收/分配 | 点击对应按钮执行批量操作 |

#### 4.1.2 预约回电

**菜单位置**：📞 外呼管理 → 预约回电

**功能入口**：`/callback-management`

**操作步骤**：

| 步骤 | 操作 | 说明 |
|:---:|:---|:---|
| 1 | 进入预约回电页面 | 查看待回电任务列表 |
| 2 | 创建回电预约 | 点击"新建回电"创建预约 |
| 3 | 执行回电 | 点击"回电"按钮拨打电话 |
| 4 | 取消预约 | 点击"取消"按钮取消预约 |
| 5 | 导出结果 | 点击"导出"导出回电记录 |

#### 4.1.3 外呼任务管理

**菜单位置**：📞 外呼管理 → 外呼任务管理

**功能入口**：`/outbound-task-management`

**操作步骤**：

| 步骤 | 操作 | 说明 |
|:---:|:---|:---|
| 1 | 进入外呼任务页面 | 查看任务列表 |
| 2 | 筛选任务 | 按名称、状态、时间筛选 |
| 3 | 创建任务 | 点击"新建任务"创建外呼任务 |
| 4 | 启动任务 | 点击"启动"按钮启动任务 |
| 5 | 暂停/停止任务 | 点击对应按钮控制任务状态 |
| 6 | 编辑任务 | 点击"编辑"修改任务配置 |

#### 4.1.4 通话记录查询

**菜单位置**：📞 外呼管理 → 通话记录查询

**功能入口**：`/call-records`

**操作步骤**：

| 步骤 | 操作 | 说明 |
|:---:|:---|:---|
| 1 | 进入通话记录页面 | 查看历史通话记录 |
| 2 | 筛选记录 | 按时间、客户、坐席筛选 |
| 3 | 播放录音 | 点击"播放"按钮收听录音 |

## 5. 注意事项

| 注意事项 | 说明 |
|:---|:---|
| 名单操作 | 批量回收/分配操作需谨慎，确认后再执行 |
| 任务启停 | 任务启动后无法删除，只能停止 |
| 时间编辑 | 任务编辑时开始时间不能晚于原时间，结束时间不能早于原时间 |
| 权限配置 | 角色权限修改后立即生效 |
| 数据导出 | 导出操作可能需要较长时间，请耐心等待 |

## 6. 常见问题

| 问题 | 解决方案 |
|:---|:---|
| 名单搜索不到 | 检查搜索条件是否正确，尝试模糊搜索 |
| 无法启动任务 | 检查任务配置是否完整，确认坐席组是否可用 |
| 录音无法播放 | 检查网络连接，确认录音文件是否存在 |
| 坐席状态不更新 | 刷新页面或检查坐席客户端连接状态 |
| 无法导出数据 | 检查浏览器设置，确认是否拦截了弹出窗口 |
