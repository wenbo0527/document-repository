## 一、产品概述

### 1.1 功能简介

人工电销工作台是数字营销的核心模块，为电销人员提供统一的客户管理、外呼、通话记录、工单管理和数据分析能力。

### 1.2 核心功能

| 功能 | 说明 |
|:---|:---|
| 电销工作台 | 客户列表、详情、外呼操作 |
| 通话管理 | 通话记录、质检、统计 |
| 工单管理 | 工单创建、处理、跟进 |
| 数据分析 | 电销报表、业绩统计、转化分析 |

## 七、常见问题

### Q1: 外呼失败怎么办？
**A**：检查网络连接和耳机设备，确认客户电话是否正确，尝试重新拨号。

### Q2: 工单被退回如何处理？
**A**：查看退回原因，根据原因修改工单内容后重新提交。

### Q3: 如何提升接通率？
**A**：选择最佳外呼时间（工作日 10-12 点、14-17 点），优先联系高意向客户。

### Q4: 质检评分低怎么办？
**A**：查看质检意见，学习优秀通话案例，注意语速、态度和话术规范。
