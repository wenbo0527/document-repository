## 2. FP 清单

### FP-MKT-SALES-WO-001 工单创建

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-SALES-WO-001 |
| 功能点名称 | 工单创建 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：电销人员在通话结束后创建工单，记录客户需求和跟进事项，选择工单类型和优先级。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 工单创建功能正常，必填项校验通过 |
| 操作验收 | 创建操作<3s，表单校验及时 |
| 数据验收 | 工单数据正确存储，关联客户和通话记录 |
| 交互验收 | 创建成功后自动跳转详情，支持草稿保存 |

### FP-MKT-SALES-WO-002 工单处理

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-SALES-WO-002 |
| 功能点名称 | 工单处理 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：处理工单，填写处理记录，选择处理结果（已解决/待跟进/已关闭），支持内部备注。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 工单处理流程正常，状态更新准确 |
| 操作验收 | 处理操作<2s，状态变更即时生效 |
| 数据验收 | 处理记录完整，工单状态变更可追溯 |
| 交互验收 | 处理结果选择后实时更新，待办列表同步刷新 |
