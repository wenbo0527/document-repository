## 2. FP 清单

### FP-MKT-SALES-ANAL-001 电销报表

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-SALES-ANAL-001 |
| 功能点名称 | 电销报表 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：生成电销日报/周报/月报，展示拨打量、接通量、成单量、成单率、业绩等核心指标。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 报表生成正常，数据完整准确 |
| 操作验收 | 报表生成<5s，支持订阅推送 |
| 数据验收 | 报表数据与实际业务一致，可追溯 |
| 交互验收 | 支持导出PDF/Excel，报表模板可配置 |

### FP-MKT-SALES-ANAL-002 业绩统计

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-SALES-ANAL-002 |
| 功能点名称 | 业绩统计 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：统计电销人员业绩，包括成单数量、成单金额、排名，支持个人和团队维度对比。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 业绩统计准确，排名计算正确 |
| 操作验收 | 业绩查询<3s，排名更新实时 |
| 数据验收 | 业绩数据与订单数据一致 |
| 交互验收 | 支持排名切换（日/周/月），数据对比清晰 |
