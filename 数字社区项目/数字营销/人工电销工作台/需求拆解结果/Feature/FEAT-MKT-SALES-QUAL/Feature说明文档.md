## 2. FP 清单

### FP-MKT-SALES-CALL-001 通话记录

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-SALES-CALL-001 |
| 功能点名称 | 通话记录 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：记录每次通话的详细信息，包括通话时间、时长、拨打人、接听状态、客户反馈。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 通话记录完整，状态（接通/未接/忙线）准确 |
| 操作验收 | 记录查询<2s，支持时间范围筛选 |
| 数据验收 | 记录数据与通话实际一致，可导出 |
| 交互验收 | 支持按状态筛选，点击查看详情和录音 |

### FP-MKT-SALES-CALL-002 通话质检

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-SALES-CALL-002 |
| 功能点名称 | 通话质检 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：质检人员对电销通话进行评分，评价服务质量（话术/态度/成单率），支持评分模板配置。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 质检评分功能正常，评分模板生效 |
| 操作验收 | 评分操作<2s，批量评分<10s |
| 数据验收 | 评分记录完整，与质检员和录音关联 |
| 交互验收 | 评分表单清晰，评分历史可查 |
