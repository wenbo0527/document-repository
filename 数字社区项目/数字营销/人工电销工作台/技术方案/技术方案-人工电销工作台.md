## 一、系统架构

### 1.1 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                    前端层 (Vue3 + Element Plus)              │
├─────────────────────────────────────────────────────────────┤
│  客户列表    通话记录    工单管理    数据分析                 │
├─────────────────────────────────────────────────────────────┤
│                    服务层 (Java Spring Boot)                  │
│  客户服    通话服务    工单服务    分析服务                  │
│           外呼服务                                        │
├─────────────────────────────────────────────────────────────┤
│                    第三方接入层                              │
│         呼叫中心( Sip/Cti )    CRM 系统    录音系统           │
├─────────────────────────────────────────────────────────────┤
│                    数据层                                     │
│     MySQL     Redis      Kafka       ClickHouse              │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 技术栈

| 层级 | 技术选型 | 说明 |
|:---|:---|:---|
| 前端 | Vue3 + TypeScript | 组件化开发 |
| 后端 | Java Spring Boot 2.7 | 业务逻辑处理 |
| 数据库 | MySQL 8.0 | 客户、通话、工单元数据 |
| 缓存 | Redis 6.0 | 客户数据缓存、session |
| 消息队列 | Kafka | 通话事件异步处理 |
| 分析引擎 | ClickHouse | 电销效果分析 |
| 呼叫中心 | Sip/Cti | 电话拨打和录音 |

## 二、数据库设计

### 2.1 客户表 (customer)

```sql
CREATE TABLE customer (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    customer_code VARCHAR(64) NOT NULL UNIQUE,
    customer_name VARCHAR(128) NOT NULL,
    phone VARCHAR(32) NOT NULL,
    intent_level VARCHAR(32) COMMENT 'HIGH/MEDIUM/LOW/NONE',
    status VARCHAR(32) DEFAULT 'UNCONTACTED' COMMENT 'UNCONTACTED/CONTACTED/FOLLOWUP/CLOSED',
    owner_id BIGINT COMMENT '负责电销人员',
    last_contact_time DATETIME COMMENT '最后联系时间',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_customer_code (customer_code),
    INDEX idx_phone (phone),
    INDEX idx_owner_id (owner_id)
) COMMENT='客户表';
```

### 2.2 通话记录表 (call_record)

```sql
CREATE TABLE call_record (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    record_code VARCHAR(64) NOT NULL UNIQUE,
    customer_code VARCHAR(64) NOT NULL,
    caller_id BIGINT NOT NULL COMMENT '电销人员ID',
    call_type VARCHAR(32) NOT NULL COMMENT 'OUTBOUND/INBOUND',
    call_result VARCHAR(32) COMMENT 'CONNECTED/NOCONNECTED/NOANSWER/BUSY',
    call_duration INT COMMENT '通话时长(秒)',
    call_time DATETIME NOT NULL,
    recording_url VARCHAR(256) COMMENT '录音地址',
    intent_result VARCHAR(32) COMMENT '意向结果',
    remark TEXT COMMENT '备注',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_record_code (record_code),
    INDEX idx_customer_code (customer_code),
    INDEX idx_call_time (call_time)
) COMMENT='通话记录表';
```

### 2.3 工单表 (work_order)

```sql
CREATE TABLE work_order (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    order_code VARCHAR(64) NOT NULL UNIQUE,
    customer_code VARCHAR(64) NOT NULL,
    order_type VARCHAR(32) NOT NULL COMMENT 'CONSULT/COMPLAINT/SUGGEST/OTHER',
    title VARCHAR(256) NOT NULL,
    content TEXT NOT NULL,
    priority VARCHAR(32) DEFAULT 'NORMAL' COMMENT 'NORMAL/URGENT',
    status VARCHAR(32) DEFAULT 'PENDING' COMMENT 'PENDING/PROCESSING/CLOSED/CANCELLED',
    creator_id BIGINT NOT NULL,
    handler_id BIGINT COMMENT '处理人',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_order_code (order_code),
    INDEX idx_customer_code (customer_code),
    INDEX idx_status (status)
) COMMENT='工单表';
```

### 2.4 通话质检表 (call_quality)

```sql
CREATE TABLE call_quality (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    quality_code VARCHAR(64) NOT NULL UNIQUE,
    record_code VARCHAR(64) NOT NULL,
    quality_score DECIMAL(3,1) COMMENT '质检评分 0-10',
    quality_result TEXT COMMENT '质检结果',
    quality_type VARCHAR(32) COMMENT 'ONLINE/OFFLINE',
    quality_by BIGINT COMMENT '质检人员',
    quality_time DATETIME,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_quality_code (quality_code),
    INDEX idx_record_code (record_code)
) COMMENT='通话质检表';
```

### 2.5 电销统计表 (sales_stats)

```sql
CREATE TABLE sales_stats (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    stats_date DATE NOT NULL,
    caller_id BIGINT NOT NULL,
    total_calls INT DEFAULT 0 COMMENT '总通话数',
    connected_calls INT DEFAULT 0 COMMENT '接通数',
    total_duration INT DEFAULT 0 COMMENT '总时长(秒)',
    converted_count INT DEFAULT 0 COMMENT '转化数',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_stats_date (stats_date),
    INDEX idx_caller_id (caller_id),
    UNIQUE INDEX idx_date_caller (stats_date, caller_id)
) COMMENT='电销统计表';
```

## 四、核心流程

### 4.1 外呼流程

```
用户 → 选择客户 → 点击拨号 → 系统呼叫 → 客户接通 → 通话 → 记录通话 → 更新客户状态
```

### 4.2 质检流程

```
通话结束 → 录音生成 → 质检分配 → 质检评分 → 质检结果 → 反馈电销
```

### 4.3 工单流程

```
客户需求 → 创建工单 → 工单分配 → 处理工单 → 关闭工单 → 客户确认
```
