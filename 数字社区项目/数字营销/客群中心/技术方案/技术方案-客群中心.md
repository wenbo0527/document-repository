## 二、数据库设计

### 2.1 人群表 (crowd)

```sql
CREATE TABLE crowd (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    crowd_code VARCHAR(64) NOT NULL UNIQUE,
    crowd_name VARCHAR(128) NOT NULL,
    crowd_desc TEXT COMMENT '人群描述',
    crowd_type VARCHAR(32) NOT NULL COMMENT 'STATIC/DYNAMIC',
    status VARCHAR(32) DEFAULT 'ACTIVE',
    crowd_count INT DEFAULT 0 COMMENT '人群人数',
    tags JSON COMMENT '人群标签',
    owner_id BIGINT,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_crowd_code (crowd_code),
    INDEX idx_status (status)
) COMMENT='人群表';
```

### 2.2 圈选规则表 (crowd_rule)

```sql
CREATE TABLE crowd_rule (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    rule_code VARCHAR(64) NOT NULL UNIQUE,
    crowd_code VARCHAR(64) NOT NULL,
    rule_type VARCHAR(32) NOT NULL COMMENT 'ATTRIBUTE/BEHAVIOR/COMPOUND',
    rule_config JSON NOT NULL COMMENT '规则配置',
    rule_order INT DEFAULT 0 COMMENT '规则顺序',
    status VARCHAR(32) DEFAULT 'ACTIVE',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_rule_code (rule_code),
    INDEX idx_crowd_code (crowd_code)
) COMMENT='圈选规则表';
```

### 2.3 人群分发表 (crowd_dispatch)

```sql
CREATE TABLE crowd_dispatch (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    dispatch_code VARCHAR(64) NOT NULL UNIQUE,
    crowd_code VARCHAR(64) NOT NULL,
    target_system VARCHAR(64) NOT NULL COMMENT '目标系统',
    target_config JSON COMMENT '目标配置',
    dispatch_type VARCHAR(32) NOT NULL COMMENT 'IMMEDIATE/SCHEDULED',
    schedule_time DATETIME,
    status VARCHAR(32) DEFAULT 'PENDING',
    result_message TEXT COMMENT '结果消息',
    owner_id BIGINT,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_dispatch_code (dispatch_code),
    INDEX idx_crowd_code (crowd_code),
    INDEX idx_status (status)
) COMMENT='人群分发表';
```

### 2.4 人群更新表 (crowd_update)

```sql
CREATE TABLE crowd_update (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    update_code VARCHAR(64) NOT NULL UNIQUE,
    crowd_code VARCHAR(64) NOT NULL,
    update_type VARCHAR(32) NOT NULL COMMENT 'FULL/INCREMENTAL',
    strategy_config JSON COMMENT '更新策略配置',
    schedule_time DATETIME COMMENT '计划更新时间',
    status VARCHAR(32) DEFAULT 'PENDING',
    last_update_time DATETIME COMMENT '最后更新时间',
    owner_id BIGINT,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_update_code (update_code),
    INDEX idx_crowd_code (crowd_code)
) COMMENT='人群更新表';
```

### 2.5 人群版本表 (crowd_version)

```sql
CREATE TABLE crowd_version (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    version_code VARCHAR(64) NOT NULL UNIQUE,
    crowd_code VARCHAR(64) NOT NULL,
    version_num INT NOT NULL,
    crowd_count INT NOT NULL,
    rule_config JSON COMMENT '规则配置快照',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_version_code (version_code),
    INDEX idx_crowd_code (crowd_code)
) COMMENT='人群版本表';
```

## 四、核心流程

### 4.1 人群圈选流程

```
用户 → 配置规则 → 预览人数 → 保存人群 → 生成人群包
```

### 4.2 人群分发流程

```
用户 → 选择人群 → 配置目标 → 提交分发 → 执行分发 → 分发结果
```

### 4.3 画像生成流程

```
触发 → 聚合查询 → 统计计算 → 生成报告 → 缓存结果
```
