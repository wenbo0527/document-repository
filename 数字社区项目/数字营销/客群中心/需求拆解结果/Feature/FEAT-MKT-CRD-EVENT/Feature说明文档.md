## 2. FP 清单

### FP-MKT-CRD-EVENT-001 事件管理

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-CRD-EVENT-001 |
| 功能点名称 | 事件管理 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：统一管理所有用户行为事件，支持事件的增删改查；每个事件包含事件名称、描述、属性列表（属性名/类型/默认值）；支持事件元数据维护（创建人/创建时间/状态/数据表映射）；支持事件上下架管理。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 支持创建/编辑/删除/上下架事件；事件属性支持String/Number/Boolean/Date四种类型；事件删除前校验是否有标签或人群引用，有引用时提示"该事件已被N个对象引用，不可删除"；事件列表按创建时间倒序 |
| 操作验收 | 事件列表搜索响应时间<1秒；编辑事件后元数据自动更新；批量上下架操作（≤100个）响应时间<5秒；分页加载（每页50条）流畅无白屏 |
| 数据验收 | 事件属性类型与数据仓库字段类型一致；删除事件后已引用该事件的标签计算结果不受影响（保留历史快照）；事件统计数据与数据源数据一致（抽样验证） |
| 交互验收 | 事件列表支持按名称/状态/创建人筛选；新建事件时属性字段动态增减；事件状态变更（上下架）操作需二次确认；删除事件显示红色警示提示 |

### FP-MKT-CRD-EVENT-002 事件分析

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-CRD-EVENT-002 |
| 功能点名称 | 事件分析 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：提供事件维度的统计分析能力，支持事件趋势分析（按小时/日/周/月查看事件触发量走势）、漏斗分析（定义步骤序列查看转化率）、留存分析（分析事件对用户留存的影响）。支持自定义时间范围和维度拆分。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 事件趋势支持小时/日/周/月粒度切换；漏斗分析支持2-10步自定义；留存分析支持自定义起始事件和留存周期；支持导出分析结果（CSV格式） |
| 操作验收 | 趋势图渲染时间<3秒（30天数据）；漏斗图每个步骤显示转化率数值；留存表支持横向滚动查看所有周期；时间范围选择器支持快捷日期（近7天/近30天/自定义） |
| 数据验收 | 趋势数据与数据仓库直接查询结果偏差<0.1%；漏斗转化率=下一步人数/上一步人数×100%；留存率=第N天回访人数/首日人数×100%，计算口径与行业标准一致 |
| 交互验收 | 图表支持鼠标悬停显示具体数值；支持图表放大至全屏；无数据时显示空状态插画和提示文案；切换维度时图表平滑过渡无闪烁 |

### FP-MKT-CRD-EVENT-003 数据源接入

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-CRD-EVENT-003 |
| 功能点名称 | 数据源接入 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：支持多渠道数据源接入，包括Kafka实时消息队列（配置topic和consumer group）、HTTP API推送（生成webhook地址接收事件）、文件导入（CSV/JSON定时拉取或手动上传）。接入时自动进行数据Schema映射和字段清洗。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 支持Kafka/Api/文件三种接入方式；Kafka接入需配置broker、topic、group.id；API接入生成唯一webhook地址，支持GET/POST；文件接入支持CSV/JSON格式，单文件上限500MB |
| 操作验收 | Kafka连接测试响应时间<5秒（成功/失败提示）；API webhook地址一键复制；文件上传进度条实时显示；数据源列表显示最后同步时间和状态 |
| 数据验收 | Kafka消费数据延迟<30秒；文件导入数据条数与源文件一致（清洗后）；Schema映射字段一一对应，无遗漏；API推送数据丢包率<0.01% |
| 交互验收 | 数据源接入向导步骤不超过5步；测试连接通过后下一步按钮才可点击；导入失败时高亮失败行并提示原因；支持数据源启停切换 |
