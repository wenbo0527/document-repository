## 2. FP 清单

### FP-MKT-CRD-SYSTEM-001 权限配置

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-CRD-SYSTEM-001 |
| 功能点名称 | 权限配置 |
| 类型 | 功能点 |
| 优先级 | P1 |
| 状态 | 已上线 |

**功能描述**：基于RBAC模型管理用户权限，支持创建/编辑/删除角色（如数据分析师/营销经理/管理员），为角色分配功能权限（标签管理/人群管理/事件管理等模块级权限）和数据权限（可见部门/可见标签范围）。支持为用户分配单个或多个角色。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 支持创建/编辑/删除角色；角色权限精确到模块级功能点；支持为用户分配多个角色（权限取并集）；支持数据权限范围配置（全部/本部门/自定义） |
| 操作验收 | 角色创建后默认未激活，需配置权限后手动启用；权限变更保存后5分钟内生效；用户列表加载响应时间<2秒；不支持删除已被用户使用的角色（提示先解绑） |
| 数据验收 | 用户权限=所有角色权限的并集；数据权限范围配置精确到人；权限变更日志完整记录（变更人/变更时间/变更内容）；超级管理员角色不可删除或修改 |
| 交互验收 | 权限树形结构展示，支持勾选/取消勾选；权限变更时高亮显示变更项；已分配角色的用户显示角色标签；无权限时操作按钮置灰并提示"无权限" |

### FP-MKT-CRD-SYSTEM-002 系统参数

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-CRD-SYSTEM-002 |
| 功能点名称 | 系统参数 |
| 类型 | 功能点 |
| 优先级 | P1 |
| 状态 | 已上线 |

**功能描述**：提供系统级参数配置能力，包括计算引擎参数（并发数/超时时间/重试次数）、数据源参数（连接池大小/查询超时）、通知参数（钉钉/企微 webhook 配置）、缓存策略（TTL/刷新周期）等。参数修改需记录变更日志。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 支持对计算/数据源/通知/缓存四类参数配置；参数修改前需二次确认；敏感参数（如数据库密码）加密展示；支持参数恢复默认值 |
| 操作验收 | 参数保存后自动应用，无需重启服务；参数校验失败时阻止保存并提示错误原因；参数列表支持按类别筛选；修改人记录自动写入审计日志 |
| 数据验收 | 参数值类型与预设类型一致（整数/字符串/布尔/JSON）；修改参数后系统运行不受影响（参数隔离）；缓存TTL最小值=1分钟，最大值=30天 |
| 交互验收 | 整数参数支持步进器微调；JSON参数提供格式化展示和编辑模式切换；必填参数空缺时保存按钮置灰；参数修改后显示toast"配置已保存" |

### FP-MKT-CRD-SYSTEM-003 审计日志

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-CRD-SYSTEM-003 |
| 功能点名称 | 审计日志 |
| 类型 | 功能点 |
| 优先级 | P1 |
| 状态 | 已上线 |

**功能描述**：记录所有用户在系统中的关键操作行为，包括标签/人群/事件的增删改、权限变更、登录登出、系统参数修改等。日志内容包括操作人/操作时间/操作类型/操作对象/操作前后内容差异。支持按时间范围/操作类型/操作人筛选。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 记录操作类型覆盖增删改查；日志保留周期=180天（可配置）；支持按时间范围/操作类型/操作人/对象名称搜索；支持导出日志（Excel格式） |
| 操作验收 | 日志列表加载时间<3秒（单次查询1万条以内）；时间范围筛选支持快捷选项（今天/近7天/近30天/自定义）；导出万级日志响应时间<30秒；日志列表实时刷新（30秒轮询） |
| 数据验收 | 日志记录完整性=100%（关键操作不遗漏）；操作前后内容差异以JSON格式完整记录；日志数据不可删除和修改（仅追加）；登录日志与LDAP/SSO登录记录一致 |
| 交互验收 | 日志行支持展开查看详情；操作对象名称点击跳转至对应详情页；高危操作（删除/权限变更）日志标红突出；空结果搜索显示"未找到匹配的日志记录" |
