## 2. FP 清单

### FP-MKT-CRD-LIST-001 人群创建

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-CRD-LIST-001 |
| 功能点名称 | 人群创建 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：支持通过交（AND）、并（OR）、差（NOT）组合多个标签或行为条件创建人群；支持行为序列圈选（"先做A事件，在30天内再做B事件"）；支持属性筛选（地域/年龄/设备等基础属性）；人群创建后可命名、保存和复制。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 支持标签+属性+行为序列的组合圈选；支持交、并、差三种逻辑组合；可保存为标准化人群包并分配唯一ID；支持人群包复制和编辑；相同名称人群包不允许重复创建 |
| 操作验收 | 条件组合界面拖拽操作流畅（帧率≥30fps）；人群规模实时预览更新延迟<3秒；保存人群后自动跳转至人群详情页；人群列表加载时间<2秒 |
| 数据验收 | 交并差计算结果与SQL逻辑一致（抽样验证100条）；人群规模估算值与实际计算值偏差<5%；人群包数据导出CSV格式正确，字段一一对应 |
| 交互验收 | 拖拽标签至组合区时高亮提示可放置位置；条件组合支持嵌套显示；预览面板固定在页面右侧；保存时若人群为0人则提示"当前条件无人群，请调整条件" |

### FP-MKT-CRD-LIST-002 人群估算

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-CRD-LIST-002 |
| 功能点名称 | 人群估算 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：基于已选条件实时计算预估人群规模；提供人群规模分布图（按地域/年龄/性别等维度拆解）；支持估算结果与历史人群规模对比；当条件变更时实时刷新估算值。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 实时返回人群规模数字（精确到个位）；支持按地域/年龄/性别/设备等维度拆分人群分布；支持与已有人群包进行规模对比；条件变更触发自动重算 |
| 操作验收 | 估算请求响应时间<5秒（1000万用户规模）；分布图渲染时间<2秒；对比历史人群时展示差异百分比；支持一键展开/折叠各维度分布 |
| 数据验收 | 估算规模与实际跑批人群数偏差<5%；分布图各维度占比之和=100%（允许±1%误差）；对比结果数值精确到小数点后2位 |
| 交互验收 | 分布图默认以饼图展示，支持切换为柱状图；鼠标悬停显示具体数值tooltip；加载中显示骨架屏而非空白页；数据异常时显示"数据加载失败，请重试" |

### FP-MKT-CRD-LIST-003 人群对比

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-CRD-LIST-003 |
| 功能点名称 | 人群对比 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：支持同时选择2-5个人群包进行多维度特征对比分析；对比维度包括基础属性（年龄/性别/地域分布）、行为特征（活跃度/购买频次）、标签覆盖度等；输出对比报告并支持导出。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 支持同时对比2-5个人群包；对比维度覆盖基础属性、行为特征、标签覆盖度；支持导出对比报告（PDF/Excel格式）；对比数据自动缓存5分钟 |
| 操作验收 | 选择人群后5秒内展示对比结果；切换对比维度时图表平滑过渡；导出PDF响应时间<10秒；对比人群超过5个时提示"最多支持5个对比" |
| 数据验收 | 各人群同一维度数值加和不超过总人群数的100%；标签覆盖度计算口径一致；导出Excel列数与对比维度一一对应；对比报告数据与界面显示数据一致 |
| 交互验收 | 人群选择面板支持搜索；被选中对比的人群高亮标记；各维度图表可独立放大查看；无交集人群提示"两个人群无重叠特征" |
