## 2. FP 清单

### FP-MKT-CRD-TAG-001 标签创建

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-CRD-TAG-001 |
| 功能点名称 | 标签创建 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：支持创建三种类型的标签——规则标签（通过条件组合定义，如"近30天购买次数≥3"）、算法标签（调用机器学习模型输出，如用户流失概率分群）、导入标签（通过CSV/Excel批量导入静态人群）。用户可配置标签名称、描述、数据源、计算周期等属性。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 支持创建规则标签、算法标签、导入标签三种类型；标签创建后自动入库并分配唯一ID；支持编辑和删除草稿状态标签；标签名称不允许重复（同名拦截提示） |
| 操作验收 | 创建流程不超过5步；保存后页面自动刷新显示新标签；加载标签列表响应时间<2秒；导入文件大小上限100MB，支持xlsx/csv格式 |
| 数据验收 | 导入标签数据与源文件行数一致（不含表头）；规则标签SQL预览与实际计算结果一致；标签覆盖率=打标人数/总人数，符合预期 |
| 交互验收 | 标签类型切换时表单字段动态变化；必填字段空缺时保存按钮置灰；创建成功 toast 提示"标签创建成功"；标签列表支持按名称/类型/状态筛选 |

### FP-MKT-CRD-TAG-002 标签分类

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-CRD-TAG-002 |
| 功能点名称 | 标签分类 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：支持层级分类管理（最多3级类目），可创建标签组并对标签进行归类；提供拖拽排序功能调整标签在列表中的展示顺序；支持批量移动标签到指定分类；分类名称唯一性校验。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 支持创建/编辑/删除最多3级分类；标签可归属于某个分类或无分类；支持批量选择标签（≤500个）并移动到目标分类；同级别分类名称不允许重复 |
| 操作验收 | 拖拽分类节点重新排序后自动保存；批量移动操作完成后显示移动数量；分类树支持展开/折叠；切换分类后标签列表过滤响应时间<1秒 |
| 数据验收 | 分类删除时，若该分类下有标签，则提示"该分类下存在N个标签，请先迁移"；移动标签后原分类标签数实时更新；分类顺序调整后列表顺序一致 |
| 交互验收 | 右键分类节点显示上下文菜单（新增/编辑/删除）；批量选择时显示已选数量角标；无分类标签默认显示在"未分类"节点下；分类树支持关键字搜索定位 |

### FP-MKT-CRD-TAG-003 标签计算

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-CRD-TAG-003 |
| 功能点名称 | 标签计算 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：支持实时计算（用户行为触发即时打标）、离线计算（T+1批量任务）和增量更新（仅处理新增或变更数据）三种模式。用户可配置计算周期（小时/日/周/月），查看计算任务历史记录和状态，支持失败重试。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 支持实时/离线/增量三种计算模式；可配置计算周期（小时/日/周/月）；计算任务失败后支持手动重试；计算历史记录保留90天 |
| 操作验收 | 触发计算后展示任务ID和预计完成时间；任务状态实时更新（等待中/运行中/成功/失败）；失败任务显示错误日志摘要；手动重试操作响应时间<3秒 |
| 数据验收 | 离线计算T+1任务在次日0点前完成；增量更新仅处理变更数据，对全量数据无影响；计算结果与SQL预览偏差<0.1%；标签值分布与历史基线对比偏差在±5%以内 |
| 交互验收 | 任务列表按创建时间倒序排列；失败任务行标红突出显示；支持按任务状态筛选；计算进度条实时更新（百分比）；支持查看计算SQL详情 |
