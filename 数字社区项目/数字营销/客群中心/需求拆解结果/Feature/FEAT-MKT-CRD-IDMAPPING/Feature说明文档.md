## 2. FP 清单

### FP-MKT-CRD-IDMAPPING-001 ID关联

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-CRD-IDMAPPING-001 |
| 功能点名称 | ID关联 |
| 类型 | 功能点 |
| 优先级 | P1 |
| 状态 | 已上线 |

**功能描述**：支持将同一个自然人的多个ID（手机号/邮箱/身份证/设备ID/账号ID等）进行关联合并，构建统一身份档案；基于规则（如相同手机号+相同设备）或算法（如相似行为画像）进行身份自动合并；支持人工审核确认自动合并结果；支持ID关联关系查询和导出。

**验收标准**：

| 验收项 | 标准 |
|:---|
| 功能验收 | 支持至少5种ID类型关联（手机/邮箱/身份证/DeviceID/用户ID）；自动合并规则可配置（支持AND/OR组合）；自动合并结果需人工确认后才正式生效；支持查看每个身份档案下的全部关联ID |
| 操作验收 | 关联关系查询响应时间<2秒（百万级数据）；批量合并操作（≤1000条）响应时间<10秒；合并确认页面展示所有候选ID及置信度；关联关系导出支持CSV格式 |
| 数据验收 | 合并后去重人数=原始人数-重复人数，精确匹配；自动合并准确率≥95%（基于样本评估）；关联关系变更记录完整（合并时间/操作人/合并依据）；身份档案一人一档，无重复 |
| 交互验收 | 合并确认页面支持批量勾选确认；高置信度（≥90%）自动通过无需审核；低置信度（<70%）高亮提醒；合并失败时展示失败原因（ID类型冲突/数据格式错误） |

### FP-MKT-CRD-IDMAPPING-002 ID查询

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-CRD-IDMAPPING-002 |
| 功能点名称 | ID查询 |
| 类型 | 功能点 |
| 优先级 | P1 |
| 状态 | 已上线 |

**功能描述**：提供基于任意ID的快速搜索和定位功能，支持单ID查询和批量查询（最多100个ID）；返回该ID关联的所有其他ID及身份档案基本信息；支持模糊搜索（部分匹配）和精确搜索（完全匹配）；查询结果支持导出。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 支持单ID查询和批量查询（批量上限100个）；支持手机号/邮箱/身份证/DeviceID/用户ID五类ID查询；查询结果展示所有关联ID及关联置信度；支持查询结果导出CSV |
| 操作验收 | 单ID查询响应时间<1秒；批量查询（100个ID）响应时间<5秒；查询结果分页展示（每页20条）；支持复制查询结果中的任意ID值 |
| 数据验收 | 查询结果与数据仓库数据一致（抽样验证100条）；批量查询返回结果与单条查询结果一一对应；导出CSV字段与页面显示字段一致 |
| 交互验收 | 输入框支持输入即搜索（防抖500ms）；无结果时显示"未找到匹配的ID，请检查输入或尝试其他ID类型"；批量查询展示进度条；支持查询历史记录（最近10条） |

### FP-MKT-CRD-IDMAPPING-003 ID质量

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-CRD-IDMAPPING-003 |
| 功能点名称 | ID质量 |
| 类型 | 功能点 |
| 优先级 | P1 |
| 状态 | 已上线 |

**功能描述**：提供ID数据质量监控能力，覆盖三大维度——覆盖率（各ID类型在用户中的覆盖比例）、稳定性（ID发生变更的频率监控）、准确性（ID格式校验和有效率分析）。支持配置质量告警阈值，当指标低于阈值时触发通知。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 覆盖率统计支持按各ID类型分别计算；稳定性监控支持按日/周/月粒度；准确性校验支持手机号/身份证/邮箱格式规则；支持配置质量告警阈值（覆盖率<80%/变更率>20%/准确率<95%） |
| 操作验收 | 质量报告生成时间<10秒；告警触发后5分钟内发送通知（企微/钉钉）；质量趋势图支持时间范围切换；支持手动刷新质量指标 |
| 数据验收 | 覆盖率=拥有该类型ID的用户数/总用户数×100%；变更率=周期内ID发生变更的用户数/总用户数×100%；准确性=有效ID数/总ID数×100%；告警历史保留90天 |
| 交互验收 | 质量仪表盘以雷达图/仪表盘形式可视化展示；低于阈值的指标标红预警；支持点击指标查看明细数据；无数据指标灰化显示并提示"数据不足" |
