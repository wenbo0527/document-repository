## 1. 产品域概述

### 1.1 基本信息

| 字段 | 内容 |
|:---|:---|
| 产品域 ID | PD-MKT |
| 产品域名称 | 数字营销 |
| 英文名 | Digital Marketing |
| 所属业务线 | 企业数字化 |
| 产品负责人 | Tony Stark |
| 创建日期 | 2026-04-24 |

### 1.2 产品域定位

数字营销产品域聚焦于企业数字化营销能力建设，覆盖客户洞察、营销触达、权益管理、电销支持等核心业务场景。

### 1.3 核心价值

| 价值维度 | 说明 |
|:---|:---|
| 用户价值 | 精准客户分群，个性化营销触达 |
| 业务价值 | 提升营销效率，降低获客成本 |
| 技术价值 | 构建营销数据闭环，支撑运营决策 |

### 1.4 覆盖业务场景

1. 场景1：客户分群与画像分析
2. 场景2：营销流程编排与自动化
3. 场景3：多渠道触达（短信/推送/邮件）
4. 场景4：积分/权益管理
5. 场景5：电销业务支持

| 标签管理 | 标签加工、标签市场、标签订阅、标签血缘 | 统一标签资产，避免标签重复建设 | 🟢已实现 |
