## 一、产品概述

### 1.1 功能简介

权益中心是数字营销的核心模块，提供统一的权益类型管理、发放、核销、风控和分析能力。

### 1.2 核心功能

| 功能 | 说明 |
|:---|:---|
| 权益类型管理 | 配置和管理权益类型、模板、批次 |
| 权益发放 | 创建、审批和执行权益发放任务 |
| 权益核销 | 核销、查询和退回用户权益 |
| 权益风控 | 配置风控规则、检测异常、生成报表 |
| 权益分析 | 发放分析、核销分析、ROI分析 |

## 八、常见问题

### Q1: 如何添加新的权益类型？
**A**：在类型管理页面点击「添加类型」，选择权益类型并配置参数，保存即可。

### Q2: 权益发放被驳回怎么办？
**A**：查看驳回意见，根据意见修改发放任务参数后重新提交审批。

### Q3: 权益核销失败如何处理？
**A**：检查核销条件（有效期、使用限制等），确认满足条件后重试。

### Q4: 如何设置风控规则？
**A**：在风控中心点击「添加规则」，选择规则类型并配置参数，保存规则后启用。
