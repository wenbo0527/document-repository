## 一、系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                    前端层 (Vue3 + Element Plus)              │
├─────────────────────────────────────────────────────────────┤
│  类型管理    权益发放    权益核销    风控中心    数据分析       │
├─────────────────────────────────────────────────────────────┤
│                    服务层 (Java Spring Boot)                  │
│  类型服务    发放服务    核销服务    风控服务    分析服务      │

│                    数据层                                     │
│     MySQL     Redis      Kafka       ClickHouse              │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 技术栈

| 层级 | 技术选型 | 说明 |
|:---|:---|:---|
| 前端 | Vue3 + TypeScript | 组件化开发 |
| 后端 | Java Spring Boot 2.7 | 业务逻辑处理 |
| 数据库 | MySQL 8.0 | 权益类型、模板、批次元数据 |

| 分析引擎 | ClickHouse | 权益效果分析 |

## 二、数据库设计

### 2.1 权益类型表 (coupon_type)

```sql
CREATE TABLE coupon_type (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    type_code VARCHAR(64) NOT NULL UNIQUE,
    type_name VARCHAR(128) NOT NULL,
    type_kind VARCHAR(32) NOT NULL COMMENT 'COUPON/POINT/MEMBER/GIFTCARD',
    status VARCHAR(32) DEFAULT 'ACTIVE',
    config JSON COMMENT '权益配置',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_type_code (type_code),
    INDEX idx_type_kind (type_kind)
) COMMENT='权益类型表';
```

### 2.2 权益模板表 (coupon_template)

```sql
CREATE TABLE coupon_template (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    template_code VARCHAR(64) NOT NULL UNIQUE,
    template_name VARCHAR(128) NOT NULL,
    type_code VARCHAR(64) NOT NULL,
    face_value DECIMAL(10,2) COMMENT '面值',
    validity_days INT COMMENT '有效期天数',
    validity_start DATETIME COMMENT '有效期开始',
    validity_end DATETIME COMMENT '有效期结束',
    status VARCHAR(32) DEFAULT 'DRAFT',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_template_code (template_code),
    INDEX idx_type_code (type_code)
) COMMENT='权益模板表';
```

### 2.3 权益批次表 (coupon_batch)

```sql
CREATE TABLE coupon_batch (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    batch_code VARCHAR(64) NOT NULL UNIQUE,
    template_code VARCHAR(64) NOT NULL,
    total_count INT NOT NULL,
    remain_count INT NOT NULL,
    status VARCHAR(32) DEFAULT 'ACTIVE',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_batch_code (batch_code)
) COMMENT='权益批次表';
```

### 2.4 用户权益表 (user_coupon)

```sql
CREATE TABLE user_coupon (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    coupon_code VARCHAR(64) NOT NULL UNIQUE,
    user_id VARCHAR(64) NOT NULL,
    type_code VARCHAR(64) NOT NULL,
    template_code VARCHAR(64) NOT NULL,
    batch_code VARCHAR(64) NOT NULL,
    status VARCHAR(32) DEFAULT 'UNUSED' COMMENT 'UNUSED/USED/EXPIRED/RETURNED',
    get_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    use_time DATETIME COMMENT '核销时间',
    expire_time DATETIME COMMENT '过期时间',
    INDEX idx_coupon_code (coupon_code),
    INDEX idx_user_id (user_id),
    INDEX idx_status (status)
) COMMENT='用户权益表';
```

### 2.5 发放任务表 (grant_task)

```sql
CREATE TABLE grant_task (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    task_code VARCHAR(64) NOT NULL UNIQUE,
    task_name VARCHAR(128) NOT NULL,
    type_code VARCHAR(64) NOT NULL,
    template_code VARCHAR(64) NOT NULL,
    target_type VARCHAR(32) NOT NULL COMMENT 'ALL/TAG/USER',
    target_config JSON COMMENT '目标配置',
    grant_type VARCHAR(32) NOT NULL COMMENT 'IMMEDIATE/SCHEDULED',
    schedule_time DATETIME,
    status VARCHAR(32) DEFAULT 'DRAFT',
    total_count INT DEFAULT 0,
    success_count INT DEFAULT 0,
    owner_id BIGINT,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_task_code (task_code),
    INDEX idx_status (status)
) COMMENT='发放任务表';
```

## 四、核心流程

### 4.1 权益发放流程

```
用户 → 创建任务 → 审批通过 → 启动发放 → 生成权益 → 领取记录 → 用户账户
```

### 4.2 权益核销流程

```
用户出示权益 → 核销验证 → 风控检查 → 权益状态更新 → 核销记录
```

### 4.3 风控检查流程

```
领取请求 → 风控服务 → 规则匹配 → 通过/拒绝 → 异常记录
```

### 5.1 性能设计

| 指标 | 目标 | 方案 |
|:---|:---|:---|
| 权益发放延迟 | ≤ 3秒 | Kafka异步+批量处理 |
