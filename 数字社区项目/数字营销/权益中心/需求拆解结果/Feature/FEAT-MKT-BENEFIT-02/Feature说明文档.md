## 2. 功能描述

券模板管理提供优惠券模板的创建、编辑、详情查看和删除功能。用户可以配置券的基本信息、发放规则、使用条件等。

## 2. FP 清单

### FP-MKT-COUPON-TYPE-001 权益类型配置

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-COUPON-TYPE-001 |
| 功能点名称 | 权益类型配置 |
| 类型 | 功能点 |

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 权益类型配置保存正常，类型状态管理准确 |

| 数据验收 | 类型配置正确存储，与权益模板关联准确；权益类型列表最大条目数≤100条；单类型配置数据大小≤1KB；

## 2.3 用户场景

| 场景 | 用户 | 描述 |
|:---|:---|:---|
| 场景1 | 运营人员 | 创建新的优惠券模板，配置券类型（免息券/折扣券/入场券/锁定券）、适用范围、有效期 |
| 场景2 | 运营人员 | 编辑已有券模板，修改模板参数后保存 |
| 场景3 | 运营人员 | 查看券模板详情，了解模板的完整配置信息 |
| 场景4 | 运营人员 | 复制已有券模板，快速创建相似的新模板 |
| 场景5 | 运营人员 | 对券模板进行上下线操作，切换模板的启用状态 |
| 场景6 | 运营人员 | 按券类型筛选券模板列表，快速定位目标模板 |
| 场景7 | 运营人员 | 删除草稿状态的券模板 |
| 场景8 | 客服人员 | 根据券模板ID或名称查询模板详情，解答用户咨询 |
