## 2. 功能描述

券库存管理提供优惠券库存的查询和管理功能，包括库存预警、库存充值、库存流水查看等。

## 2. FP 清单

### FP-MKT-COUPON-REDEEM-001 权益核销

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-COUPON-REDEEM-001 |
| 功能点名称 | 权益核销 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：支持多种核销方式（扫码核销/API核销/手动核销），核销时验证权益有效性并更新状态。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 权益核销流程正常，状态更新准确 |
| 操作验收 | 扫码核销<500ms，API核销<1s |
| 数据验收 | 核销记录正确存储，状态变更有日志；单次API核销请求记录数≤100条；核销流水ID最大字符数≤32；
| 交互验收 | 核销反馈及时（声音/震动），异常提示清晰 |

### FP-MKT-COUPON-REDEEM-002 权益查询

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-COUPON-REDEEM-002 |
| 功能点名称 | 权益查询 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：用户查询个人可用权益列表，展示权益名称、状态、有效期，支持按状态和类型筛选。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 权益查询响应正常，列表展示准确 |
| 操作验收 | 查询响应<1s，筛选切换流畅 |
| 数据验收 | 权益数据与用户实际一致，状态准确；单用户权益列表最大条目数≤200条；权益名称最大字符数≤100；
| 交互验收 | 权益卡片展示清晰，支持点击查看详情 |

### FP-MKT-COUPON-REDEEM-003 权益退回

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-COUPON-REDEEM-003 |
| 功能点名称 | 权益退回 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：对已发放但未使用的权益进行退回操作，退回后权益状态更新，用户不再可用。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 权益退回功能正常，退回后用户不可用 |
| 操作验收 | 退回操作<2s，确认提示清晰 |
| 数据验收 | 退回记录完整，权益状态正确变更；单次退回操作最大券数量≤100张；退回原因最大字符数≤500；
| 交互验收 | 退回需二次确认，退回原因必填 |

### FP-MKT-COUPON-REDEEM-004 核销记录

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-COUPON-REDEEM-004 |
| 功能点名称 | 核销记录 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：查询权益核销的历史记录，包括核销时间、核销渠道、核销门店/用户、核销操作人。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 核销记录查询正常，数据完整 |
| 操作验收 | 记录查询<2s，支持时间范围筛选 |
| 数据验收 | 记录数据与实际核销一致，可导出；单次查询记录数≤1000条；记录保留周期≥2年；导出字段可配；
| 交互验收 | 支持多维度筛选，筛选条件可保存 |

## 2.3 用户场景

| 场景 | 用户 | 描述 |
|:---|:---|:---|
| 场景1 | 核销人员 | 使用扫码枪扫码核销优惠券，系统验证权益有效性并更新状态 |
| 场景2 | 系统 | 通过API接口自动核销权益，支持实时计算和批量处理 |
| 场景3 | 客服人员 | 帮助用户查询个人可用权益列表，展示权益名称、状态、有效期 |
| 场景4 | 运营人员 | 对已发放但未使用的权益进行退回操作，退回后用户不可用 |
| 场景5 | 运营人员 | 查询权益核销的历史记录，包括核销时间、渠道、门店/用户、操作人 |
| 场景6 | 客服人员 | 查询特定用户的核销记录，解答用户关于权益使用的咨询 |
| 场景7 | 运营人员 | 按时间范围和核销渠道筛选核销记录，支持数据导出 |
