## 2. 功能描述

预警管理提供权益业务的风险预警功能，包括预警规则配置、预警历史查询、预警通知设置等。当权益发放出现异常情况时，系统会自动触发预警通知。

---

## 2. FP 清单

### FP-MKT-COUPON-RISK-001 风控规则

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-COUPON-RISK-001 |
| 功能点名称 | 风控规则 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：配置权益风控规则，包括用户领取上限、领取频率限制、设备限制、IP限制，支持规则测试。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 风控规则配置保存正常，规则生效 |
| 操作验收 | 规则配置<2s，规则测试<3s |
| 数据验收 | 规则数据正确存储，优先级逻辑正确；单用户同一权益最多限领次数≤100次；单设备绑定权益数量上限≤50个；IP段限制支持CIDR格式；
| 交互验收 | 规则条件可视化配置，测试反馈清晰 |

### FP-MKT-COUPON-RISK-002 异常检测

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-COUPON-RISK-002 |
| 功能点名称 | 异常检测 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：实时检测权益领取和使用的异常行为，包括机器批量领取、套现行为、账户关联异常。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 异常检测正常，检测结果准确 |
| 操作验收 | 检测实时，异常标记<1s |
| 数据验收 | 异常记录完整，与用户和权益关联；单次批量检测最大记录数≤10万条；异常标记响应时间≤1s；异常记录保留周期≥2年；
| 交互验收 | 异常告警通知及时，支持人工审核 |

## 2.3 用户场景

| 场景 | 用户 | 描述 |
|:---|:---|:---|
| 场景1 | 运营人员 | 配置权益风控规则，包括用户领取上限、领取频率限制 |
| 场景2 | 运营人员 | 配置设备限制和IP限制，防止批量领取 |
| 场景3 | 运营人员 | 测试风控规则，验证规则配置是否生效 |
| 场景4 | 系统 | 实时检测权益领取和使用的异常行为，包括机器批量领取、套现行为 |
| 场景5 | 运营人员 | 查看异常检测结果，对标记的异常进行人工审核 |
| 场景6 | 客服人员 | 查看用户的异常领取记录，解答相关咨询 |
| 场景7 | 管理人员 | 查看权益风险预警概览，了解整体风控状况 |
