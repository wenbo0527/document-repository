## 2. 功能描述

权益数据统计看板提供权益数据的统计分析和可视化展示，包括发放统计、核销统计、ROI分析等，支持自定义时间范围和维度筛选。

---

## 2. FP 清单

### FP-MKT-COUPON-ANAL-001 发放分析

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-COUPON-ANAL-001 |
| 功能点名称 | 发放分析 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：分析权益发放数据，包括发放量、发放渠道分布、发放人群画像，支持按时间/渠道/权益类型多维分析。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 发放分析数据准确，图表展示正常 |
| 操作验收 | 分析查询<3s，支持时间范围切换 |
| 数据验收 | 分析数据与实际发放一致；单次查询最大时间跨度≤365天；单次分析记录数≤10万条；渠道分布维度≤20个；
| 交互验收 | 支持图表类型切换，hover显示详情 |

## 2.3 用户场景

| 场景 | 用户 | 描述 |
|:---|:---|:---|
| 场景1 | 运营人员 | 查看权益发放分析数据，包括发放量、发放渠道分布、发放人群画像 |
| 场景2 | 运营人员 | 查看权益核销分析数据，包括核销量、核销率、核销渠道、核销时间分布 |
| 场景3 | 运营人员 | 分析营销转化漏斗，识别领券到核销各环节的流失情况 |
| 场景4 | 运营人员 | 计算权益投入产出比，配置成本参数，查看ROI系数 |
| 场景5 | 运营人员 | 导出权益分析数据，支持Excel格式，配置导出字段和时间范围 |
| 场景6 | 运营人员 | 切换分析图表类型（柱状图/折线图/饼图），支持hover查看详情 |
| 场景7 | 管理人员 | 查看权益统计分析看板，了解整体权益运营状况 |
