## 2. 功能描述

权益概览是权益中心的入口页面，提供权益发放数据概览和快捷入口。用户可以快速查看权益整体情况，包括发放总量、领取量、核销量等核心指标。

---

## 2.3 用户场景

| 场景 | 用户 | 描述 |
|:---|:---|:---|
| 场景1 | 运营人员 | 进入权益首页，查看权益整体数据概览，包括发放总量、领取量、核销量等核心指标 |
| 场景2 | 运营人员 | 查看营销转化漏斗图表，了解从权益发放到核销的转化情况 |
| 场景3 | 运营人员 | 查看营销效果趋势图表，分析权益发放效果随时间的变化 |
| 场景4 | 运营人员 | 查看最近营销活动列表，了解活动基本信息（名称、类型、时间、预算、状态） |
| 场景5 | 运营人员 | 点击活动列表中的"查看"按钮，查看单个营销活动的详细信息 |
| 场景6 | 运营人员 | 点击活动列表中的"编辑"按钮，编辑营销活动配置 |
