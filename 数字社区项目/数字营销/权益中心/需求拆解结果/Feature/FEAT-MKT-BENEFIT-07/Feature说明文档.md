## 2. 功能描述

库存查询提供券库存的批量查询和管理功能，用户可以查看各券模板的库存数量、库存预警阈值、库存变更历史等。

## 2. FP 清单

### FP-MKT-COUPON-INV-001 库存查询

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-COUPON-INV-001 |
| 功能点名称 | 库存查询 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：查询各权益的当前库存，包括总库存、已发放库存、可用库存，支持按权益类型和状态筛选。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 库存查询数据准确，库存数据实时 |
| 操作验收 | 查询响应<1s，切换筛选流畅 |
| 数据验收 | 库存数据与实际一致，误差=0 |
| 交互验收 | 库存预警高亮显示，支持导出库存报表 |

### FP-MKT-COUPON-INV-002 库存预警

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-COUPON-INV-002 |
| 功能点名称 | 库存预警 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：配置库存预警规则，当库存低于阈值时自动发送预警通知（站内信/短信/邮件）。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 库存预警配置生效，预警触发及时 |
| 操作验收 | 预警配置<2s，预警检测间隔可配 |
| 数据验收 | 预警规则正确存储，预警记录完整 |
| 交互验收 | 预警规则配置清晰，支持阈值测试 |
