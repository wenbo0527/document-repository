## 2. 功能描述

券包管理提供券包（优惠券组合包）的创建、编辑、详情查看功能。管理员可以配置券包的内容、有效期、发放规则等。

---

## 2. FP 清单

### FP-MKT-COUPON-GRANT-001 发放任务

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-COUPON-GRANT-001 |
| 功能点名称 | 发放任务 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：创建权益发放任务，选择目标人群、权益类型和数量，配置发放时间（即时/定时），支持定向发放和批量发放。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 发放任务创建正常，任务配置完整 |
| 操作验收 | 任务创建<5s，人群选择<3s |
| 数据验收 | 任务数据正确存储，关联人群和权益；单任务最大发放数量≤100万张；任务名称最大字符数≤100；定时发放支持最多提前90天配置；
| 交互验收 | 任务配置向导清晰，创建后自动跳转详情 |

### FP-MKT-COUPON-GRANT-002 发放审批

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-COUPON-GRANT-002 |
| 功能点名称 | 发放审批 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：大额或重要权益发放需审批，审批人审核任务信息，可批准/驳回/退回修改，支持审批意见记录。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 审批流程正常，审批结果生效 |
| 操作验收 | 审批操作<2s，审批意见必填 |
| 数据验收 | 审批记录完整，与任务关联准确；审批意见最大字符数≤500；单次审批记录数≤100条；
| 交互验收 | 审批详情展示清晰，驳回原因明确 |

### FP-MKT-COUPON-GRANT-003 发放记录

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-COUPON-GRANT-003 |

| 类型 | 功能点 |

**功能描述**：查看权益发放的历史记录，包括发放时间、发放数量、目标人群、发放状态和操作人。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 发放记录查询正常，数据完整 |

| 数据验收 | 记录数据与实际发放一致，可导出；单次查询记录数≤1000条；发放记录保留周期≥2年；导出字段可配；
| 交互验收 | 支持按状态/人群/时间筛选，详情查看便捷 |

## 2.3 用户场景

| 场景 | 用户 | 描述 |
|:---|:---|:---|
| 场景1 | 运营人员 | 创建权益发放任务，选择目标人群、权益类型和数量，配置发放时间（即时/定时） |
| 场景2 | 运营人员 | 创建批量发放任务，支持定向发放和批量发放 |
| 场景3 | 审批人员 | 审核大额或重要权益发放任务，查看任务信息，可批准/驳回/退回修改 |
| 场景4 | 运营人员 | 查看权益发放的历史记录，包括发放时间、数量、目标人群、状态和操作人 |
| 场景5 | 运营人员 | 查看发放统计数据，包括发放总量、发放成功量、发放失败量、发放成功率 |
| 场景6 | 运营人员 | 按时间/人群/状态维度筛选发放记录，支持数据导出 |
| 场景7 | 运营人员 | 快速审批所有待审批券库存，提高运营效率 |
