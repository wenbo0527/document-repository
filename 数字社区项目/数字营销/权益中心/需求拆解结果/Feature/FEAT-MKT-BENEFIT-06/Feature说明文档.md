## 2. 功能描述

权益日志记录所有权益相关的操作日志，包括发放记录、领取记录、核销记录、退回记录等。用户可以查看和导出操作日志。

---

## 2. FP 清单

### FP-MKT-COUPON-LOG-001 日志查询

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-COUPON-LOG-001 |
| 功能点名称 | 日志查询 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：查询权益相关操作日志，包括发放日志、核销日志、退回日志，支持按操作类型/时间/操作人筛选。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 日志查询功能正常，记录完整 |
| 操作验收 | 日志查询<2s，支持时间范围筛选 |
| 数据验收 | 日志数据与实际操作一致，不可删除；单次查询日志记录数≤1000条；日志保留周期≥2年；日志ID最大字符数≤32；
| 交互验收 | 支持按类型/操作人筛选，日志详情查看便捷 |

### FP-MKT-COUPON-LOG-002 日志导出

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-COUPON-LOG-002 |
| 功能点名称 | 日志导出 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：导出权益操作日志，支持Excel格式，可配置导出字段和时间范围，支持脱敏处理。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 日志导出功能正常，文件生成成功 |
| 操作验收 | 导出操作<5s，进度条展示 |
| 数据验收 | 导出数据与日志记录一致，字段完整；单次导出记录数上限≤5万条；导出文件大小≤50MB；支持导出格式：xlsx/csv；支持脱敏字段可配；
| 交互验收 | 支持脱敏配置，下载链接有效期明确 |

## 2.3 用户场景

| 场景 | 用户 | 描述 |
|:---|:---|:---|
| 场景1 | 运营人员 | 查询权益发放记录，按操作类型/时间/操作人筛选日志 |
| 场景2 | 运营人员 | 查询权益核销记录，查看核销的详细信息 |
| 场景3 | 运营人员 | 查询权益退回记录，了解退回操作的详情 |
| 场景4 | 运营人员 | 导出权益操作日志，支持Excel格式，可配置导出字段和时间范围 |
| 场景5 | 客服人员 | 查询特定用户的权益操作日志，解答用户咨询 |
| 场景6 | 管理人员 | 审计权益操作记录，查看完整操作流水 |
| 场景7 | 运营人员 | 按操作类型（发放/锁定/解锁/核销/过期/作废）筛选日志记录 |
