## 2. 功能描述

全局规则提供权益业务的全局规则配置，包括发放限制、使用规则、风控规则等。管理员可以配置全局业务规则，确保权益发放的安全性和合规性。

## 2. FP 清单

### FP-MKT-COUPON-RULE-001 规则配置

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-COUPON-RULE-001 |
| 功能点名称 | 规则配置 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：配置权益使用规则，包括使用条件（满减/指定日期/指定渠道）、互斥规则、叠加规则。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 规则配置正常，规则逻辑生效 |
| 操作验收 | 配置保存<2s，规则测试反馈及时 |
| 数据验收 | 规则数据正确存储，互斥叠加逻辑正确 |
| 交互验收 | 规则条件可视化，测试结果展示清晰 |

### FP-MKT-COUPON-RULE-002 规则引擎

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-COUPON-RULE-002 |
| 功能点名称 | 规则引擎 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：规则引擎执行权益使用条件的判断，支持实时计算和批量计算，返回权益可用性结果。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 规则引擎计算准确，返回结果正确 |
| 操作验收 | 实时计算<50ms，批量计算<1s/千条 |
| 数据验收 | 计算结果与规则配置一致 |
| 交互验收 | 规则执行日志完整，异常可追溯 |
