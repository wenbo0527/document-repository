## 一、产品概述

### 1.1 产品定位
权益中心（EPIC-MKT-COUPON）是数字营销产品域的核心组成部分，为企业提供统一的权益（优惠券、积分、会员权益等）管理、发放、核销和风控能力。

### 1.2 核心价值

| 价值 | 说明 |
|:---|:---|
| 权益统一管理 | 统一管理优惠券、积分、会员权益等各类权益 |
| 权益标准化 | 建立权益模板库，统一权益发放和核销流程 |
| 权益数据共享 | 建立权益数据共享机制，支持跨系统调用 |
| 权益风控 | 建立权益风控体系，防止薅羊毛行为 |

### 1.3 目标用户

- **运营人员**：创建和管理权益，配置权益模板和批次
- **运营主管**：审批权益发放，配置风控规则
- **风控人员**：监控异常行为，生成风控报表
- **用户**：查询和使用权益

## 二、产品架构

EPIC-MKT-COUPON 包含五个主要功能模块：

| 模块 | 说明 | 优先级 |
|:---|:---|:---:|
| **权益类型管理（FEAT-MKT-COUPON-TYPE）** | 权益类型、模板、批次管理 | P0 |
| **权益发放（FEAT-MKT-COUPON-GRANT）** | 发放任务、审批、记录 | P0 |
| **权益核销（FEAT-MKT-COUPON-REDEEM）** | 核销、查询、退回 | P0 |
| **权益风控（FEAT-MKT-COUPON-RISK）** | 风控规则、异常检测、报表 | P0 |
| **权益分析（FEAT-MKT-COUPON-ANALYSIS）** | 发放分析、核销分析、ROI | P1 |
