## 2. 功能描述

画布节点配置提供画布中各类节点的配置面板，用户可以在节点配置面板中设置节点的各项参数。节点分为三大类：业务逻辑节点、触达节点、权益节点。

### 节点分类

#### 业务逻辑节点

| 节点 | 说明 |
|:---|:---|
| 起始节点 | 画布起点节点，配置画布触发条件 |
| 结束节点 | 画布结束节点，标记画布结束 |
| 人群分流 | 根据人群属性进行条件分流 |
| 事件分流 | 根据用户事件触发进行分流 |
| A/B测试 | 配置A/B测试分组和比例 |
| 等待节点 | 配置延时等待时长 |

#### 触达节点

| 节点 | 说明 |
|:---|:---|
| 短信节点 | 配置短信模板、签名、变量 |
| AI外呼 | 配置AI外呼话术、重试策略 |
| 人工外呼 | 配置人工外呼任务分配规则 |

#### 权益节点

| 节点 | 说明 |
|:---|:---|
| 权益节点 | 配置权益类型、发放数量 |

## 2. FP 清单

### FP-MKT-CANVAS-NODES-001 拖拽设计

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-CANVAS-NODES-001 |
| 功能点名称 | 拖拽设计 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：从左侧节点池拖拽节点到画布，支持拖拽放置、位置调整、节点连线。连线自动吸附到节点锚点。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 拖拽放置成功，节点添加到画布 |
| 操作验收 | 拖拽流畅无卡顿，响应延迟<100ms |
| 数据验收 | 节点位置数据正确保存 |
| 交互验收 | 拖拽时显示放置预览，连线自动吸附 |
