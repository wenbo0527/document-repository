## 2. 功能描述

节点统计查询提供画布各节点执行数据的统计汇总功能。用户可以查看每个节点的执行数量、转化率、漏斗分析、异常统计等聚合数据。

### 功能列表

| 功能 | 说明 |
|:---|:---|
| 节点执行统计 | 各节点的总执行次数、人群分叉比例 |
| 漏斗分析 | 画布整体漏斗转化分析 |
| 转化率展示 | 各节点之间的转化率计算 |
| 异常统计 | 各节点的异常/失败次数统计 |
| 导出功能 | 统计数据导出 |
