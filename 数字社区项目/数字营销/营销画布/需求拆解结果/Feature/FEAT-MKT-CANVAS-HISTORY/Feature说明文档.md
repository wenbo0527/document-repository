## 2. FP 清单

### FP-MKT-CANVAS-HISTORY-001 实时数据

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-CANVAS-HISTORY-001 |
| 功能点名称 | 实时数据 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：展示画布运行时的实时数据面板，包括进入量、各节点执行量、转化率、耗时等核心指标。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 实时数据面板正常展示，指标计算准确 |
| 操作验收 | 数据刷新间隔可配置（5s/30s/1min），加载流畅 |
| 数据验收 | 数据与实际执行一致，延迟<刷新间隔 |
| 交互验收 | 支持hover查看详情，点击节点跳转监控 |

### FP-MKT-CANVAS-HISTORY-002 节点监控

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-CANVAS-HISTORY-002 |
| 功能点名称 | 节点监控 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：对画布中每个节点进行单独监控，展示节点的进入量、输出量、丢弃量、平均处理时长。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 节点监控数据准确，状态正常 |
| 操作验收 | 节点监控面板打开<1s，数据更新及时 |
| 数据验收 | 节点级数据与全局数据一致 |
| 交互验收 | 支持放大节点监控视图，导出节点数据 |

### FP-MKT-CANVAS-HISTORY-003 异常预警

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-CANVAS-HISTORY-003 |
| 功能点名称 | 异常预警 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：监控画布运行异常（如节点执行失败率超阈值、响应超时），自动发送预警通知。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 异常检测正常，预警触发及时 |
| 操作验收 | 预警通知送达<1min，异常标记准确 |
| 数据验收 | 预警记录完整，包含异常详情和时间 |
| 交互验收 | 支持预警规则配置，预警列表展示清晰 |
