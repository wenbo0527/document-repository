## 2. 功能描述

画布编辑提供画布详情页的编辑能力，仅在画布处于草稿状态时可编辑。用户可以修改节点内容、新增节点、编辑策略等。

### 功能列表

| 功能 | 说明 |
|:---|:---|
| 修改节点内容 | 编辑已存在节点的各种配置参数 |
| 新增节点 | 从节点池拖拽新增节点到画布 |
| 编辑策略 | 编辑分流条件、触发事件等策略配置 |
| 删除节点 | 删除画布中的节点 |
| 画布缩放 | 支持画布缩放、平移操作 |
| 撤销重做 | 支持编辑操作的撤销和重做 |
