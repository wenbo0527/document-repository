## 2. 功能描述

工具栏提供画布设计器页面的工具操作面板，包括画布缩放、撤销重做、节点池操作、保存发布等快捷操作。

### 功能列表

| 功能 | 说明 |
|:---|:---|
| 画布缩放 | 画布缩放比例调整 |
| 撤销重做 | 撤销/重做编辑操作 |
| 节点池 | 节点组件库，支持拖拽 |
| 保存 | 保存画布草稿 |
| 发布 | 发布画布使其可运行 |
| 预览 | 预览画布效果 |
