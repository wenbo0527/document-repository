## 2. 功能描述

画布列表是营销画布的主入口，提供画布的列表展示、新建、编辑、查看、启动、暂停等操作入口。

### 功能列表

| 操作 | 说明 |
|:---|:---|
| 新建 | 创建空白画布 |
| 编辑 | 进入画布编辑模式（仅草稿状态） |
| 查看 | 进入画布详情页（只读模式） |
| 启动 | 将草稿状态的画布发布为运行中 |
| 暂停 | 暂停运行中的画布 |
| 删除 | 删除画布（仅草稿状态）|
| 复制 | 复制画布创建新画布 |
