## 2. 功能描述

单一用户统计查询提供针对特定用户个体的画布执行轨迹查询功能。用户可以输入用户ID查看该用户在整个画布中的执行路径、各节点状态、触达记录等信息。

### 功能列表

| 功能 | 说明 |
|:---|:---|
| 用户轨迹查询 | 输入用户ID查询该用户的画布执行轨迹 |
| 节点状态查看 | 查看用户在各节点的执行状态 |
| 触达记录查看 | 查看触达类节点的发送/触达记录 |
| 权益发放查看 | 查看权益节点的发放记录 |
| 时间线展示 | 以时间线形式展示用户触达历史 |

## 2. FP 清单

### FP-MKT-CANVAS-STATS-004 用户群分析

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-CANVAS-STATS-004 |
| 功能点名称 | 用户群分析 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：分析参与画布的用户群体特征，包括用户属性分布、行为路径、生命周期阶段。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 用户群分析正常，数据准确 |
| 操作验收 | 分析查询<5s，支持维度过滤 |
| 数据验收 | 用户数据脱敏后与分析结果一致 |
| 交互验收 | 支持图表交互（放大/筛选/对比） |

### FP-MKT-CANVAS-STATS-005 转化路径

| 字段 | 内容 |
|:---|:---|
| FP ID | FP-MKT-CANVAS-STATS-005 |
| 功能点名称 | 转化路径 |
| 类型 | 功能点 |
| 优先级 | P0 |
| 状态 | 已上线 |

**功能描述**：追踪用户在画布中的完整转化路径，分析各节点的转化率和流失点。

**验收标准**：

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 转化路径展示正常，节点串联准确 |
| 操作验收 | 路径渲染<3s，支持多路径对比 |
| 数据验收 | 路径数据与实际用户行为一致 |
| 交互验收 | 支持点击节点查看该节点的用户列表 |
