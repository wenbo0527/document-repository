## 一、产品概述

### 1.1 功能简介

营销画布是数字营销的核心产品，为营销运营提供可视化营销流程配置能力。

### 1.2 核心功能

| 功能 | 说明 |
|:---|:---|
| 画布编辑器 | 可视化拖拽配置营销流程 |
| 节点管理 | 标准节点库，支持快速配置 |
| 触发条件 | 支持事件、时间、API 多种触发 |
| 流程控制 | 条件分支、循环、等待控制 |
| 数据分析 | 营销漏斗、节点效果、实时监控 |

## 三、画布编辑器操作指南

### 3.1 创建画布

**操作步骤**：

| 步骤 | 操作 | 说明 |
|:---:|:---|:---|
| 1 | 点击「创建画布」 | 打开画布创建弹窗 |
| 2 | 输入画布名称 | 名称全局唯一 |
| 3 | 选择画布模板 | 可选空白模板或预置模板 |
| 4 | 点击「创建」 | 完成画布创建 |

### 3.2 节点拖拽

**操作步骤**：

| 步骤 | 操作 | 说明 |
|:---:|:---|:---|
| 1 | 从左侧节点库拖拽节点 | 支持搜索节点 |
| 2 | 放置节点到画布 | 节点自动对齐 |
| 3 | 连接节点 | 拖拽节点边缘连接线 |
| 4 | 配置节点参数 | 点击节点打开配置面板 |

**节点类型说明**：

| 类型 | 图标 | 说明 |
|:---|:---:|:---|
| 触发节点 | ⚡ | 流程起始节点 |
| 动作节点 | 🎯 | 执行具体动作 |
| 逻辑节点 | 🔀 | 条件判断和处理 |
| 数据节点 | 📊 | 数据处理和转换 |

### 3.3 画布预览

**操作步骤**：

| 步骤 | 操作 | 说明 |
|:---:|:---|:---|
| 1 | 点击「预览」按钮 | 打开预览模式 |
| 2 | 查看节点布局 | 确认节点位置 |
| 3 | 查看流程走向 | 确认连接线 |
| 4 | 点击「退出预览」 | 返回编辑模式 |

| 步骤 | 操作 | 说明 |

## 八、常见问题

### Q1: 如何创建画布模板？
**A**：在画布编辑完成后，点击「另存为模板」即可将当前画布保存为模板。

### Q2: 如何复制画布？
**A**：在画布列表点击「复制」按钮，系统会创建画布副本并自动命名。

### Q3: 如何恢复已删除的画布？
**A**：画布删除后会进入回收站，7天内可在回收站恢复。

### Q4: 如何设置节点超时？
**A**：在节点配置面板中选择「高级设置」，可配置节点执行超时时间。
