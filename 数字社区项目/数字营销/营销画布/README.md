## 概述

营销画布是数字营销产品域的**营销策略层**核心模块，提供可视化拖拽式营销流程编排能力，支持人群选择、触发条件、触达渠道等节点的配置。

---

## 菜单结构

**入口**：数字营销 → 营销画布

> ⚠️ **重要说明**：菜单只有一个入口「画布列表」，所有功能（新建、编辑、查看、统计等）均通过画布列表进入画布详情页后操作。

---

## 画布状态机

| 状态 | 可执行操作 |
|:---|:---|
| 草稿 | 编辑、发布、删除 |
| 运行中 | 暂停、查看统计、终止 |
| 完成 | 查看统计、重跑 |
| 停止 | 查看统计、重跑 |
| 暂停 | 恢复、查看统计、终止 |

---

## 用户操作流程

```
① 画布列表（FEAT-MKT-CANVAS-LIST）
      │
      ├── 点击「新建」→ 创建空白画布 → 进入画布详情（草稿状态）
      ├── 点击「编辑」→ 进入画布详情（草稿状态）
      ├── 点击「查看」→ 进入画布详情（只读模式）
      ├── 点击「启动」→ 草稿→运行中
      └── 点击「暂停」→ 运行中→暂停

② 画布详情页（根据状态显示不同模式）
      │
      ├── 草稿状态 → 编辑模式
      │      ├── 画布编辑（FEAT-MKT-CANVAS-EDIT）：修改节点内容、新增节点、编辑策略
      │      ├── 节点配置（FEAT-MKT-CANVAS-NODES）：业务逻辑/触达/权益节点配置
      │      └── 工具栏（FEAT-MKT-CANVAS-TOOLBAR）：画布缩放、撤销重做、保存、发布
      │
      └── 运行中/完成/停止 → 统计模式
             ├── 单一用户统计查询（FEAT-MKT-CANVAS-STATS-USER）：用户轨迹查询
             └── 节点统计查询（FEAT-MKT-CANVAS-STATS-NODES）：节点执行统计、漏斗分析
```
