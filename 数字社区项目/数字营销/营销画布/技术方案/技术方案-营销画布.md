### 1.2 技术栈

| 层级 | 技术选型 | 说明 |
|:---|:---|:---|
| 前端 | Vue3 + TypeScript + Canvas | 可视化编辑器 |
| BFF | Node.js + Express | 画布编辑和流程执行 |
| 后端 | Java Spring Boot 2.7 | 业务逻辑处理 |
| 数据库 | MySQL 8.0 | 画布和节点元数据 |
| 缓存 | Redis 6.0 | 执行状态和热点数据 |
| 消息队列 | Kafka | 事件驱动和异步执行 |
| 分析引擎 | ClickHouse | 营销数据分析 |
| 流程引擎 | 自研 + JSON Schema | 流程配置和执行 |

## 二、数据库设计

### 2.1 画布表 (marketing_canvas)

```sql
CREATE TABLE marketing_canvas (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
    canvas_code VARCHAR(64) NOT NULL UNIQUE COMMENT '画布编码',
    canvas_name VARCHAR(128) NOT NULL COMMENT '画布名称',
    canvas_desc TEXT COMMENT '画布描述',
    canvas_type VARCHAR(32) COMMENT '画布类型: TEMPLATE/CUSTOM',
    status VARCHAR(32) NOT NULL DEFAULT 'DRAFT' COMMENT '状态: DRAFT/PUBLISHED/ARCHIVED',
    version INT DEFAULT 1 COMMENT '版本号',
    config JSON COMMENT '画布配置JSON',
    trigger_config JSON COMMENT '触发配置JSON',
    owner_id BIGINT COMMENT '创建人ID',
    publish_time DATETIME COMMENT '发布时间',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_canvas_code (canvas_code),
    INDEX idx_status (status),
    INDEX idx_owner_id (owner_id)
) COMMENT='营销画布表';
```

### 2.2 节点表 (canvas_node)

```sql
CREATE TABLE canvas_node (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
    node_code VARCHAR(64) NOT NULL UNIQUE COMMENT '节点编码',
    canvas_id BIGINT NOT NULL COMMENT '画布ID',
    node_name VARCHAR(128) NOT NULL COMMENT '节点名称',
    node_type VARCHAR(32) NOT NULL COMMENT '节点类型: TRIGGER/ACTION/LOGIC/DATA',
    node_sub_type VARCHAR(64) COMMENT '节点子类型',
    position_x INT COMMENT 'X坐标',
    position_y INT COMMENT 'Y坐标',
    config JSON COMMENT '节点配置JSON',
    status VARCHAR(32) DEFAULT 'ACTIVE' COMMENT '状态: ACTIVE/INACTIVE',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_canvas_id (canvas_id),
    INDEX idx_node_type (node_type),
    FOREIGN KEY (canvas_id) REFERENCES marketing_canvas(id)
) COMMENT='画布节点表';
```

### 2.3 节点连线表 (canvas_edge)

```sql
CREATE TABLE canvas_edge (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
    edge_code VARCHAR(64) NOT NULL UNIQUE COMMENT '连线编码',
    canvas_id BIGINT NOT NULL COMMENT '画布ID',
    source_node_id BIGINT NOT NULL COMMENT '源节点ID',
    target_node_id BIGINT NOT NULL COMMENT '目标节点ID',
    source_port VARCHAR(32) COMMENT '源端口',
    target_port VARCHAR(32) COMMENT '目标端口',
    condition_expr TEXT COMMENT '条件表达式',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    INDEX idx_canvas_id (canvas_id),
    INDEX idx_source_node (source_node_id),
    INDEX idx_target_node (target_node_id),
    FOREIGN KEY (canvas_id) REFERENCES marketing_canvas(id),
    FOREIGN KEY (source_node_id) REFERENCES canvas_node(id),
    FOREIGN KEY (target_node_id) REFERENCES canvas_node(id)
) COMMENT='画布节点连线表';
```

### 2.4 执行记录表 (canvas_execution)

```sql
CREATE TABLE canvas_execution (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
    execution_code VARCHAR(64) NOT NULL UNIQUE COMMENT '执行编码',
    canvas_id BIGINT NOT NULL COMMENT '画布ID',
    canvas_version INT COMMENT '画布版本',
    trigger_type VARCHAR(32) COMMENT '触发类型',
    trigger_id VARCHAR(64) COMMENT '触发ID',
    status VARCHAR(32) NOT NULL DEFAULT 'RUNNING' COMMENT '状态: RUNNING/SUCCESS/FAILED/PAUSED',
    start_time DATETIME COMMENT '开始时间',
    end_time DATETIME COMMENT '结束时间',
    current_node_id BIGINT COMMENT '当前执行节点',
    execute_data JSON COMMENT '执行数据',
    result_data JSON COMMENT '执行结果',
    error_message TEXT COMMENT '错误信息',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    INDEX idx_canvas_id (canvas_id),
    INDEX idx_status (status),
    INDEX idx_start_time (start_time)
) COMMENT='画布执行记录表';
```

## 五、非功能性设计

### 5.1 性能设计

| 指标 | 目标 | 方案 |
|:---|:---|:---|
| 画布加载 | ≤ 3s | 画布配置 Redis 缓存 |
| 节点拖拽 | ≤ 100ms | Canvas 本地渲染优化 |
| 数据实时延迟 | ≤ 5min | Kafka + ClickHouse 实时写入 |

### 5.2 高可用设计

| 方案 | 说明 |
|:---|:---|
| 服务多实例 | 后端服务多实例部署 |
| 画布编辑锁定 | 防止并发编辑冲突 |
| 执行断点恢复 | 支持执行中断后恢复 |

### 5.3 安全设计

| 方案 | 说明 |
|:---|:---|
| 操作审计 | 记录所有画布操作日志 |
| 权限控制 | RBAC 权限模型 |
| 数据脱敏 | 敏感数据脱敏展示 |
