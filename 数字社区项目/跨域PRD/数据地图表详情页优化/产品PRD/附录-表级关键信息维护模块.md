## 一、模块定位

| 维度 | 内容 |
|:---|:---|
| **用途** | 供数仓开发同学在 SQL 任务脚本中维护 **🤚 人工维护** 的表级关键信息 |
| **使用位置** | SQL 脚本头部 `@meta` + `@table-info` 块 |
| **解析方式** | CI/CD 解析，同步至 dmt-app |

**两个块的区别**：

| 模块 | 维护类型 | 内容 |
|:---|:---:|:---|
| `@meta` | 🔧 **自动化**（CI解析） | 技术侧信息，CI 自动填充 |
| `@table-info` | 🤚 **人工维护**（手动填写） | 业务侧信息，数据同学手动填写 |

## 三、字段说明

### 3.1 @meta 字段

| 字段 | 类型 | 维护方式 | 说明 |
|:---|:---|:---:|:---|
| `table_name` | string | 🔧 自动 | 从 Git 路径提取 |
| `table_name_cn` | string | 🤚 人工 | 表中文名 |
| `hive_cluster` | string | 🤚 人工 | 计算集群表名 |
| `doris_cluster` | string | 🤚 人工 | 分析集群表名 |
| `owner` | string | 🔧 自动 | Git author（首次提交人）|
| `domain` | string | 🤚 人工 | 业务域 |
| `category` | string | 🤚 人工 | 数据域/主题域 |
| `update_frequency` | string | 🤚 人工 | 更新周期 |
| `status` | string | 🔄 可覆盖 | 默认 active |
| `tags` | list | 🤚 人工 | 标签 |
| `version` | string | 🔧 自动 | Git tag |
| `registered_at` | date | 🔧 自动 | 首次提交日期 |
| `last_modified` | date | 🔧 自动 | 最近修改日期 |

### 3.2 @table-info 字段

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---:|:---|
| `usage` | string | ✅ | 表使用说明（用 `"""` 多行字符串） |
| `field_descriptions` | list[object] | ✅ | 核心字段说明 |
| `relations` | list[object] | ✅ | 数据关系 |

```sql
/*
-- @table-info
{
  "usage": """DWD层用户交易明细表，承接ODS层原始交易数据，清洗加工后形成用户维度的交易明细。

【数据内容】包含用户ID、订单号、交易金额、交易时间、交易渠道、交易状态等核心字段。主键为 (id, order_id)，分区字段为 dt。

【常用场景】

【示例查询】

FROM dwd_user_trade_detail WHERE dt = CURRENT_DATE LIMIT 10;

【相关文档】
- 用户交易域口径说明书：https://wiki.example.com/trade-standard
- 交易域数据血缘：https://wiki.example.com/trade-lineage""",

  "field_descriptions": [
    {"field": "id", "desc": "主键，自增"},
    {"field": "user_id", "desc": "用户ID，关联dim_user.id"},
    {"field": "order_id", "desc": "订单号"},
    {"field": "trade_amount", "desc": "交易金额（元），已做分转元"},
    {"field": "trade_time", "desc": "交易时间"},

    {"field": "dt", "desc": "分区字段，格式YYYY-MM-DD"}

  "relations": [

      "target_field": "id",
      "usage": "关联用户基础信息（姓名、手机号、会员等级）"
    },
    {
      "target": "dim_trade_type",
      "join_type": "LEFT JOIN",
      "current_field": "trade_type",
      "target_field": "type_code",
      "usage": "补充交易类型业务含义名称（payment→支付，refund→退款）"
    }
  ]

*/

CREATE TABLE IF NOT EXISTS dwd_user_trade_detail (
    id            BIGINT          NOT NULL COMMENT '主键，自增',
    user_id       BIGINT          NOT NULL COMMENT '用户ID，关联 dim_user.id',
    order_id      VARCHAR(64)     NOT NULL COMMENT '订单号',
    trade_amount  DECIMAL(16,2)   NOT NULL COMMENT '交易金额（元）',
    trade_time    TIMESTAMP       NOT NULL COMMENT '交易时间',
    trade_channel VARCHAR(32)     COMMENT '交易渠道 app/web/miniapp/API',
    trade_status  VARCHAR(32)     COMMENT '交易状态 pending/success/failed/refunded',
    dt            VARCHAR(10)     NOT NULL COMMENT '分区字段，格式 YYYY-MM-DD',
    etl_time      TIMESTAMP       NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT 'ETL 入表时间',
    CONSTRAINT pk_dwd_user_trade_detail PRIMARY KEY (id, order_id)
)
COMMENT '用户交易明细表'
PARTITIONED BY (dt VARCHAR(10))
STORED AS PARQUET
LOCATION '/warehouse/dwd/dwd_user_trade_detail';
```

### 4.2 dml_daily.sql 示例

```sql
/*
-- @meta
{
  "table_name": "dwd.dwd_user_trade_detail",
  "task_name": "ETL-DWD-USER-TRADE-001",
  "schedule": "daily T+1 02:00",
  "owner": "zhangsan",
  "modifier": "lisi",
  "modified_at": "2026-04-15",
  "version": "v1.2.0"
}
*/

/*
-- @table-info
{
  "usage": """每日从 ods_user_trade_raw 清洗加工生成 DWD 层交易明细。

【数据内容】主要加工逻辑：金额分转元、过滤测试用户、过滤异常数据。该任务为全量覆盖分区，每日 02:00 执行。

【常用场景】
- 每日交易数据清洗
- 交易指标统计（GMV、订单量、客单价）
- 用户交易行为画像

【更新周期】每日更新（daily）

【注意事项】
- 执行前需确保上游 ODS 层任务已完成
- 过滤规则：user_id IS NOT NULL AND order_id IS NOT NULL AND trade_amount > 0
- 测试用户（user_type=test）已被过滤

【示例查询】
SELECT * FROM dwd_user_trade_detail WHERE dt = '${bizdate}' LIMIT 10;""",

  "field_descriptions": [
    {"field": "id", "desc": "主键，自增"},
    {"field": "user_id", "desc": "用户ID"},
    {"field": "trade_amount", "desc": "交易金额（元），已做分转元"}
  ],

  "relations": [
    {
      "target": "ods_user_trade_raw",
      "join_type": "FROM",
      "current_field": "-",
      "target_field": "-",
      "usage": "ODS层原始数据来源"
    }
  ]
}
*/

INSERT OVERWRITE TABLE dwd_user_trade_detail PARTITION(dt = '${bizdate}')
SELECT
    id,
    user_id,
    order_id,
    trade_amount / 100.0                AS trade_amount,
    trade_time,
    trade_channel,
    trade_status,
    '${bizdate}'                         AS dt,
    CURRENT_TIMESTAMP                    AS etl_time
FROM ods_user_trade_raw
WHERE dt = '${bizdate}'
  AND user_id IS NOT NULL
  AND order_id IS NOT NULL
  AND trade_amount > 0;
```

## 五、解析规则

| 规则 | 说明 |
|:---|:---|
| **块标识** | 以 `/*` + `-- @meta` 或 `-- @table-info` 标记块开始 |
| **块终止** | 遇到 `*/` 则块结束 |
| **JSON 格式** | 块内为标准 JSON |
| **多行字符串** | 用 `"""` 包裹 usage 字段 |
| **CI 填充** | @meta 部分字段由 CI 自动填充 |

## 六、与 dmt-app 字段的映射

| 块 | 字段 | dmt-app 字段 | 说明 |
|:---|:---|:---|:---|
| @meta | `table_name_cn` | `chineseName` | 表中文名 |
| @meta | `hive_cluster` | `hiveTable` | Hive 表名 |
| @meta | `doris_cluster` | `dorisTable` | Doris 表名 |
| @meta | `domain` | `businessDomain` | 业务域 |
| @meta | `category` | `topicDomain` | 主题域 |
| @meta | `update_frequency` | `updateFrequency` | 更新周期 |
| @meta | `owner` | `manager` | 管理人 |
| @meta | `version` | `version` | 版本号 |
| @table-info | `usage` | `description` | 表描述 |
| @table-info | `field_descriptions` | `fields[].description` | 字段描述 |
| @table-info | `relations` | `fieldRelations` | 关联关系 |

## 七、维护时机建议

| 场景 | @meta | @table-info |
|:---|:---:|:---:|
| 新建表 | 🔧 自动（部分） | ✅ 必须填写 |
| 表名/集群变更 | 🔄 可覆盖 | - |
| 业务域/数据域变更 | ✅ 需要更新 | - |
| 表用途变更 | - | ✅ 需要更新 usage |
| 新增字段 | 🔧 自动（DB抽取） | ✅ 需要更新 field_descriptions |
| 新增关联表 | - | ✅ 需要更新 relations |
| 表下线/归档 | 🔄 可覆盖 status | ❌ 无需更新 |
