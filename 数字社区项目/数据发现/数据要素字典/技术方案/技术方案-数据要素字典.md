## 三、数据库设计

### 3.1 要素类型表 (element_type)

```sql
CREATE TABLE element_type (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    type_code VARCHAR(64) NOT NULL UNIQUE,
    type_name VARCHAR(128) NOT NULL,
    type_kind VARCHAR(32) NOT NULL COMMENT 'FIELD/INDICATOR/DIMENSION/MEASURE',
    status VARCHAR(32) DEFAULT 'ACTIVE',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_type_code (type_code)
) COMMENT='要素类型表';
```

### 3.2 要素定义表 (element_definition)

```sql
CREATE TABLE element_definition (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    element_code VARCHAR(64) NOT NULL UNIQUE,
    element_name VARCHAR(128) NOT NULL,
    type_code VARCHAR(64) NOT NULL,
    data_type VARCHAR(32) COMMENT '数据类型',
    description TEXT COMMENT '描述',
    business_rule TEXT COMMENT '业务规则',
    status VARCHAR(32) DEFAULT 'DRAFT',
    creator_id BIGINT,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_element_code (element_code),
    INDEX idx_type_code (type_code)
) COMMENT='要素定义表';
```

### 3.3 要素血缘表 (element_lineage)

```sql
CREATE TABLE element_lineage (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    source_code VARCHAR(64) NOT NULL COMMENT '源要素',
    target_code VARCHAR(64) NOT NULL COMMENT '目标要素',
    lineage_type VARCHAR(32) NOT NULL COMMENT '上游/下游',
    transform_rule TEXT COMMENT '转换规则',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_source (source_code),
    INDEX idx_target (target_code)
) COMMENT='要素血缘表';
```

## 四、接口设计
