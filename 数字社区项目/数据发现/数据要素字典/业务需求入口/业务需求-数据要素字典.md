## 一、业务背景

数据要素字典是数据发现产品域的核心模块，用于统一管理数据要素（字段/指标）定义，确保数据口径一致。

## 二、业务需求

### 2.1 要素类型管理

| 功能 | 说明 |
|:---|:---|
| 要素类型配置 | 配置要素类型（字段、指标、维度、度量） |
| 要素类型查询 | 查询已有要素类型 |

### 2.2 要素定义管理

| 功能 | 说明 |
|:---|:---|
| 要素创建 | 创建新的要素定义 |
| 要素编辑 | 编辑已有要素 |
| 要素审核 | 审核要素定义变更 |

### 2.3 要素检索

| 功能 | 说明 |
|:---|:---|
| 要素搜索 | 多条件搜索要素 |
| 要素详情 | 查看要素详细信息 |
| 要素血缘 | 查看要素上下游血缘 |

### 2.4 要素标准

| 功能 | 说明 |
|:---|:---|
| 标准要素库 | 维护标准要素库 |
| 要素映射 | 业务要素与技术要素映射 |
