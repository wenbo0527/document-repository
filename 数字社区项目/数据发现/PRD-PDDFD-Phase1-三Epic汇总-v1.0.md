## 三、需求背景

### 3.1 目标

数据发现域旨在帮助用户高效地发现、理解和管理企业数据资产。一期聚焦三个核心模块：**统一搜索**、**数据要素字典**、**数据资产字典**，构建数据资产的单点查找与详情查看能力。

### 3.2 痛点

1. **找数困难**：业务人员不清楚有哪些数据资产可用，数据分散在多个系统，缺乏统一的发现入口
2. **元信息缺失**：找到数据后，无法快速了解其业务含义、血缘关系和质量问题
3. **口径不统一**：同一指标/变量在不同系统中定义不一致，缺乏统一的要素管理

### 3.3 核心挑战

1. 多源异构数据的统一检索与排名
2. 指标/变量/特征三类要素的统一管理视图
3. 资产目录的多维度筛选与血缘追溯

**Story SE-001：全局关键词搜索（扩展）**

| 字段 | 内容 |
|:---|:---|
| 角色-场景-价值 | 作为用数的人（数据分析/风险策略/风险模型），在首页搜索框输入关键词，一次搜索定位数据表/指标/外部数据/行为变量/征信变量/外数变量，快速找到目标资产，以便开展数据分析工作 |
| 优先级 | P0 |
| 状态 | 待开发 |

**验收标准**：

1. 全局搜索框支持同时搜索6类资产（数据表/指标/外部数据/行为变量/征信变量/外数变量）
2. 输入关键词后500ms内返回搜索结果
3. 搜索结果准确展示资产名称、类型、所属系统
4. 无结果时给出合理提示

用户打开数据发现首页（/discovery/data-map），搜索框自动获得焦点；输入关键词后下拉实时展示建议列表；按回车或点击搜索按钮查看完整结果页；结果按相关性默认排序。
