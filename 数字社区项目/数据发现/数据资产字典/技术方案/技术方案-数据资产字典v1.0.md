## 一、技术架构

### 1.1 模块定位
数据资产字典是数据发现产品域的核心模块，负责数据资产的登记、检索、详情展示等能力。

## 二、核心功能实现

### 2.1 资产列表

| 功能 | 实现方式 | 说明 |
|:---|:---|:---|
| 分页加载 | MySQL LIMIT/OFFSET | 支持大规模数据 |
| 多维度筛选 | 动态SQL拼接 | 类型/部门/标签/状态 |
| 搜索 | ElasticSearch | 关键词全文检索 |
| 排序 | MySQL ORDER BY | 支持多字段排序 |

### 2.2 资产详情

| 功能 | 实现方式 | 说明 |
|:---|:---|:---|
| 基本信息 | MySQL 查询 | 单行记录读取 |
| 字段列表 | MySQL 查询 | 关联字段表 |
| 血缘关系 | Neo4j 图查询 | 上游/下游遍历 |
| 质量评分 | 计算服务 | 实时计算评分 |

## 三、API 设计

### 3.1 资产列表 API

```
GET /api/asset/list
Query: page, pageSize, type, department, tag, keyword
Response: { list: [], total, page, pageSize }
```

### 3.2 资产详情 API

```
GET /api/asset/detail/:id
Response: { id, name, type, fields: [], lineage: {}, quality: {} }
```

### 3.3 资产搜索 API

```
GET /api/asset/search
Query: keyword, filters
Response: { list: [], total }
```

## 四、数据模型

### 4.1 资产主表 (asset)

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| id | BIGINT | 主键 |
| name | VARCHAR(255) | 资产名称 |
| type | VARCHAR(50) | 资产类型 |
| department | VARCHAR(100) | 所属部门 |
| creator | VARCHAR(100) | 创建人 |
| create_time | DATETIME | 创建时间 |
| update_time | DATETIME | 更新时间 |

### 4.2 资产字段表 (asset_field)

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| id | BIGINT | 主键 |
| asset_id | BIGINT | 资产ID |
| field_name | VARCHAR(100) | 字段名 |
| field_type | VARCHAR(50) | 字段类型 |
| description | VARCHAR(500) | 字段描述 |
