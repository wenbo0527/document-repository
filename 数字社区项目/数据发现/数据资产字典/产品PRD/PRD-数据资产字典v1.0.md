## 一、产品概述

### 1.1 产品定位
数据资产字典是数据发现产品域的核心组成部分，提供数据资产的登记、分类、检索、详情查看等全生命周期管理能力。

### 1.2 核心价值

| 价值 | 说明 |
|:---|:---|
| 统一管理 | 集中管理企业全部数据资产 |
| 快速检索 | 高效定位所需数据资产 |
| 详情透明 | 完整展示资产的元信息、血缘、质量等 |
| 生命周期管理 | 支持资产的注册、变更、下线全流程 |

### 1.3 目标用户

| 角色 | 高频场景 |
|:---|:---|
| 业务分析师 | 查找数据资产、理解资产详情 |
| 数据开发 | 注册新资产、变更资产信息 |
| 数据管理 | 资产审批、权限管理、质量监控 |
| 算法工程师 | 发现特征、评估资产质量 |

## 三、功能详细说明

### 3.1 资产列表 (FEAT-DFD-ASSET-LIST)

#### 3.1.1 功能概述
资产列表提供数据资产的集中展示、筛选、搜索能力，是用户发现数据资产的主要入口。

#### 3.1.2 核心功能点

| FP ID | 功能点 | 说明 | 验收标准 |
|:---|:---|:---|:---|
| FP-DFD-ASSET-LIST-001 | 资产列表展示 | 分页展示全部数据资产 | ✅ 功能：列表展示<br>✅ 操作：分页加载正常 |
| FP-DFD-ASSET-LIST-002 | 资产筛选 | 支持多维度筛选 | ✅ 功能：类型/部门/标签筛选<br>✅ 操作：筛选生效 |
| FP-DFD-ASSET-LIST-003 | 资产搜索 | 快速定位目标资产 | ✅ 功能：关键词搜索<br>✅ 操作：搜索结果准确 |
| FP-DFD-ASSET-LIST-004 | 资产收藏 | 收藏常用资产 | ✅ 功能：收藏/取消收藏<br>✅ 操作：状态同步 |
| FP-DFD-ASSET-LIST-005 | 批量操作 | 批量注册、批量导入 | ✅ 功能：批量操作入口<br>✅ 操作：批量处理正常 |

#### 3.1.3 用户交互流程

```
进入资产列表 → 选择筛选条件 → 浏览资产卡片 → 点击进入详情
```

### 3.2 资产详情页 (FEAT-DFD-ASSET-DETAIL)

#### 3.2.1 功能概述
资产详情页完整展示单个数据资产的元信息、血缘关系、质量评分、使用统计等核心内容。

#### 3.2.2 核心功能点

| FP ID | 功能点 | 说明 | 验收标准 |
|:---|:---|:---|:---|
| FP-DFD-ASSET-DETAIL-001 | 基本信息 | 展示资产基础元信息 | ✅ 功能：名称/类型/创建人/更新时间<br>✅ 操作：信息准确展示 |
| FP-DFD-ASSET-DETAIL-002 | 字段详情 | 展示资产的所有字段 | ✅ 功能：字段列表/类型/说明<br>✅ 操作：字段信息完整 |
| FP-DFD-ASSET-DETAIL-003 | 血缘关系 | 展示资产的血缘图谱 | ✅ 功能：上游/下游依赖<br>✅ 操作：血缘图谱可交互 |
| FP-DFD-ASSET-DETAIL-004 | 质量评分 | 展示资产质量评估结果 | ✅ 功能：质量分数/评分维度<br>✅ 操作：评分客观准确 |
| FP-DFD-ASSET-DETAIL-005 | 使用统计 | 展示资产的使用情况 | ✅ 功能：调用次数/使用方/趋势<br>✅ 操作：统计数据准确 |
| FP-DFD-ASSET-DETAIL-006 | 申请权限 | 一键申请资产访问权限 | ✅ 功能：权限申请入口<br>✅ 操作：申请流程完整 |

#### 3.2.3 用户交互流程

```
从列表点击资产 → 进入详情页 → 查看基础信息 → 查看血缘 → 申请权限 → 使用数据
```
