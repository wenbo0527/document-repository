## 三、数据库设计

### 3.1 推荐记录表 (recommendation_record)

```sql
CREATE TABLE recommendation_record (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    rec_code VARCHAR(64) NOT NULL UNIQUE,
    user_id BIGINT NOT NULL,
    asset_code VARCHAR(64) NOT NULL,
    rec_type VARCHAR(32) NOT NULL COMMENT 'SMART/RELEVANT/SCENE',
    score DECIMAL(5,3) COMMENT '推荐分数',
    status VARCHAR(32) DEFAULT 'SHOW' COMMENT 'SHOW/HIDE/CLICK',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_rec_code (rec_code),
    INDEX idx_user_id (user_id)
) COMMENT='推荐记录表';
```

### 3.2 推荐反馈表 (recommendation_feedback)

```sql
CREATE TABLE recommendation_feedback (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    feedback_code VARCHAR(64) NOT NULL UNIQUE,
    rec_code VARCHAR(64) NOT NULL,
    user_id BIGINT NOT NULL,
    feedback_type VARCHAR(32) NOT NULL COMMENT 'LIKE/DISLIKE',
    feedback_reason TEXT,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_feedback_code (feedback_code),
    INDEX idx_rec_code (rec_code)
) COMMENT='推荐反馈表';
```

### 3.3 推荐规则表 (recommendation_rule)

```sql
CREATE TABLE recommendation_rule (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    rule_code VARCHAR(64) NOT NULL UNIQUE,
    rule_name VARCHAR(128) NOT NULL,
    rule_type VARCHAR(32) NOT NULL COMMENT 'INCLUDE/EXCLUDE',
    rule_config JSON NOT NULL COMMENT '规则配置',
    status VARCHAR(32) DEFAULT 'ACTIVE',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_rule_code (rule_code)
) COMMENT='推荐规则表';
```
