## 一、产品概述

### 1.1 产品定位
数据资产运营工具是数据发现产品域的核心组成部分，提供数据资产的分析、监控、评价等运营能力。

### 1.2 核心价值

| 价值 | 说明 |
|:---|:---|
| 运营分析 | 多维度分析数据资产 |
| 实时监控 | 监控资产状态和异常 |
| 评价体系 | 建立资产质量评价机制 |
