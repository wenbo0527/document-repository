## 一、业务背景

数据资产运营工具是数据发现产品域的核心模块，提供数据资产的分析、监控、评价等运营能力，帮助提升数据资产质量。

## 二、业务需求

### 2.1 资产分析

| 功能 | 说明 |
|:---|:---|
| 资产统计 | 统计资产数量、类型、分布 |
| 资产趋势 | 分析资产变化趋势 |
| 资产报告 | 生成资产分析报告 |

### 2.2 资产监控

| 功能 | 说明 |
|:---|:---|
| 资产巡检 | 定期检查资产状态 |
| 异常告警 | 资产异常时发送告警 |
| 监控大屏 | 展示资产监控状态 |

### 2.3 资产评价

| 功能 | 说明 |
|:---|:---|
| 评价体系 | 建立资产评价指标 |
| 评价打分 | 用户对资产进行评价 |
| 评价统计 | 统计评价结果 |

### 2.4 运营管理

| 功能 | 说明 |
|:---|:---|
| 资产认领 | 资产责任认领 |
| 资产标签 | 资产标签管理 |
| 资产收藏 | 用户收藏资产 |
