## 三、数据库设计

### 3.1 资产评价表 (asset_evaluation)

```sql
CREATE TABLE asset_evaluation (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    eval_code VARCHAR(64) NOT NULL UNIQUE,
    asset_code VARCHAR(64) NOT NULL,
    user_id BIGINT NOT NULL,
    score INT COMMENT '评分 1-5',
    tags JSON COMMENT '评价标签',
    comment TEXT COMMENT '评价内容',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_eval_code (eval_code),
    INDEX idx_asset_code (asset_code),
    INDEX idx_user_id (user_id)
) COMMENT='资产评价表';
```

### 3.2 资产监控表 (asset_monitor)

```sql
CREATE TABLE asset_monitor (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    monitor_code VARCHAR(64) NOT NULL UNIQUE,
    asset_code VARCHAR(64) NOT NULL,
    monitor_type VARCHAR(32) NOT NULL COMMENT 'HEALTH/PERFORMANCE',
    monitor_value TEXT COMMENT '监控值',
    threshold VARCHAR(64) COMMENT '阈值',
    status VARCHAR(32) DEFAULT 'NORMAL',
    alert_time DATETIME,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_monitor_code (monitor_code),
    INDEX idx_asset_code (asset_code)
) COMMENT='资产监控表';
```

### 3.3 资产认领表 (asset_claim)

```sql
CREATE TABLE asset_claim (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    claim_code VARCHAR(64) NOT NULL UNIQUE,
    asset_code VARCHAR(64) NOT NULL,
    claimer_id BIGINT NOT NULL,
    claim_reason TEXT,
    status VARCHAR(32) DEFAULT 'PENDING',
    approve_id BIGINT,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_claim_code (claim_code),
    INDEX idx_asset_code (asset_code)
) COMMENT='资产认领表';
```
