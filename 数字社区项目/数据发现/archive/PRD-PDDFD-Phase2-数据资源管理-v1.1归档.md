**Story RG-001：新建资源注册**

| 字段 | 内容 |
|:---|:---|
| 角色-场景-价值 | 作为数据工程师，需要将新的数据源接入平台，通过统一注册入口填写资源基本信息（名称/类型/描述）提交注册申请 |
| 优先级 | P0 |
| 状态 | 待开发 |

**验收标准**：

1. 支持选择数据源类型：业务系统数据库 / 文件资源 / 外部API / 实时数据 / 日志数据
2. 表单必填字段：资源名称、资源类型、所属系统、负责人
3. 表单选填字段：描述、标签、连接超时时间
4. 提交后创建注册记录，状态为「待配置」

**交互说明**：

点击「新建资源」按钮弹出资源类型选择Dialog；选择类型后进入对应注册表单；表单内资源类型下拉支持切换，切换时提示「切换类型将重置连接配置」；提交按钮在表单校验通过后点亮；提交后自动跳转到资源详情页（待配置状态）。

**Story RG-002：连接配置**

| 字段 | 内容 |
|:---|:---|
| 角色-场景-价值 | 作为数据工程师，为已注册资源配置连接信息（主机/端口/用户名/密码/数据库名），使系统能够访问该数据源 |
| 优先级 | P0 |
| 状态 | 待开发 |

**验收标准**：

1. 连接配置表单按数据源类型动态展示不同字段
2. 业务DB类型字段：主机、端口、数据库名、用户名、密码（加密存储）、连接参数
3. 文件资源类型字段：存储路径、文件格式、编码格式
4. API类型字段：接口地址、认证方式（None/Bearer/API Key/OAuth2）、请求超时
5. 密码字段加密展示，支持Show/Hide切换
6. 已配置的敏感信息在页面加载时脱敏显示（仅显示前3位+***）

**交互说明**：

资源详情页「连接配置」Tab；切换Tab时若未保存当前表单，提示「当前有未保存的配置，是否放弃修改」；配置字段根据资源类型动态变化；密码输入框右侧提供显示/隐藏切换图标。

**Story RG-003：连接测试**

| 字段 | 内容 |
|:---|:---|
| 角色-场景-价值 | 作为数据工程师，在配置完连接信息后，执行连接测试验证配置是否正确，及时发现连接问题避免上线后故障 |
| 优先级 | P0 |
| 状态 | 待开发 |

**验收标准**：

1. 「测试连接」按钮在连接配置表单填写完整后可见
2. 测试过程展示Loading状态（转圈 + 「正在测试连接...」）
3. 测试成功：Toast提示「连接成功」，按钮变为绿色「✅ 连接正常」
4. 测试失败：Dialog展示详细错误信息（如「连接超时」「认证失败」「数据库不存在」）
5. 测试结果关联资源状态：测试成功则状态更新为「正常」，失败保持「异常」

**交互说明**：

点击「测试连接」后按钮变为Loading状态，禁止重复点击；测试结果在按钮右侧直接展示（绿色/红色标签）；失败时点击「查看详情」展开错误信息；支持多次测试。

作为数据工程师，为已注册的日志数据源配置采集规则，包括字段映射、过滤条件、采集频率等参数

**验收标准**：

1. 支持配置字段映射：将原始日志字段映射为目标 schema 字段
2. 支持配置过滤条件：按字段值/正则过滤不需要的日志行
3. 采集频率可配置：实时 / 每分钟 / 每5分钟 / 每小时
4. 配置保存前支持预览：展示配置生效后的解析效果
5. 配置变更后支持重新解析历史数据（可选）

**交互说明**：

日志数据源详情页「采集配置」Tab；字段映射区支持可视化配置（源字段 -> 目标字段拖拽）；过滤条件以规则列表形式展示，支持添加/删除/排序；频率选择器在下拉菜单中提供预设选项；「预览」按钮展示配置解析效果。

**Story LOG-004：日志监控**

| 字段 | 内容 |
|:---|:---|
| 角色-场景-价值 | 作为数据工程师，通过日志监控视图实时查看日志采集状态、流量和错误情况，及时发现采集异常 |
| 优先级 | P1 |
| 状态 | 待开发 |

**验收标准**：

1. 展示采集状态（采集中/已停止/异常）和流量（条/秒）
2. 展示解析成功率（成功条数/总条数）
3. 展示Top5错误类型及错误数
4. 支持时间范围切换：近1小时/近24小时/近7天
5. 异常时发送告警通知（站内/邮件）

**交互说明**：

日志数据源详情页「日志监控」Tab；顶部为状态卡（采集状态/流量/成功率）；中部为流量折线图（支持鼠标悬停查看具体秒级数值）；下方为Top5错误列表；时间范围切换器在页面右上角。
