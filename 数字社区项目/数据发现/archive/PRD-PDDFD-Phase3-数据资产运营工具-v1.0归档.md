## 三、需求背景

### 3.1 目标

数据资产运营工具旨在帮助数据团队和数据治理委员会对数据资产进行运营分析，通过血缘分析、影响分析、评价打分等工具，实现数据资产的质量追踪和价值评估。

### 3.2 痛点

1. **血缘看不见**：表/字段变更时，无法快速判断影响范围，全靠人工排查
2. **影响不透明**：上游数据变更后，下游哪些指标、报表、模型会受影响，无法事前预警
3. **资产质量无量化**：数据资产质量没有量化指标，无法推动治理改进

### 3.3 核心挑战

1. 全链路表/字段级血缘的自动化构建与实时更新
2. 基于血缘的变更影响分析（向前/向后追踪）
3. 数据资产评分体系的设计与落地

#### Feature 1：全链路血缘分析（FEAT-DFD-LINEAGE-ANALYSIS）

**路由**: `/discovery/lineage`

**类型**: 🆕 新增

**功能描述**：构建并展示数据资产的完整血缘关系图谱，支持表级血缘、字段级血缘的可视化查看与分析。

**关联 Story**：

| Story ID | Story 名称 | 优先级 | 状态 |
|:---|:---|:---:|:---:|
| Story-LIN-001 | 表级血缘图谱 | P0 | 已上线 |
| Story-LIN-002 | 字段级血缘图谱 | P0 | 已上线 |
| Story-LIN-003 | 血缘搜索与定位 | P0 | 已上线 |
| Story-LIN-004 | 血缘路径导出 | P1 | 已上线 |
| Story-LIN-005 | 评价体系 | P0 | 已上线 |
| Story-LIN-006 | 评价打分 | P0 | 已上线 |
| Story-LIN-007 | 评价统计 | P0 | 已上线 |

**Story LIN-001：表级血缘图谱**

| 字段 | 内容 |
|:---|:---|
| 角色-场景-价值 | 作为数据工程师，在排查数据问题时，通过表级血缘图谱快速了解数据的上下游链路 |
| 优先级 | P0 |
| 状态 | 已上线 |

**验收标准**：
1. 输入表名后 1s 内展示该表的直接上游和下游节点
2. 血缘图谱以有向图形式展示，箭头方向表示数据流向
3. 点击节点可查看节点详情（表名、类型、更新时间）
4. 支持前向追溯和后向追溯两层

**Story LIN-002：字段级血缘图谱**

| 字段 | 内容 |
|:---|:---|
| 角色-场景-价值 | 作为数据工程师，在排查字段加工逻辑时，通过字段级血缘精确定位字段的来源和加工规则 |
| 优先级 | P0 |
| 状态 | 已上线 |

**验收标准**：
1. 字段级血缘图谱展示字段级别的加工链路
2. 支持 SQL 表达式的可视化展示
3. 字段血缘节点可点击查看字段详情

**Story LIN-005：评价体系**

| 字段 | 内容 |
|:---|:---|
| 角色-场景-价值 | 作为数据分析师，通过数据资产评价体系了解数据资产的质量等级，以便筛选高质量数据 |
| 优先级 | P0 |
| 状态 | 已上线 |

**验收标准**：
1. 评价体系包含质量、覆盖率、使用率等维度
2. 各维度权重可配置
3. 评价结果以星级或评分形式展示

#### Feature 2：变更影响分析（FEAT-DFD-IMPACT-ANALYSIS）

**路由**: `/discovery/impact-analysis`

**类型**: 🆕 新增

**功能描述**：当上游数据资产发生变更（ schema 变更、数据量异常等）时，系统自动分析对下游的影响范围，帮助数据团队评估变更风险。

**关联 Story**：

| Story ID | Story 名称 | 优先级 | 状态 |
|:---|:---|:---:|:---:|
| Story-IMP-001 | 变更影响概览 | P0 | 已上线 |
| Story-IMP-002 | 下游影响列表 | P0 | 已上线 |
| Story-IMP-003 | 影响告警订阅 | P1 | 已上线 |
| Story-IMP-004 | 资产统计 | P0 | 已上线 |
| Story-IMP-005 | 资产趋势 | P0 | 已上线 |
| Story-IMP-006 | 资产报告 | P0 | 已上线 |

**Story IMP-001：变更影响概览**

| 字段 | 内容 |
|:---|:---|
| 角色-场景-价值 | 作为数据工程师，在上游表 schema 变更前，查看变更影响概览，了解会波及多少下游资产 |
| 优先级 | P0 |
| 状态 | 已上线 |

**验收标准**：
1. 输入变更表名后 2s 内展示影响分析结果
2. 影响面以树状或图状形式展示
3. 影响范围包含：直接下游表、间接下游表、关联指标、关联报表
4. 风险等级标注（高中低）

**Story IMP-004：资产统计**

| 字段 | 内容 |
|:---|:---|
| 角色-场景-价值 | 作为数据分析师，通过资产统计了解数据资产的整体规模、使用热度、质量分布 |
| 优先级 | P0 |
| 状态 | 已上线 |

**验收标准**：
1. 展示资产总数、类型分布、环比变化
2. 数据来源、数据表、外部数据源分类统计
3. 支持时间维度切换（近7天/30天/自定义）
