## 一、产品概述

### 1.1 产品定位
数据资源管理是数据发现产品域的核心组成部分，提供数据资源（数据库、表、文件等）的统一管理能力。

### 1.2 核心价值

| 价值 | 说明 |
|:---|:---|
| 统一管理 | 统一管理各类数据资源 |
| 便捷检索 | 快速检索所需资源 |
| 实时监控 | 监控资源状态和性能 |
