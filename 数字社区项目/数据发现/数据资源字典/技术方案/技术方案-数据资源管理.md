## 三、数据库设计

### 3.1 资源表 (data_resource)

```sql
CREATE TABLE data_resource (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    resource_code VARCHAR(64) NOT NULL UNIQUE,
    resource_name VARCHAR(128) NOT NULL,
    resource_type VARCHAR(32) NOT NULL COMMENT 'DATABASE/FILE/API',
    connection_config JSON COMMENT '连接配置',
    status VARCHAR(32) DEFAULT 'ACTIVE',
    last_sync_time DATETIME,
    owner_id BIGINT,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_resource_code (resource_code),
    INDEX idx_resource_type (resource_type)
) COMMENT='数据资源表';
```

### 3.2 资源监控表 (resource_monitor)

```sql
CREATE TABLE resource_monitor (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    resource_code VARCHAR(64) NOT NULL,
    monitor_type VARCHAR(32) NOT NULL COMMENT 'CONNECTION/PERFORMANCE',
    monitor_value TEXT,
    status VARCHAR(32) DEFAULT 'NORMAL',
    alert_time DATETIME,
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_resource_code (resource_code)
) COMMENT='资源监控表';
```
