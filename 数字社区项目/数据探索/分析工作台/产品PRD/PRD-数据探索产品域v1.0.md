## 一、产品概述

### 1.1 产品定位
数据探索产品域（PD-DEX）为企业提供客户360全景分析、指标管理和自助分析能力。

### 1.2 核心价值

| 价值 | 说明 |
|:---|:---|
| 客户洞察 | 360度客户全景视图 |
| 指标管理 | 指标定义、计算、监控 |
| 自助分析 | 低代码数据分析工具 |
| 协作分享 | 分析结果分享与协作 |

### 1.3 目标用户

- **客户经理**：查看客户信息、分析客户画像
- **策略分析师**：分析客户行为、制定策略
- **数据分析师**：自助取数、制作报表
- **管理者**：业务数据监控、决策支持

## 二、产品架构

PD-DEX 数据探索域包含：

| 模块 | 说明 |
|:---|:---|
| **客户360（EPIC-DEX-C360）** | 客户搜索、详情、画像、征信解析 |
| **指标仪表盘（EPIC-DEX-METRIC）** | 指标管理、看板、预警 |
| **分析工作台（EPIC-DEX-ANALYSIS）** | SQL查询、数据透视、可视化 |
