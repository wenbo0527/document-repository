# FEAT-DEX-FLOW - 分析流程管理

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-DEX-FLOW |
| Feature 名称 | 分析流程管理 |
| 所属 EPIC | EPIC-DEX-ANALYSIS 分析工具 |
| 所属产品域 | PD-DEX 数据探索 |

## 2. 概述

数据分析流程的可视化编排和管理。

## 3. 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 流程列表。**筛选器**：流程名称(模糊)、状态(草稿/已发布/运行中/已停止)、创建人 |
| FP-002 | 页面 | 创建流程。**交互**：拖拽添加数据处理节点(数据源/数据转换/数据聚合/数据关联/数据输出)，连接上下游节点 |
| FP-003 | 页面 | 配置节点属性。**交互**：点击节点 → 属性面板，**可配**：节点名称、数据源、SQL模板 |
| FP-004 | 页面 | 运行流程。**交互**：点击运行按钮，**状态**：运行中(绿)、已完成(蓝)、失败(红) |
| FP-005 | 页面 | 停止流程。**交互**：点击停止按钮 |
| FP-006 | 页面 | 查看日志。**交互**：点击日志按钮，**内容**：执行步骤、耗时、错误信息 |
| FP-007 | 页面 | 数据源配置。**交互**：新建/编辑/测试/删除数据源，**类型**：MySQL/Hive/Kafka/API |
| FP-008 | 页面 | 流程CRUD。**交互**：创建、编辑、删除流程，**确认**：删除需二次确认 |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 流程列表筛选正确区分草稿/已发布/运行中/已停止 |
| 功能验收 | 拖拽添加节点正常，连接线正确 |
| 功能验收 | 运行流程状态正确更新 |
| 功能验收 | 日志正确展示执行步骤和耗时 |
| 功能验收 | 数据源测试连接返回成功/失败 |
| 功能验收 | 删除流程需二次确认 |

## 5. 依赖关系
