# FEAT-DEX-DASHBOARD - 指标看板

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-DEX-DASHBOARD |
| Feature 名称 | 指标看板 |
| 所属 EPIC | EPIC-DEX-ANALYSIS 分析工具 |
| 所属产品域 | PD-DEX 数据探索 |

## 2. 概述

业务指标统一监控看板，展示关键业务指标的实时数据和趋势。

## 3. 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 指标卡片展示。**指标**：今日放款金额、今日放款笔数、今日新增客户、今日到期笔数、今日逾期金额 |
| FP-002 | 页面 | 趋势图表。**图表类型**：折线图(趋势)、柱状图(对比)、饼图(构成)、漏斗图(转化)，**时间**：今日/近7天/近30天/本月/本季度/自定义 |
| FP-003 | 页面 | 指标筛选。**交互**：选择要展示的指标，**方式**：勾选指标卡片 |
| FP-004 | 页面 | 导出数据。**交互**：点击导出按钮，**格式**：Excel |
| FP-005 | 页面 | 刷新数据。**交互**：点击刷新按钮，**延迟**：≤1分钟 |
| FP-006 | 页面 | 切换图表类型。**交互**：选择图表类型下拉，**选项**：折线/柱状/饼图/漏斗 |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 指标卡片正确展示放款金额/笔数/客户数/到期笔数/逾期金额 |
| 功能验收 | 时间范围切换正确刷新数据 |
| 功能验收 | 图表类型切换正常 |
| 功能验收 | 指标筛选正确显示/隐藏指标 |
| 功能验收 | 导出数据为Excel格式 |
| 功能验收 | 刷新延迟≤1分钟 |

## 5. 依赖关系

| 依赖项 | 类型 | 说明 |
|:---|:---|:---|
| PD-DMT | 上游 | 指标数据来源于PD-DMT数据服务 |
| PD-RISK | 上游 | 逾期指标来源于风控系统 |
