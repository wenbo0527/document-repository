## 三、数据库设计

### 3.1 客户档案表 (customer_profile)

```sql
CREATE TABLE customer_profile (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    customer_code VARCHAR(64) NOT NULL UNIQUE,
    customer_name VARCHAR(128) NOT NULL,
    phone VARCHAR(32),
    email VARCHAR(128),
    gender VARCHAR(16),
    age INT,
    birthday DATE,
    status VARCHAR(32) DEFAULT 'ACTIVE',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_customer_code (customer_code)
) COMMENT='客户档案表';
```

### 3.2 客户画像表 (customer_portrait)

```sql
CREATE TABLE customer_portrait (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    customer_code VARCHAR(64) NOT NULL,
    tag_type VARCHAR(32) NOT NULL COMMENT '基础/行为/偏好/价值',
    tag_code VARCHAR(64) NOT NULL,
    tag_name VARCHAR(128) NOT NULL,
    tag_value TEXT,
    confidence DECIMAL(5,3) COMMENT '置信度',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_customer_code (customer_code),
    INDEX idx_tag_type (tag_type)
) COMMENT='客户画像表';
```

### 3.3 客户轨迹表 (customer_track)

```sql
CREATE TABLE customer_track (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    customer_code VARCHAR(64) NOT NULL,
    track_type VARCHAR(32) NOT NULL COMMENT 'BEHAVIOR/TRADE/INTERACTION',
    track_time DATETIME NOT NULL,
    track_event VARCHAR(256) NOT NULL,
    track_detail TEXT,
    source_system VARCHAR(64),
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_customer_code (customer_code),
    INDEX idx_track_time (track_time)
) COMMENT='客户轨迹表';
```

## 四、接口设计

| 接口 | 方法 | 说明 |
|:---|:---:|:---|
| `/api/v1/360/profile/{code}` | GET | 获取客户档案 |
| `/api/v1/360/profile/{code}/update` | PUT | 更新档案 |
| `/api/v1/360/portrait/{code}` | GET | 获取客户画像 |
| `/api/v1/360/track/{code}` | GET | 获取客户轨迹 |
| `/api/v1/360/value/{code}` | GET | 获取客户价值 |
