## 三、数据库设计

### 3.1 仪表盘表 (dashboard)

```sql
CREATE TABLE dashboard (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    dashboard_code VARCHAR(64) NOT NULL UNIQUE,
    dashboard_name VARCHAR(128) NOT NULL,
    dashboard_desc TEXT,
    layout_config JSON COMMENT '布局配置',
    owner_id BIGINT NOT NULL,
    status VARCHAR(32) DEFAULT 'ACTIVE',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_dashboard_code (dashboard_code),
    INDEX idx_owner_id (owner_id)
) COMMENT='仪表盘表';
```

### 3.2 仪表盘组件表 (dashboard_widget)

```sql
CREATE TABLE dashboard_widget (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    widget_code VARCHAR(64) NOT NULL UNIQUE,
    dashboard_code VARCHAR(64) NOT NULL,
    widget_type VARCHAR(32) NOT NULL COMMENT 'CARD/CHART/TABLE',
    widget_config JSON NOT NULL COMMENT '组件配置',
    position_config JSON COMMENT '位置配置',
    data_config JSON COMMENT '数据配置',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_widget_code (widget_code),
    INDEX idx_dashboard_code (dashboard_code)
) COMMENT='仪表盘组件表';
```

### 3.3 指标配置表 (indicator_config)

```sql
CREATE TABLE indicator_config (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    indicator_code VARCHAR(64) NOT NULL UNIQUE,
    indicator_name VARCHAR(128) NOT NULL,
    indicator_sql TEXT NOT NULL COMMENT '指标计算SQL',
    refresh_interval INT COMMENT '刷新间隔(秒)',
    status VARCHAR(32) DEFAULT 'ACTIVE',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_indicator_code (indicator_code)
) COMMENT='指标配置表';
```

## 四、接口设计

| 接口 | 方法 | 说明 |
|:---|:---:|:---|
| `/api/v1/dashboard/list` | GET | 仪表盘列表 |

| `/api/v1/dashboard/{code}/export` | GET | 导出仪表盘 |
