# FEAT-DEX-C360-CREDIT - 授信信息

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-DEX-C360-CREDIT |
| Feature 名称 | 授信信息 |
| 所属 EPIC | EPIC-DEX-CUSTOMER 客户中心 |
| 所属产品域 | PD-DEX 数据探索 |

## 2. 概述

客户授信相关信息展示，包括授信额度、额度使用、征信报告等。

## 3. 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 额度概览卡片。**字段**：授信总额度、已用额度、可用额度、额度使用率 |
| FP-002 | 页面 | 额度使用图表。**图表**：额度使用可视化(饼图/柱状图) |
| FP-003 | 页面 | 征信报告。**字段**：查询时间、查询机构、信用评分、信用等级 |
| FP-004 | 页面 | 授信历史。**字段**：调整时间、调整类型(提额/降额/冻结)、调整前后额度、调整原因 |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 额度卡片正确展示总额度、已用、可用、使用率 |
| 功能验收 | 图表正确可视化额度使用情况 |
| 功能验收 | 征信报告正确展示查询记录 |
| 功能验收 | 授信历史正确展示调整记录 |
| 功能验收 | 状态正确区分提额/降额/冻结 |

## 5. 依赖关系

| 依赖项 | 类型 | 说明 |
|:---|:---|:---|
| FEAT-DEX-C360-SEARCH | 上游 | 授信数据依赖客户查询结果 |
