# FEAT-DEX-C360-BENEFIT - 权益记录

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-DEX-C360-BENEFIT |
| Feature 名称 | 权益记录 |
| 所属 EPIC | EPIC-DEX-CUSTOMER 客户中心 |
| 所属产品域 | PD-DEX 数据探索 |

## 2. 概述

客户权益发放和使用记录查询。

## 3. 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 权益记录查询。**筛选器**：权益类型(优惠券/积分/卡券/礼品)、发放状态(已发放/已使用/已过期/已作废)、发放时间范围 |
| FP-002 | 页面 | 权益记录列表。**字段**：权益名称、类型(优惠券红/积分橙/卡券蓝/礼品绿)、发放时间、有效期、状态(已发放蓝/已使用绿/已过期灰/已作废红)、关联活动 |
| FP-003 | 页面 | 查看详情。**交互**：点击查看详情弹窗 |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 类型筛选正确区分优惠券/积分/卡券/礼品 |
| 功能验收 | 状态筛选正确区分已发放/已使用/已过期/已作废 |
| 功能验收 | 类型标签颜色正确(优惠券红/积分橙/卡券蓝/礼品绿) |
| 功能验收 | 详情弹窗正确展示权益信息 |

## 5. 依赖关系

| 依赖项 | 类型 | 说明 |
|:---|:---|:---|
| FEAT-DEX-C360-SEARCH | 上游 | 权益数据依赖客户查询结果 |
| PD-MKT | 上游 | 权益记录来源于营销系统 |
