# FEAT-DEX-C360-TOUCH - 触达记录

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-DEX-C360-TOUCH |
| Feature 名称 | 触达记录 |
| 所属 EPIC | EPIC-DEX-CUSTOMER 客户中心 |
| 所属产品域 | PD-DEX 数据探索 |

## 2. 概述

客户触达历史记录查询。

## 3. 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 触达记录查询。**筛选器**：触达类型(短信/推送/外呼)、触达状态(成功/失败/未触达)、时间范围 |
| FP-002 | 页面 | 触达记录列表。**字段**：触达时间、类型、内容摘要、状态(成功绿/失败红/未触达灰)、渠道、用户反馈 |
| FP-003 | 页面 | 查看详情。**交互**：点击查看详情弹窗，**内容**：触达完整内容、发送参数、用户处理结果 |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 触达类型筛选正确区分短信(绿)/推送(蓝)/外呼(橙) |
| 功能验收 | 状态筛选正确区分成功(绿)/失败(红)/未触达(灰) |
| 功能验收 | 详情弹窗正确展示触达完整内容 |
| 功能验收 | 列表支持分页 |

## 5. 依赖关系

| 依赖项 | 类型 | 说明 |
|:---|:---|:---|
| FEAT-DEX-C360-SEARCH | 上游 | 触达数据依赖客户查询结果 |
| PD-MKT | 上游 | 触达记录来源于营销系统 |
