# FEAT-DEX-C360-POSTLOAN - 贷后信息

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-DEX-C360-POSTLOAN |
| Feature 名称 | 贷后信息 |
| 所属 EPIC | EPIC-DEX-CUSTOMER 客户中心 |
| 所属产品域 | PD-DEX 数据探索 |

## 2. 概述

客户贷后管理信息展示，包括还款记录、逾期情况、催收记录等。

## 3. 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 贷后概览卡片。**字段**：当前待还金额、下个账期金额、逾期金额、逾期天数 |
| FP-002 | 页面 | 还款计划列表。**字段**：计划还款日、计划金额、已还金额、剩余金额、状态(正常/逾期/已还清) |
| FP-003 | 页面 | 还款记录。**字段**：还款时间、还款金额、还款方式 |
| FP-004 | 页面 | 逾期记录。**字段**：逾期期数、开始日期、天数、本金、利息、罚息、是否还清 |
| FP-005 | 页面 | 催收记录。**字段**：催收时间、方式(短信/电话/上门)、人员、结果、备注 |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 贷后概览正确展示待还、逾期金额和天数 |
| 功能验收 | 还款计划状态正确区分(正常绿/逾期红/已还清蓝) |
| 功能验收 | 逾期记录正确展示本金、利息、罚息 |
| 功能验收 | 催收记录正确展示方式和结果 |
| 功能验收 | 列表支持分页 |

## 5. 依赖关系

|:---|:---|:---|
| FEAT-DEX-C360-SEARCH | 上游 | 贷后数据依赖客户查询结果 |
