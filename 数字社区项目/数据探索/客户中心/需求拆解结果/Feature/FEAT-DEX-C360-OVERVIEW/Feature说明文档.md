# FEAT-DEX-C360-OVERVIEW - 客户概览

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-DEX-C360-OVERVIEW |
| Feature 名称 | 客户概览 |
| 所属 EPIC | EPIC-DEX-CUSTOMER 客户中心 |
| 所属产品域 | PD-DEX 数据探索 |

## 2. 概述

### 2.1 是什么
客户基础信息和标签展示区域。

### 2.2 解决什么问题
- 客户基础信息分散
- 缺乏统一的客户标签展示

## 3. 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 基础信息展示。**字段**：统一客户ID、姓名、性别、年龄、身份证号(脱敏)、手机号(脱敏)、注册时间 |
| FP-002 | 页面 | 标签展示。**标签类型**：客户类型、客户等级、风险标签、活跃标签，**颜色**：高风险(红)、中风险(橙)、低风险(绿)、活跃(绿)、沉默(灰)、流失(红) |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 基础信息正确展示客户ID、姓名、性别、年龄 |
| 功能验收 | 身份证号和手机号正确脱敏显示 |
| 功能验收 | 标签正确分类展示(客户类型/等级/风险/活跃) |
| 功能验收 | 风险颜色正确区分(高风险红/中风险橙/低风险绿) |
| 功能验收 | 活跃颜色正确区分(活跃绿/沉默灰/流失红) |
