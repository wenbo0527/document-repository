# FEAT-DEX-C360-SEARCH - 客户360搜索

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-DEX-C360-SEARCH |
| Feature 名称 | 客户360搜索 |
| 所属 EPIC | EPIC-DEX-CUSTOMER 客户中心 |
| 所属产品域 | PD-DEX 数据探索 |

## 2. 概述

### 2.1 是什么
客户信息统一查询和分析平台，提供精确搜索和模糊搜索两种方式。

### 2.2 解决什么问题
- 客户信息分散，难以统一查询
- 缺乏多种搜索方式

## 3. 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 精确搜索，按用户ID精确查询。**字段**：用户ID(必填)，**结果**：直接跳转客户详情 |
| FP-002 | 页面 | 模糊搜索，按姓名+身份证查询。**字段**：姓名(完整)、身份证后6位，**结果**：展示匹配客户列表 |
| FP-003 | 页面 | 搜索结果，匹配客户列表展示。**字段**：统一客户ID、姓名、产品名称，**交互**：点击行跳转客户详情 |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 精确搜索：用户ID必填，结果直接跳转详情 |
| 功能验收 | 模糊搜索：姓名+身份证后6位必填 |
| 功能验收 | 搜索结果正确展示统一客户ID、姓名、产品名称 |
| 功能验收 | 点击搜索结果行跳转客户详情页 |
| 性能验收 | 搜索响应时间≤2s |

## 5. 依赖关系

|:---|:---|:---|
