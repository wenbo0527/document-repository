# FEAT-DEX-C360-PRODUCT - 产品信息

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-DEX-C360-PRODUCT |
| Feature 名称 | 产品信息 |
| 所属 EPIC | EPIC-DEX-CUSTOMER 客户中心 |
| 所属产品域 | PD-DEX 数据探索 |

## 2. 概述

客户持有的金融产品信息展示。

## 3. 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 产品概览。**字段**：持有产品数、历史申请数、通过数、拒绝数 |
| FP-002 | 页面 | 产品列表卡片。**字段**：产品名称、类型(贷款/信用卡/分期)、授信额度、在贷余额、状态(正常/逾期/已结清/已拒绝)、利率、期限 |
| FP-003 | 页面 | 产品详情弹窗。**Tab**：基本信息、费用信息、账户信息、还款计划、历史还款 |
| FP-004 | 页面 | 产品还款计划。**字段**：期数、计划还款日、计划金额、已还金额、状态 |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 产品概览正确展示持有/申请/通过/拒绝数量 |
| 功能验收 | 产品卡片状态正确区分(正常绿/逾期红/已结清蓝/已拒绝灰) |
| 功能验收 | 详情弹窗Tab切换正常 |
| 功能验收 | 还款计划状态正确区分 |
| 功能验收 | 列表支持分页 |

## 5. 依赖关系

| 依赖项 | 类型 | 说明 |
|:---|:---|:---|
| FEAT-DEX-C360-SEARCH | 上游 | 产品数据依赖客户查询结果 |
