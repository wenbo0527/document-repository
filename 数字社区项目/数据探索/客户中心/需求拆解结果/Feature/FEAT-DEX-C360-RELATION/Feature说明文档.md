# FEAT-DEX-C360-RELATION - 关系查询与图谱

## 1. 基本信息

| 字段 | 内容 |
|:---|:---|
| Feature ID | FEAT-DEX-C360-RELATION |
| Feature 名称 | 关系查询与图谱 |
| 所属 EPIC | EPIC-DEX-CUSTOMER 客户中心 |
| 所属产品域 | PD-DEX 数据探索 |

## 2. 概述

客户关系网络查询和可视化展示。

## 3. 功能清单

| 功能点 | 类型 | 描述 |
|:---|:---|:---|
| FP-001 | 页面 | 关系类型查询。**类型**：联系人、担保关系、共同申请人、共同贷款人、账户关联 |
| FP-002 | 页面 | 关系列表展示。**字段**：关系类型、关联对象、关联时间、状态(有效/已解除) |
| FP-003 | 页面 | 关系图谱可视化。**节点颜色**：当前客户(蓝)、联系人(绿)、担保人(橙)、共同申请人(紫)、共同设备(灰) |
| FP-004 | 页面 | 图谱交互操作。**交互**：缩放、拖动节点、查看节点详情、展开/收起关联节点 |

## 4. 验收标准

| 验收项 | 标准 |
|:---|:---|
| 功能验收 | 关系类型正确区分5种关系 |
| 功能验收 | 关系列表正确展示关联信息 |
| 功能验收 | 图谱节点颜色正确区分类型 |
| 功能验收 | 图谱支持缩放和拖动 |
| 功能验收 | 点击节点正确展示详情 |

## 5. 依赖关系

| 依赖项 | 类型 | 说明 |
|:---|:---|:---|
| FEAT-DEX-C360-SEARCH | 上游 | 关系数据依赖客户查询结果 |
