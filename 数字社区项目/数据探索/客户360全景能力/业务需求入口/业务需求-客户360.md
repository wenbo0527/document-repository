# 业务需求 - 客户360

> **版本**: v2.0
> **日期**: 2026-04-29
> **作者**: Tony Stark
> **状态**: 已上线
> **定位**: 客户360全景能力业务需求文档，被客服系统和人工审批系统调用

---

## 一、业务背景

### 1.1 目标
构建客户360全景能力，作为客户信息查询系统被客服系统和人工审批系统调用，提供统一的客户信息视图。

### 1.2 系统定位
- **上游调用方**：客服系统、人工审批系统
- **本系统角色**：信息提供方，无下游业务系统

### 1.3 痛点

1. 客户数据分散在多个系统，客服和审批人员缺乏统一的查询入口
2. 客户信息不全，无法支撑客服和审批决策
3. 缺乏完整的历史记录展示，影响服务质量

---

## 二、业务需求

### 2.1 客户搜索（FEAT-DEX-C360-SEARCH）

- 精确搜索：按客户ID（UserId）精确查询，回车键快捷搜索
- 模糊搜索：按姓名+身份证组合查询，列表展示
- 自动跳转：唯一结果3秒自动跳转到详情页

### 2.2 客户360详情（FEAT-DEX-C360-DETAIL）

详情页整合以下子模块数据，支撑客服和审批决策：

| 子模块 | Feature | 说明 |
|:---|:---|:---|
| 客户基本信息 | FEAT-DEX-C360-BASIC | 基础信息展示、账户概览 |
| 客户画像分析 | FEAT-DEX-C360-PROFILE | 人口统计、行为、消费、风险特征 |
| 产品信息总览 | FEAT-DEX-C360-PRODUCT | 授信明细、借据详情 |
| 贷款记录管理 | FEAT-DEX-C360-LOAN | 还款明细、还款计划、放款记录 |
| 调额历史 | FEAT-DEX-C360-ADJUST | 额度调整历史 |
| 催收记录 | FEAT-DEX-C360-COLLECT | 催收详情与跟进 |
| 征信记录 | FEAT-DEX-C360-CREDIT | 征信报告查询展示 |
| 营销记录 | FEAT-DEX-C360-MARKETING | 触达记录、权益发放、营销效果分析 |
| 支付流程 | FEAT-DEX-C360-PAYMENT | 签约记录、还款记录 |
| 数据反馈 | FEAT-DEX-C360-FEEDBACK | 问题反馈入口 |

#### 2.2.1 客户基本信息
- 基础信息展示：脱敏展示姓名、年龄、性别、手机号、身份证号等
- 账户概览：账户状态、客户等级、历史逾期天数、总在贷余额、授信金额

#### 2.2.2 客户画像分析
- 人口统计特征：年龄段、性别、地域、职业、收入水平
- 行为特征：活跃度、使用习惯、功能偏好、操作行为
- 消费与风险特征：消费能力、信用等级、还款能力

#### 2.2.3 产品信息总览
- 授信明细列表：产品名称、状态、授信/已用/可用金额，支持搜索筛选
- 借据详情：抽屉展示借据基本信息、用信记录列表

#### 2.2.4 贷款记录管理
- 还款明细：期次、应还日期、实际还款日期、金额、银行卡信息
- 还款计划：未来还款计划，含期次、应还金额、剩余余额、状态
- 放款记录：批次号、放款日期、金额、银行名称、交易流水号

#### 2.2.5 调额历史
- 调额历史展示：调额日期、前后金额、利率、期限变化、调额原因、操作人

#### 2.2.6 催收记录
- 催收详情：催收日期、方式、催收员信息、联系结果、客户响应
- 催收跟进：承诺金额、日期、跟进措施、催收效果评分、通话时长

#### 2.2.7 征信记录
- 征信报告：信用评分、信用等级、风险等级、查询次数、逾期次数
- 报告内容详情：个人信息、信贷历史、公共记录查询与展示

#### 2.2.8 营销记录
- 触达记录：触达日期、渠道、活动名称、内容、结果、响应动作
- 权益发放记录：权益类型、名称、价值、状态、使用日期、过期日期
- 营销效果分析：触达次数、转化率、总成本、ROI、客户终身价值

#### 2.2.9 支付流程
- 签约记录：合同编号、状态、金额、签约日期、合同文件
- 还款记录：还款金额、方式、日期、交易流水号、本金利息明细

#### 2.2.10 数据反馈
- 反馈入口：在客户全景看板提供数据反馈入口，支持问题截图上传
