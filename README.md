## 概述

### 这是什么？

文档仓库是企业数字化产品的集中文档存储中心，包含产品管理系统的工具文档和数字社区产品的业务文档。

### 为什么重要？

- **统一存储**：所有产品文档集中管理
- **版本可控**：Git 版本控制，可追溯变更历史
- **结构清晰**：按产品域、EPIC 分层组织
- **协作友好**：支持飞书文档同步

### 适用场景？

- 查看产品需求文档（PRD）
- 了解 EPIC 拆解结果
- 参考技术方案和操作手册
- 产品管理 SOP 执行

## 文档写入规范

### 命名规范

```
格式: YYYY-MM-DD-类型-标题.md

类型:
- PRD      - 产品需求文档
- 需求     - 业务需求
- 设计     - 技术设计方案
- 周报     - 周期性报告
- 会议     - 会议纪要
- 报告     - 分析报告
```

### 存储路径规则

| 文档类型 | 存储路径 |
|:---|:---|
| 产品 PRD | `数字社区项目/{产品域}/{EPIC}/产品PRD/` |
| 业务需求 | `数字社区项目/{产品域}/{EPIC}/业务需求入口/` |
| 需求拆解 | `数字社区项目/{产品域}/{EPIC}/需求拆解结果/` |
| 技术方案 | `数字社区项目/{产品域}/{EPIC}/技术方案/` |
| 操作手册 | `数字社区项目/{产品域}/{EPIC}/产品操作手册/` |
| 产品管理 PRD | `产品管理项目/PRD/主文档/` |
| 本体论文档 | `产品管理项目/本体论/` |
