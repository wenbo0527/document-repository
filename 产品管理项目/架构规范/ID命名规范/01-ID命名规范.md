> **版本**: v1.0
> **日期**: 2026-04-24
> **作者**: Tony Stark
> **状态**: 正式发布

---

## 1. 概述

本文档定义产品管理系统的 ID 命名规范，确保系统中的标识符唯一、可读、易于管理。

---

## 2. 命名原则

| 原则 | 说明 |
|:---|:---|
| 唯一性 | 每个 ID 在系统中唯一 |
| 可读性 | ID 体现业务含义 |
| 可扩展性 | ID 结构支持扩展 |
| 简洁性 | 避免过长，但保持清晰 |

---

## 3. 产品域编码

### 3.1 编码规则

```
PD-{DOMAIN}
```

| 部分 | 说明 | 示例 |
|:---|:---|:---|
| PD | Product Domain 前缀 | PD |
| {DOMAIN} | 2-4字母缩写 | MKT, RISK, DFD |

| 数据探索 | PD-DEX | Data Exploration |
| 数据管理 | PD-DMT | Data Management |
| 数字社区 | PD-COM | Community |

## 9. 编码校验规则

### 9.1 格式校验

- 长度：不超过 50 字符
- 字符：只能包含字母、数字、连字符
- 连字符：不能在首尾

### 9.2 正则表达式

```regex
^[A-Z]{2,4}-[A-Z0-9]+(-[0-9]{3})?$
```
