## 三、架构选型

### 3.1 微服务架构

| 维度 | 方案 | 说明 |
|:---|:---|:---|
| **服务拆分** | 按产品域拆分 | PD-COM / PD-DFD / PD-DMT / PD-RISK / PD-MKT / PD-DEX |
| **服务发现** | Consul / Nacos | 服务注册与发现 |
| **配置中心** | Apollo / Nacos | 统一配置管理 |
| **网关** | Spring Cloud Gateway / Kong | 统一入口 |
| **链路追踪** | Skywalking / Jaeger | 分布式追踪 |

### 3.2 数据架构

| 组件 | 选型 | 用途 |
|:---|:---|:---|
| **关系数据库** | MySQL 8.0 | 业务数据、用户数据 |
| **图数据库** | Neo4j Enterprise | 产品层级、血缘关系 |
| **缓存** | Redis Cluster | 会话、热点数据 |
| **消息队列** | Kafka | 事件驱动、数据同步 |
| **搜索引擎** | Elasticsearch | 全文检索、日志分析 |
| **OLAP** | ClickHouse | 自助分析、指标计算 |
| **对象存储** | OSS / MinIO | 文件、日志、备份 |
| **时序数据库** | InfluxDB / TDengine | 指标监控 |

### 3.3 部署架构

| 方案 | 适用场景 | 说明 |
|:---|:---|:---|
| **容器化（K8s）** | 生产环境 | K8s + Helm Chart |
| **Docker Compose** | 预发布/开发 | 快速部署 |
| **混合云部署** | 金融场景 | 核心数据本地，AI能力云上 |

## 四、网络规划

### 4.1 网络分区

```
DMZ区（公网访问）
    │
    ▼
负载均衡（SLB）
    │
    ▼
应用区（K8s Cluster）
    │  │  │  │  │  │
    ▼  ▼  ▼  ▼  ▼  ▼
  COM DFD DMT RIS MKT DEX
    │
    ▼
数据区（内网隔离）
MySQL / Neo4j / Redis / Kafka
```

### 4.2 核心网络配置

| 配置项 | 说明 |
|:---|:---|
| **VPC** | 私有网络隔离 |
| **安全组** | 按组件划分入站/出站规则 |
| **SLB** | 公网/私网负载均衡 |
| **NAT网关** | 外网访问 |
| **VPN** | 远程运维 |

## 六、运维监控

### 6.1 监控体系

| 组件 | 工具 | 监控指标 |
|:---|:---|:---|
| **基础设施** | Prometheus + Node Exporter | CPU/内存/磁盘/网络 |
| **应用** | Spring Boot Actuator | JVM/接口/QPS/延迟 |
| **数据库** | mysqld_exporter / neo4j_exporter | 连接数/慢查询/缓存命中率 |
| **消息队列** | kafka_exporter | 消费 lag/吞吐量/延迟 |
| **日志** | ELK / Loki | 应用日志/错误日志 |
| **链路追踪** | Skywalking / Jaeger | 调用链/性能分析 |
| **告警** | AlertManager + 飞书/钉钉 | 阈值告警/异常告警 |

### 6.2 高可用指标

| 指标 | 目标 | 说明 |
|:---|:---:|:---|
| **服务可用性** | 99.9% | 核心服务 |
| **数据库可用性** | 99.99% | 金融级要求 |
| **接口响应时间** | <200ms P99 | 常用接口 |
| **数据同步延迟** | <1min | 实时性要求 |
| **RTO（恢复时间）** | <15min | 故障恢复 |
| **RPO（数据丢失）** | <5min | 数据恢复 |
