---

## 1. 概述

### 1.1 目标

日常维护文档、Neo4j、飞书的同步一致性

### 1.2 触发时机

- 定期维护（建议每周）
- 发现数据不一致
- 版本更新

### 1.3 输入

- 上次维护记录
- 健康检查报告

### 1.4 输出

- 维护报告
- 问题修复记录
- 更新后的文档/数据

---

## 2. 处理流程

### 步骤 1: 健康检查

**Skill 调用**：`health-check`

**执行频率**：每周一次

**检查项**：

| 检查项 | 检查内容 | 工具 |
|:---|:---|:---|
| Neo4j 检查 | 节点数量、关系完整性 | `neo4j_check.py` |
| 飞书检查 | 文档同步状态 | `feishu_check.py` |
| Wiki 检查 | 知识库完整性 | `wiki_check.py` |
| 模板检查 | 模板版本 | `template_check.py` |

**操作**：
```bash
# 执行健康检查
python3 health_check.py --report

# 输出检查报告
# /tmp/health_check_report_{date}.json
```

---

### 步骤 2: 问题修复

**问题分类处理**：

| 问题类型 | 处理方式 | Skill |
|:---|:---|:---|
| 文档缺失 | 创建/补齐 | `requirement-breakdown` |
| 数据不一致 | 修复 Neo4j | `neo4j-product-domain-repair` |
| 版本过期 | 更新版本 | 手动 |
| 关系缺失 | 补充关系 | `neo4j-product-domain-repair` |

**操作流程**：
1. 确认问题清单
2. 按优先级修复
3. 验证修复结果

---

### 步骤 3: Wiki 维护

**Skill 调用**：`wiki-maintenance`

**执行频率**：每周一次

**检查项**：

| 检查项 | 说明 |
|:---|:---|
| 文档完整性 | 专题文档是否齐全 |
| 双向链接 | 链接是否有效 |
| 内容时效性 | 是否过期 |
| 格式规范 |是否符合规范 |

**维护操作**：
1. 创建/更新专题文档
2. 修复失效链接
3. 更新过期内容
4. 补充双向链接

---

### 步骤 4: 飞书同步

**Skill 调用**：`feishu-sync`

**触发条件**：
- PRD 定稿后
- Epic 状态变更
- 每周定期同步

**同步内容**：

| 内容 | 同步方式 |
|:---|:---|
| PRD 文档 | 手动同步 |
| 状态变更 | 自动同步 |
| 里程碑 | 自动同步 |
| 周报 | 自动同步 |

**操作**：
```bash
# 同步 PRD 到飞书
python3 feishu_sync.py --type prd --id {doc_id}

# 同步状态到飞书
python3 feishu_sync.py --type status --domain {domain}
```
