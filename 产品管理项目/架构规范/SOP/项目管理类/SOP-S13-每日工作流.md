## 6. 状态同步流程

### 6.1 Neo4j 状态同步

**同步时机**:
- Epic/Feature/Story 状态变更时
- 每日傍晚（批量同步）

**同步内容**:

| 字段 | 来源 | 同步方式 |
|:---|:---|:---|
| status | 开发反馈 | 手动更新 |
| completion | Story 完成比例 | 自动计算 |
| updatedAt | 系统时间 | 自动更新 |

**同步命令**:
```python
# Neo4j 状态更新示例
from neo4j import GraphDatabase
driver = GraphDatabase.driver("bolt://localhost:7687", auth=("neo4j", "password123"))

with driver.session() as tx:
    tx.run('''
        MATCH (s:Story {uri: $uri})
        SET s.status = $status,
            s.updatedAt = datetime()
    ''', uri=story_uri, status=status)

driver.close()
```

### 6.2 飞书状态同步

**同步时机**:
- PRD 定稿后
- Epic 状态变更时
- 每周五（周报同步）

**同步内容**:

| 飞书表格 | 同步内容 | 同步方式 |
|:---|:---|:---|
| 需求确认表 | Epic/Feature/Story 状态 | 手动/自动 |
| 里程碑跟踪表 | 里程碑进度 | 手动 |
| 风险跟踪表 | 风险状态 | 手动 |

## 10. 附录：常见问题处理

| 问题 | 处理方式 |
|:---|:---|
| 健康检查失败 | 立即查询问题节点，修复后重跑 |
| 预警触发 | 按级别响应，2h/当日/3日内处理 |
| Neo4j 连接失败 | 重试 3 次，间隔 10 秒，仍失败则记录日志 |
| 飞书同步失败 | 加入队列，延迟处理，记录重试 |
