> **版本**: v1.0
> **日期**: 2026-04-24
> **作者**: Tony Stark
> **状态**: 正式发布

---

## 1. 概述

### 1.1 目标

识别、评估、跟踪、应对项目风险，降低风险影响

### 1.2 触发时机

- 项目启动时
- 定期检查（周报）
- 风险事件发生时

### 1.3 输入

- 项目计划
- 历史风险数据
- 团队反馈

### 1.4 输出

- 风险清单
- 风险预警
- 应对措施

---

## 2. 处理流程

### 步骤 1: 风险识别

**识别方法**：

| 方法 | 说明 |
|:---|:---|
| 头脑风暴 | 团队讨论可能的 risks |
| 检查表法 | 基于历史风险清单检查 |
| SWOT 分析 | 分析优势/劣势/机会/威胁 |
| 专家访谈 | 向有经验的人请教 |

**风险分类**：

| 类型 | 说明 |
|:---|:---|
| 范围风险 | 需求变更、范围蔓延 |
| 进度风险 | 延期、资源不足 |
| 质量风险 | 缺陷多、质量不达标 |
| 技术风险 | 技术方案不可行 |
| 人员风险 | 人员流动、能力不足 |
| 外部风险 | 政策变化、供应商问题 |

### 步骤 2: 风险评估

**评估维度**：

| 维度 | 说明 |
|:---|:---|
| 影响程度 | 对项目目标的影响大小 |
| 发生概率 | 风险发生的可能性 |
| 可控性 | 风险是否可控 |

**风险等级计算**：

```
风险等级 = 影响程度 × 发生概率

等级定义：
- 高：等级 >= 6
- 中：等级 3-5
- 低：等级 < 3
```

**风险矩阵**：

|  | 低概率 | 中概率 | 高概率 |
|:---|:---:|:---:|:---:|
| **高影响** | 中 | 高 | 高 |
| **中影响** | 低 | 中 | 高 |
| **低影响** | 低 | 低 | 中 |

---

### 步骤 3: 风险应对

**应对策略**：

| 策略 | 说明 | 适用场景 |
|:---|:---|:---|
| 规避 | 消除风险源 | 高概率、高影响 |
| 转移 | 将风险转给第三方 | 高概率、中影响 |
| 缓解 | 降低风险概率或影响 | 中概率、中影响 |
| 接受 | 接受风险，准备应急 | 低概率、低影响 |

### 步骤 4: 风险监控

**监控频率**：

| 风险等级 | 监控频率 |
|:---|:---|
| 高 | 每天 |
| 中 | 每周 |
| 低 | 每两周 |

**预警机制**：

| 预警级别 | 触发条件 | 通知 |
|:---|:---|:---|
| 红色预警 | 高风险新发生 | 立即通知 |
| 橙色预警 | 中风险加剧 | 24h内通知 |
| 黄色预警 | 低风险加剧 | 周报中体现 |

**风险状态**：

| 状态 | 说明 |
|:---|:---|
| MONITORING | 监控中 |
| TRIGGERED | 已触发 |
| MITIGATED | 已缓解 |
| RESOLVED | 已解决 |
| CLOSED | 已关闭 |

---

### 步骤 5: 风险复盘

**复盘内容**：

1. 风险识别是否及时
2. 评估是否准确
3. 应对措施是否有效
4. 需要哪些改进
