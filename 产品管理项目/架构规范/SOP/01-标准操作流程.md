## 1. 概述

本文档定义产品管理系统的标准操作流程（SOP），确保团队成员按照统一规范执行操作。

## 2. 需求拆解流程

### 2.1 流程图

```
业务需求输入
    │
    ▼
┌─────────────────┐
│  需求理解       │  ← 输入：原始需求
│  ProductContext │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  产品分析       │  ← 分析影响范围、风险
│  ProductAnalysis│
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  PRD 生成       │  ← 输出：Epic/Feature/Story
│  PRDGenerator   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  人工审核       │  ← PM 审核确认
│  Human Review   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  同步到 Neo4j   │  ← 状态更新
│  DataSync       │
└─────────────────┘
```

### 2.2 流程说明

| 步骤 | 操作 | 负责人 | 输出 |
|:---:|:---|:---|:---|
| 1 | 收集业务需求 | 产品经理 | 原始需求文档 |
| 2 | 需求理解 Agent 分析 | AI Agent | 结构化需求 |
| 3 | 产品分析 Agent 评估 | AI Agent | 影响分析报告 |
| 4 | PRD 生成 Agent 拆解 | AI Agent | Epic/Feature/Story |
| 5 | 产品经理审核 | PM | 审核意见 |
| 6 | 根据意见修改 | AI Agent | 修改后文档 |
| 7 | 确认并同步 | PM | 最终文档 |
| 8 | 同步到 Neo4j | DataSync Agent | 图数据库更新 |

## 4. 状态流转规范

### 4.1 Epic 状态

| 状态 | 说明 | 可转换到 |
|:---|:---|:---|
| DRAFT | 草稿 | IN_PROGRESS, ARCHIVED |
| IN_PROGRESS | 进行中 | PENDING_REVIEW, ON_HOLD |
| PENDING_REVIEW | 待审核 | IN_PROGRESS, APPROVED |
| APPROVED | 已审核 | IN_PROGRESS |
| ON_HOLD | 暂停 | IN_PROGRESS |
| COMPLETED | 已完成 | - |
| ARCHIVED | 已归档 | - |

### 4.2 Feature 状态

| 状态 | 说明 | 可转换到 |
|:---|:---|:---|
| DRAFT | 草稿 | PLANNED |
| PLANNED | 已计划 | IN_PROGRESS |
| IN_PROGRESS | 进行中 | PENDING_REVIEW, BLOCKED |
| PENDING_REVIEW | 待审核 | IN_PROGRESS, DONE |
| BLOCKED | 阻塞 | IN_PROGRESS |
| DONE | 已完成 | - |

### 4.3 Story 状态

| 状态 | 说明 | 可转换到 |
|:---|:---|:---|
| DRAFT | 草稿 | READY |
| READY | 就绪 | IN_PROGRESS |
| IN_PROGRESS | 进行中 | PENDING_REVIEW |
| PENDING_REVIEW | 待审核 | IN_PROGRESS, DONE |
| DONE | 已完成 | - |
| REMOVED | 已移除 | - |

## 5. 周报生成流程

### 5.1 流程

```
┌─────────────────┐
│  收集工作数据   │  ← 读取 Neo4j、飞书
│  状态跟踪       │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  周报生成       │  ← WeeklyReport Agent
│  Agent          │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  发送飞书       │  ← 发送到团队群
│  通知          │
└─────────────────┘
```

### 5.2 周报内容

| 章节 | 内容 |
|:---|:---|
| 本周完成 | 完成的 Epic/Feature/Story |
| 进行中 | 正在开发的功能 |
| 下周计划 | 计划开始的工作 |
| 风险预警 | 延期或阻塞风险 |
| 资源需求 | 需要支援的地方 |

## 6. 数据同步流程

### 6.1 触发条件

| 触发类型 | 说明 |
|:---|:---|
| 自动同步 | 状态变更时自动同步 |
| 手动同步 | 用户主动触发 |
| 定时同步 | 每日凌晨全量同步 |

### 6.2 同步优先级

| 优先级 | 说明 | 超时时间 |
|:---|:---|:---:|
| P0 | 紧急同步 | 1 分钟 |
| P1 | 正常同步 | 5 分钟 |
| P2 | 低优先级 | 30 分钟 |

### 6.3 异常处理

| 异常 | 处理方式 |
|:---|:---|
| Neo4j 连接失败 | 重试 3 次，间隔 10 秒 |
| 飞书 API 限流 | 加入队列，延迟处理 |
| 数据不一致 | 记录日志，告警通知 |
