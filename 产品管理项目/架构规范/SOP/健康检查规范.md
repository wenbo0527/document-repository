## 三、健康检查SOP

### 3.1 每日检查（建议）

```bash
#!/bin/bash
# health_check.sh - 每日健康检查脚本

echo "=== Neo4j健康检查 ==="

# 1. 检查Neo4j服务状态
curl -s http://localhost:7474 > /dev/null
if [ $? -ne 0 ]; then
    echo "⚠️ Neo4j服务未运行"
    exit 1
fi

# 2. 检查节点数量
python3 << 'EOF'
from neo4j import GraphDatabase

uri = 'bolt://localhost:7687'
driver = GraphDatabase.driver(uri, auth=('neo4j', 'password123'))

with driver.session() as session:
    result = session.run('''
    MATCH (n) 
    RETURN labels(n)[0] as label, count(*) as count
    ORDER BY label
    ''')
    
    expected = {'ProductDomain': 6, 'Epic': 22, 'Feature': 140, 'Story': 210}
    
    for r in result:
        label = r['label']
        count = r['count']
        exp = expected.get(label, 0)
        if exp > 0:
            status = "✅" if count >= exp * 0.9 and count <= exp * 1.1 else "⚠️"
            print(f"  {status} {label}: {count} (期望 {exp})")

driver.close()
EOF

echo "=== 检查完成 ==="
```

### 3.2 每周检查

| 步骤 | 内容 | 工具 |
|:---:|:---|:---|
| 1 | 图数据库节点数量 | Neo4j Browser |
| 2 | Epic→Feature粒度分布 | Python脚本 |
| 3 | 本地文档与Neo4j同步 | 文件比对 |
| 4 | 重复节点检查 | Python脚本 |
| 5 | 关系完整性检查 | Python脚本 |

### 3.3 变更后检查

| 操作 | 必须检查项 |
|:---|:---|
| 新增Epic | 命名不重复、关联ProductDomain、Feature粒度 |
| 新增Feature | 命名不重复、关联Epic、粒度合规 |
| 删除节点 | 子节点处理、关系清理 |
| 重命名 | Neo4j更新、本地文档同步 |
