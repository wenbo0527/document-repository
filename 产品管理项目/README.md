## 项目概述

产品管理系统基于 Neo4j 图数据库 + 飞书协作，实现业务需求的智能拆解与全链路追踪。

### 核心架构

```
业务需求入口
    ↓
AI 需求智能拆解（Epic/Feature/Story/FP）
    ↓
本体论语义层（术语统一 & 知识图谱）
    ↓
图与向量层（Neo4j + RAG）
```

## 六大产品域

| 产品域 | 名称 | 说明 |
|:---|:---|:---|
| PD-DFD | 数据发现 | 数据资产字典、数据要素、资源管理 |
| PD-MKT | 数字营销 | 客群中心、营销活动、内容管理 |
| PD-RISK | 数字风险 | 模型回溯、实时决策、合规管理 |
| PD-COM | 数字社区 | 门户管理、权限管理、个性化 |
| PD-DEX | 数据探索 | 即席查询、自助分析、报表中心 |
| PD-DMT | 数据管理 | 元数据管理、数据标准、数据质量 |
