## 概述

### 这是什么？

产品管理系统是一套基于 AI + 知识图谱的产品管理方法论，通过四层架构实现业务需求的智能拆解与全链路追踪。

### 为什么重要？

- **结构化**：Domain → Epic → Feature → Story → FP 五层结构
- **可追溯**：Neo4j 图数据库存储层级关系
- **协作化**：飞书多维表格实时同步状态
- **AI 增强**：智能问答、RAG 检索

### 适用场景？

- 新产品域初始化
- 需求分析与拆解
- Epic 交付开发
- 项目进度追踪

---

## 核心架构

```
业务需求入口
    ↓
AI 需求智能拆解（Epic/Feature/Story/FP）
    ↓
本体论语义层（术语统一 & 知识图谱）
    ↓
图与向量层（Neo4j + RAG）
```

## 六大产品域

| 产品域 | 名称 | 说明 |
|:---|:---|:---|
| PD-DFD | 数据发现 | 数据资产字典、数据要素、资源管理 |
| PD-MKT | 数字营销 | 客群中心、营销活动、内容管理 |
