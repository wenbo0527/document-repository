## 2. 系统架构

```
┌─────────────────────────────────────────────────────┐
│                   产品管理系统                        │
├─────────────────────────────────────────────────────┤
│  业务需求入口 → AI需求拆解 → 本体论语义层 → 图数据库层   │
│       ↓            ↓           ↓           ↓         │
│   飞书多维表格    Epic/Story   术语统一     Neo4j    │
└─────────────────────────────────────────────────────┘
```

---

## 3. 日常操作流程

### 3.1 创建新需求

1. 在飞书多维表格中创建需求记录
2. 使用 requirement-understanding 解析需求
3. 使用 requirement-breakdown 拆解到 Neo4j
4. 使用 prd-generation 生成 PRD

### 3.2 更新需求状态

1. 修改飞书多维表格状态
2. 同步更新 Neo4j 状态
3. 触发相关人员通知

---

## 4. 常用命令

| 命令 | 说明 |
|:---|:---|
| 查询 Epic | `MATCH (e:Epic {id: 'EPIC-xxx'}) RETURN e` |
| 查询 Feature | `MATCH (f:Feature) WHERE f.epic = 'EPIC-xxx' RETURN f` |
| 更新状态 | `MATCH (n {id: 'xxx'}) SET n.status = 'DONE'` |

## 5. 常见问题

| 问题 | 解决方案 |
|:---|:---|
| Neo4j 连接失败 | 检查 bolt://localhost:7687 是否可达 |
| 状态不同步 | 手动执行同步脚本 |
| 数据丢失 | 从备份恢复 |
