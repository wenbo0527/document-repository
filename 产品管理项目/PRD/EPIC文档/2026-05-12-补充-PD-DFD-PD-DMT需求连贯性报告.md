## 二、问题1修复：命名统一

### 2.1 问题描述

Phase1 PRD 标题使用旧名称"数据要素字典"，与产品域说明文档中的"数据要素市场"不一致。

| 文件 | 原名称 | 统一名称 |
|:---|:---|:---|
| PRD-PDDFD-Phase1 | **数据要素字典** | **数据要素市场** |
| PRD-PDDFD-Phase1 | **指标地图/变量地图/特征地图** | ✅ 保持不变 |

### 2.2 修复方案

**Phase1 PRD 中修改**：
- 将 Epic 名称从"数据要素字典"改为"数据要素市场"
- 将 Feature 名称从"指标字典列表/变量字典列表/特征字典列表"改为"指标地图/变量地图/特征地图"
- 将路由从 `/discovery/metrics-dic` 改为 `/discovery/metrics-map`（已更新）

## 三、问题2澄清：边界划清

### 3.1 PD-DMT 与 PD-DFD 的边界

| 维度 | PD-DMT 数据管理 | PD-DFD 数据发现 |
|:---|:---|:---|
| **定位** | 治理层 | 展示层 |
| **核心职责** | 标准制定、审批管控 | 检索发现、消费使用 |
| **用户** | 数据管理员 | 数据使用者 |
| **生命周期** | 上架前 | 上架后 |

### 3.2 "数据要素"边界定义

| 要素类型 | PD-DMT 职责 | PD-DFD 职责 |
|:---|:---|:---|
| **指标** | 创建、审批、口径定义、上下架 | 检索、发现、使用申请 |
| **变量** | 创建、审批、类型定义、上下架 | 检索、发现、使用申请 |
| **特征** | 创建、审批、来源定义、上下架 | 检索、发现、使用申请 |
| **API** | 创建、审批、权限授权、上下线 | 检索、发现、调用申请 |

## 四、问题3补充：价值闭环

### 4.1 完整价值链

```
┌────────────────────────────────────────────────────────────────────┐
│                         完整价值闭环                                │
├────────────────────────────────────────────────────────────────────┤
│                                                                    │
│   【治理层 PD-DMT】                                                │
│   标准制定 → 元数据采集 → 审批上架 → 质量检查                       │
│        ↑                                                          │
│        │ 引用/依赖                                                 │
│   【展示层 PD-DFD】                                                │
│   统一搜索 → 资产发现 → 详情了解 → 申请使用                        │
│        ↓                                                          │
│   【消费层】                                                       │
│   PD-DEX 即席查询 / PD-MKT 数字营销 / PD-RISK 数字风险             │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘
```

### 4.2 下游消费场景

| 下游产品域 | 消费方式 | 说明 |
|:---|:---|:---|
| **PD-DEX 数据探索** | API调用/数据下载 | 查询数据、下载报表 |
| **PD-MKT 数字营销** | 客群数据调用 | 精准营销人群包 |
| **PD-RISK 数字风险** | 变量/特征调用 | 风控模型入参 |
| **PD-COM 通用** | 统一认证授权 | 单点登录、权限验证 |

### 4.3 闭环缺失环节

| 缺失环节 | 当前状态 | 建议补充 |
|:---|:---|:---|
| 使用反馈 | ❌ 无 | 资产使用后可评价打分 |
| 问题反馈 | ❌ 无 | 数据问题可提交工单 |
| 变更通知 | ⚠️ 部分 | 影响分析仅内部使用 |
| 使用追踪 | ⚠️ 部分 | 服务监控有，但资产使用无 |
