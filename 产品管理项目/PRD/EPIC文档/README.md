## 概述

### 这是什么？

EPIC 文档库按产品域组织，每个产品域下包含该域的所有 EPIC 文档。

### 为什么重要？

- **结构清晰**：按产品域分层，便于查找
- **统一入口**：想知道某个产品域有哪些 EPIC，看这里
- **可扩展**：新增产品域只需创建目录和 README

### 适用场景？

- 查看某产品域的所有 EPIC
- 了解 EPIC 之间的关联
- 新增 EPIC 文档

## 目录结构

```
EPIC文档/
├── README.md              # 本文档（产品域层索引）
└── {产品域}/              # 产品域目录
    ├── README.md          # EPIC 层索引
    └── XX-EPIC-*.md       # EPIC 文档
```

## 维护说明

### 新增 EPIC
1. 在对应产品域目录下创建 EPIC 文档
2. 更新产品域 README 的 EPIC 列表
3. 更新本文档的产品域索引

### EPIC 文档命名规范
```
{序号}-EPIC-{英文名}.md
示例：01-EPIC-统一门户首页.md
```
