## 概述

### 这是什么？

产品域说明文档库存放六大产品域的完整说明文档，每个产品域一份。

### 为什么重要？

- **全局视角**：快速了解产品域定位和核心能力
- **知识传承**：新人了解产品的标准文档
- **协作基准**：团队协作的统一参考

### 适用场景？

- 了解产品域整体架构
- EPIC 创建前的背景调研
- 新人 onboarding

## 文档结构

每个产品域说明文档包含：

1. **产品域概述** - 基本信息、定位、核心价值、覆盖场景
2. **对标产品** - 竞品分析、差异化策略
3. **产品架构** - 层级结构、技术架构、菜单结构
4. **Epic 列表** - 所有 EPIC 及 Feature
5. **核心指标** - 业务、技术、用户指标
6. **依赖关系** - 依赖/被依赖关系
7. **团队** - 角色与职责
8. **变更记录** - 版本历史
