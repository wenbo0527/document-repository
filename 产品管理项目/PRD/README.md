## 概述

### 这是什么？

PRD 文档库是产品需求文档的集中存储仓库，包含各产品域的 EPIC 文档、PRD 模板、附录资料。

### 为什么重要？

- **统一存储**：所有 PRD 相关文档集中管理
- **版本可控**：Git 版本控制，可追溯变更历史
- **结构清晰**：按产品域、EPIC 分层组织

### 适用场景？

- 查看 EPIC 文档
- 参考 PRD 模板
- 了解产品需求范围
