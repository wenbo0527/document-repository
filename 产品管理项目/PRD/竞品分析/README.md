## 六、使用说明

### 6.1 新增竞品分析

1. 复制 `竞品分析报告模板.md` 到 `竞品报告/` 目录
2. 命名为 `{竞品名}-竞品分析.md`
3. 填写报告内容
4. 更新本目录的分析清单

### 6.2 更新能力矩阵

1. 编辑 `产品能力比对清单.md`
2. 更新对应产品域的能力项
3. 更新 `产品能力地图.md` 的成熟度标记
