### 4.2 操作流程

```
【找数据流程】
首页搜索 → 关键字/标签 → 筛选 → 查看详情 → 申请权限/收藏

【数据开发流程】
创建任务 → SQL编辑 → 提交审核 → DAG编排 → 定时调度

【质量监控流程】
配置规则 → 质量检测 → 质量报告 → 问题追踪
```

### 4.3 优点

| # | 优点 | 说明 |
|:---:|:---|:---|
| 1 | **一站式闭环** | 从找数据→开发→治理→分析，全链路覆盖 |
| 2 | **AI能力深度集成** | 智能找数、智能血缘等业界领先 |
| 3 | **内部打磨多年** | 字节内部大规模使用，稳定可靠 |
| 4 | **血缘自动解析** | 无需人工维护，降低使用门槛 |

### 4.4 缺点

| # | 缺点 | 说明 |
|:---:|:---|:---|
| 1 | **外部商业化晚** | 2020年才对外，部分功能不如内部 |
| 2 | **定制化能力弱** | 对大企业复杂需求响应慢 |
| 3 | **价格较高** | 企业版定价偏高，中小企业负担 |
