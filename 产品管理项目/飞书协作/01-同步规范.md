# 飞书协作 - 同步规范

> **版本**: v1.0
> **日期**: 2026-04-24
> **作者**: Tony Stark
> **状态**: 正式发布

---

## 1. 概述

本文档定义产品管理系统与飞书的协作同步规范。

---

## 2. 同步场景

| 场景 | 触发条件 | 同步内容 |
|:---|:---|:---|
| PRD 定稿 | PRD 状态变为 APPROVED | PRD 文档 → 飞书云盘 |
| 需求变更 | Story/Feature 状态变更 | 状态同步 → 飞书多维表格 |
| Epic 完成 | Epic 完成度达到 100% | 通知相关人员 |

---

## 3. 飞书多维表格结构

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| 需求名称 | 文本 | 需求标题 |
| 产品域 | 单选 | PD-MKT / PD-RISK 等 |
| Epic | 单选 | 关联 Epic |
| Feature | 单选 | 关联 Feature |
| 状态 | 单选 | DRAFT / IN_PROGRESS / DONE |
| 优先级 | 单选 | P0 / P1 / P2 / P3 |
| 负责人 | 人员 | 负责人 |
| 更新日期 | 日期 | 最后更新时间 |

---

## 4. 同步流程

```
飞书多维表格变更
    ↓
触发 Webhook
    ↓
Tony Agent 接收通知
    ↓
更新 Neo4j 状态
    ↓
记录同步日志
```

---

## 5. 错误处理

| 错误 | 处理方式 |
|:---|:---|
| 飞书 API 超时 | 重试 3 次，间隔 5 秒 |
| Neo4j 连接失败 | 记录日志，后续补偿 |
| 权限不足 | 通知管理员 |
