## 概述

### 这是什么？

飞书协作模块定义与飞书文档、多维表格的同步规范，确保本地文档与飞书实时同步。

### 为什么重要？

- **实时协作**：团队成员可以通过飞书实时协作
- **状态同步**：Neo4j 状态变更自动同步到飞书
- **统一入口**：飞书作为团队的统一工作入口

### 适用场景？

- Epic 状态变更同步
- 里程碑进度同步
- 周报/月报自动发送
