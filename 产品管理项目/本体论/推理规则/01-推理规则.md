## 1. 概述

本文档定义基于 OWL 的推理规则，用于产品管理系统知识图谱。

---

## 2. 层级推理规则

### 2.1 Epic 完成度计算

```
IF (Epic CONTAINS Feature)
AND (Feature.status = DONE)
AND (Feature.fp_count > 0)
THEN Epic.completion_rate = 
  SUM(Feature.completed_fp_count) / SUM(Feature.fp_count) * 100
```

### 2.2 Epic 状态推导

```
IF ALL Feature BELONGS_TO Epic
AND ALL Feature.status = DONE
THEN Epic.status = DONE
```

---

## 3. 依赖推理规则

### 3.1 Story 阻塞检测

```
IF Story A DEPENDS_ON Story B
AND Story B.status != DONE
THEN Story A.status = BLOCKED
```

### 3.2 Feature 完成条件

```
IF Story A BELONGS_TO Feature
AND Story A.status != DONE
THEN Feature.status != DONE
```

---

## 4. 产品域统计规则

### 4.1 产品域完成度

```
IF ProductDomain CONTAINS Epic
THEN ProductDomain.total_epic = COUNT(Epic)
AND ProductDomain.completed_epic = COUNT(Epic WHERE status = DONE)
AND ProductDomain.completion_rate = completed_epic / total_epic * 100
```

---

## 5. 关系推导规则

### 5.1 祖先节点推导

```
IF Node A CONTAINS Node B
AND Node B CONTAINS Node C
THEN Node A CONTAINS Node C (传递闭包)
```

### 5.2 兄弟节点识别

```
IF Node A BELONGS_TO Parent
AND Node B BELONGS_TO Parent
THEN Node A and Node B are siblings
```
