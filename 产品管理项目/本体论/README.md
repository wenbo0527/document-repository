## 概述

### 这是什么？

本体论定义了产品管理系统的概念模型，包括术语定义、实体类型、关系类型、约束规则、推理规则。

### 为什么重要？

- **术语统一**：避免歧义，确保团队沟通一致
- **知识结构**：建立清晰的概念层级
- **推理能力**：基于 OWL 规则的推理

### 适用场景？

- 新人了解产品管理概念
- 定义新实体/关系类型
- 检查数据一致性

## 核心概念

| 概念 | 英文 | 说明 |
|:---|:---|:---|
| ProductDomain | 产品域 | 最大粒度的业务域 |
| Epic | 史诗 | 跨 Feature 的业务需求 |
| Feature | 功能模块 | 具体的功能集合 |
| Story | 用户故事 | 从用户视角描述的需求 |
| FP | 功能点 | 最小可交付单位 |
