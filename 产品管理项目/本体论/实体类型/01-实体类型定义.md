# 本体论 - 实体类型定义

> **版本**: v1.0
> **日期**: 2026-04-24
> **作者**: Tony Stark
> **状态**: 正式发布

---

## 1. 概述

本文档定义产品管理系统的实体类型（节点类型），基于产品域层级结构。

---

## 2. 实体类型层级

```
L0: Vision (产品愿景)
L1: Goal (目标)
L2: OKR (关键结果)
L3: Project (项目)
L4: ProductDomain (产品域)
L5: Epic (史诗)
L6: Feature (特性)
L7: Story (用户故事)
L8: FP (功能点)
```

---

## 3. 核心实体类型

### 3.1 ProductDomain (产品域)

| 属性 | 类型 | 说明 |
|:---|:---|:---|
| id | string | 产品域 ID，如 PD-MKT |
| name | string | 产品域名称 |
| description | string | 描述 |
| status | string | 状态 |

### 3.2 Epic (史诗)

| 属性 | 类型 | 说明 |
|:---|:---|:---|
| id | string | Epic ID，如 EPIC-MKT-CANVAS |
| name | string | Epic 名称 |
| product_domain | string | 所属产品域 |
| priority | string | 优先级 P0/P1/P2/P3 |
| status | string | 状态 |
| completion_rate | number | 完成度百分比 |

### 3.3 Feature (特性)

| 属性 | 类型 | 说明 |
|:---|:---|:---|
| id | string | Feature ID |
| name | string | Feature 名称 |
| epic | string | 所属 Epic |
| priority | string | 优先级 |
| status | string | 状态 |

### 3.4 Story (用户故事)

| 属性 | 类型 | 说明 |
|:---|:---|:---|
| id | string | Story ID |
| title | string | 标题 |
| description | string | 描述 |
| acceptance_criteria | object | 验收标准 |
| status | string | 状态 |

### 3.5 FP (功能点)

| 属性 | 类型 | 说明 |
|:---|:---|:---|
| id | string | FP ID |
| name | string | 功能点名称 |
| type | string | 类型 |
| status | string | 状态 |
| story | string | 所属 Story |
