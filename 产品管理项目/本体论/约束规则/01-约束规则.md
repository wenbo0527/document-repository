# 本体论 - 约束规则

> **版本**: v1.0
> **日期**: 2026-04-24
> **作者**: Tony Stark
> **状态**: 正式发布

---

## 1. 概述

本文档定义产品管理系统的约束规则，确保数据完整性。

---

## 2. 层级约束

| 层级 | 约束 |
|:---|:---|
| ProductDomain → Epic | 一个产品域至少包含 1 个 Epic |
| Epic → Feature | 一个 Epic 包含 1-10 个 Feature |
| Feature → Story | 一个 Feature 包含 1-10 个 Story |
| Story → FP | 一个 Story 包含 1-10 个 FP |

---

## 3. ID 约束

| 类型 | 格式 | 示例 |
|:---|:---|:---|
| ProductDomain | PD-{code} | PD-MKT |
| Epic | EPIC-{域}-{模块} | EPIC-MKT-CANVAS |
| Feature | FEAT-{域}-{Epic}-{特性} | FEAT-MKT-CANVAS-DESIGN |
| Story | STORY-{域}-{Epic}-{特性}-{nnn} | STORY-MKT-CANVAS-DESIGN-001 |
| FP | FP-{域}-{Epic}-{Feature}-{nnn} | FP-MKT-CANVAS-DESIGN-001 |

---

## 4. 状态约束

| 状态 | 可转换到 |
|:---|:---|
| DRAFT | IN_PROGRESS, BLOCKED |
| IN_PROGRESS | REVIEW, DONE, BLOCKED |
| REVIEW | APPROVED, IN_PROGRESS |
| APPROVED | DONE |
| DONE | (终态) |
| BLOCKED | IN_PROGRESS |

---

## 5. 唯一性约束

- Epic ID 在同一产品域内唯一
- Feature ID 在同一 Epic 内唯一
- Story ID 在同一 Feature 内唯一
- FP ID 在同一 Story 内唯一

---

## 6. 必填属性

| 实体类型 | 必填属性 |
|:---|:---|
| ProductDomain | id, name, status |
| Epic | id, name, product_domain, priority |
| Feature | id, name, epic, priority |
| Story | id, title, acceptance_criteria |
| FP | id, name, type |
