## 1. 概述

本文档定义产品管理系统中使用的基本术语，确保团队内部沟通的一致性。

---

## 2. 产品层级术语

| 术语 | 英文 | 定义 | ID格式 |
|:---|:---|:---|:---|
| 产品域 | ProductDomain | 产品线的顶级分类，如数字营销、数字风险等 | `PD-{code}` |
| Epic | Epic | 跨多个 Feature 的高级功能块，代表一个完整的用户价值 | `EPIC-{域}-{模块}` |
| Feature | Feature | 具体的功能模块，是 Epic 的子集 | `FEAT-{域}-{Epic}-{特性}` |
| Story | Story | 具体的用户故事，对应一个可交付的功能 | `STORY-{域}-{Epic}-{特性}-{nnn}` |
| 功能点 | FP (FeaturePoint) | Story 的具体实现细节 | `FP-{域}-{Epic}-{Feature}-{nnn}` |

---

## 3. 项目管理术语

| 术语 | 英文 | 定义 |
|:---|:---|:---|
| 需求 | Requirement | 用户想要实现的功能或目标 |
| 验收标准 | Acceptance Criteria | 功能完成的判定条件 |
| 优先级 | Priority | 需求的紧急程度 (P0/P1/P2/P3) |
| 状态 | Status | 需求的当前阶段 |

---

## 4. 状态定义

| 状态 | 说明 |
|:---|:---|
| DRAFT | 草稿，尚未完成评审 |
| IN_PROGRESS | 进行中 |
| REVIEW | 评审中 |
| APPROVED | 已批准 |
| DONE | 已完成 |
| BLOCKED | 被阻塞 |

---

## 5. 优先级定义

| 优先级 | 说明 | 响应时间 |
|:---|:---|:---|
| P0 | 紧急，阻塞业务 | 立即处理 |
| P1 | 高优先 | 24小时内 |
| P2 | 中优先 | 3天内 |
| P3 | 低优先 | 1周内 |

---

## 6. 关联术语

- **CONTAINS**: 上级包含下级（Epic 包含 Feature）
- **BELONGS_TO**: 下级从属于上级（Feature 属于 Epic）
- **SUPPORTS**: 支持某个目标
- **DEPENDS_ON**: 依赖某个节点
