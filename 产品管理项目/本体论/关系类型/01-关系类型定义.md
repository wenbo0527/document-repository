> **版本**: v1.0

> **作者**: Tony Stark
> **状态**: 正式发布

---

## 1. 概述

本文档定义产品管理系统实体之间的关系类型。

---

## 2. 主要关系类型

| 关系类型 | 说明 | 方向 | 示例 |
|:---|:---|:---:|:---|
| CONTAINS | 上级包含下级 | → | Epic CONTAINS Feature |
| BELONGS_TO | 下级从属于上级 | → | Feature BELONGS_TO Epic |
| SUPPORTS | 支持某个目标 | → | Feature SUPPORTS Epic |
| DEPENDS_ON | 依赖某个节点 | → | Story DEPENDS_ON Story |
| TRACKS | 追踪 | → | Epic TRACKS OKR |

---

## 3. 层级关系

```
ProductDomain
    │
    └── CONTAINS ──→ Epic
                        │
                        └── CONTAINS ──→ Feature
                                            │
                                            └── CONTAINS ──→ Story
                                                            │
                                                            └── CONTAINS ──→ FP
```

---

## 4. 关系属性

### 4.1 CONTAINS

| 属性 | 类型 | 说明 |
|:---|:---|:---|
| created_at | datetime | 创建时间 |
| weight | number | 权重（影响完成度计算）|

### 4.2 BELONGS_TO

| 属性 | 类型 | 说明 |
|:---|:---|:---|
| role | string | 角色 |
| created_at | datetime | 创建时间 |

---

## 5. 跨层级关系

| 关系 | 说明 |
|:---|:---|
| Epic SUPPORTS ProductDomain | Epic 支持产品域目标 |
| Feature TRACKS OKR | Feature 追踪 OKR |
| Story BLOCKED_BY Story | Story 被其他 Story 阻塞 |
